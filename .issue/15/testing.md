## 確認項目

### 1. fax フィールドに値を入力してレコード作成

- **目的:** fax フィールドが正しくバリデーションを通り、レコードが作成されることを確認
- **手順:**
  1. ブラウザでログイン（admin / Admin123!）
  2. 顧客リストアプリのレコード一覧を開く
  3. 「Add Record」をクリック
  4. FAX 欄に `0312345679` を入力
  5. Save をクリック
- **期待結果:** バリデーションエラーなくレコードが作成され、詳細画面に遷移する
- **確認ポイント:** `Field code "fax" does not exist in the app` エラーが表示されないこと

### 2. notes フィールドに値を入力してレコード作成

- **目的:** notes フィールドが正しくバリデーションを通り、レコードが作成されることを確認
- **手順:**
  1. 「Add Record」をクリック
  2. Notes 欄に `テスト備考` を入力
  3. Save をクリック
- **期待結果:** バリデーションエラーなくレコードが作成される
- **確認ポイント:** `Field code "notes" does not exist in the app` エラーが表示されないこと

### 3. fax と notes の両方に値を入力してレコード作成

- **目的:** 両方のフィールドを同時に使用しても問題ないことを確認
- **手順:**
  1. 「Add Record」をクリック
  2. Company に `テスト会社`、FAX に `0312345680`、Notes に `テスト備考2` を入力
  3. Save をクリック
- **期待結果:** レコードが正常に作成される

### 4. fax と notes を空のままレコード作成

- **目的:** fax/notes が空の場合も引き続き正常に動作することを確認（デグレチェック）
- **手順:**
  1. 「Add Record」をクリック
  2. Company のみ入力し、FAX と Notes は空のまま
  3. Save をクリック
- **期待結果:** レコードが正常に作成される（修正前と同じ動作）
