## 確認項目

### 1. レコード詳細から編集画面へ遷移して保存できること

- **目的:** `spec/manual-tests/record-crud.md` TC-006 を満たす
- **手順:**
  1. 顧客リストアプリで既存レコードの詳細画面を開く
  2. `Edit record` をクリックする
  3. `Company` を `テスト株式会社（編集済み）` に変更する
  4. `Save` をクリックする
- **期待結果:** `/apps/:appId/records/:recordId/edit` へ遷移したあと、保存成功で元の詳細画面へ戻り、更新値が表示される
- **確認ポイント:** `Company` が更新され、変更履歴または更新日時に変更が反映されている

### 2. レコード削除前に確認ダイアログが表示されること

- **目的:** `spec/manual-tests/record-crud.md` TC-007 / TC-008 の前提を満たす
- **手順:**
  1. レコード詳細画面で `Options` を開く
  2. `Delete record` をクリックする
- **期待結果:** 削除確認ダイアログが表示される
- **確認ポイント:** `Cancel` と `Delete` の両方の導線が見える

### 3. レコード削除をキャンセルできること

- **目的:** `spec/manual-tests/record-crud.md` TC-008 を満たす
- **手順:**
  1. 削除確認ダイアログを開く
  2. `Cancel` をクリックする
- **期待結果:** ダイアログが閉じ、詳細画面に留まる
- **確認ポイント:** レコードがそのまま表示され、削除されていない

### 4. レコードを削除すると一覧へ戻ること

- **目的:** `spec/manual-tests/record-crud.md` TC-007 を満たす
- **手順:**
  1. 削除確認ダイアログを開く
  2. `Delete` をクリックする
- **期待結果:** レコードが削除され、アプリのレコード一覧へ遷移する
- **確認ポイント:** 直前まで見ていたレコード詳細に戻らず、一覧画面が表示される

### 5. レコード再利用で値コピー済み新規作成画面へ遷移できること

- **目的:** `spec/manual-tests/record-crud.md` TC-009 を満たす
- **手順:**
  1. 値が入ったレコード詳細画面を開く
  2. `Reuse record` をクリックする
  3. `Company` を `コピー先株式会社` に変更する
  4. `Save` をクリックする
- **期待結果:** 新規作成画面に元レコードの値が初期表示され、新しいレコードとして保存される
- **確認ポイント:** 新しいレコード番号で詳細画面が開き、`Company` 以外の項目はコピー元の値を維持している
