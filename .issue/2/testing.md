# 動作確認計画 — Issue #2: バグ: スペース作成・アプリ作成ページのルートが未実装

**Issue:** #2
**作成日:** 2026-04-12

---

## 確認環境

### デプロイ・起動手順
1. 依存パッケージのインストール
   ```bash
   pnpm install
   ```
2. データベースのマイグレーション・シード
   ```bash
   pnpm db:migrate
   pnpm db:seed
   ```
3. 開発サーバーの起動
   ```bash
   pnpm dev
   ```
4. 確認用URL: http://localhost:5173

### 前提条件
- ログイン済みのユーザーアカウントが必要（シードデータで作成されるもの）
- ポータル画面（`/portal`）にアクセスできる状態

## 確認項目

### 1. `/spaces/new` でスペース作成フォームが表示される

- **目的:** ルート未実装による 404/Internal Server Error が解消されていることを確認
- **手順:**
  1. ログイン後、ブラウザのアドレスバーに `http://localhost:5173/spaces/new` を直接入力
  2. ページが表示されることを確認
- **期待結果:** スペース作成フォームが表示される（スペース名入力フィールド、チェックボックス等）
- **確認ポイント:** 404 や Internal Server Error ではなく、正常なフォームページが表示されること

### 2. ポータルの Options メニューから「スペースを作成」で `/spaces/new` に遷移する

- **目的:** ポータルからのナビゲーションが正常に動作することを確認
- **手順:**
  1. ポータル画面（`/portal`）を開く
  2. 右上の「Options」ボタンをクリック
  3. 「スペースを作成」をクリック
- **期待結果:** `/spaces/new` に遷移し、スペース作成フォームが表示される
- **確認ポイント:** リンク先が正しいこと、遷移後にエラーが出ないこと

### 3. スペース名を入力して保存し、スペースが作成される

- **目的:** スペース作成のフォーム送信が正常に動作することを確認
- **手順:**
  1. `/spaces/new` にアクセス
  2. スペース名に「テストスペース」と入力
  3. 保存ボタンをクリック
- **期待結果:** スペースが作成され、`/spaces/{spaceId}` に遷移する
- **確認ポイント:** エラーなく遷移し、作成したスペースのページが表示されること

### 4. スペース名未入力でバリデーションエラーが表示される

- **目的:** フォームバリデーションが正常に動作することを確認（TC-007 対応）
- **手順:**
  1. `/spaces/new` にアクセス
  2. スペース名を空のまま保存ボタンをクリック
- **期待結果:** バリデーションエラーメッセージが表示され、フォームは送信されない
- **確認ポイント:** エラーメッセージがスペース名フィールド付近に表示されること

### 5. ゲストスペース作成モード（`?guest=true`）

- **目的:** ゲストスペース作成の切替が正常に動作することを確認
- **手順:**
  1. `http://localhost:5173/spaces/new?guest=true` にアクセス
  2. フォームが表示されることを確認
  3. 「非公開」チェックボックスが ON かつ変更不可であることを確認
- **期待結果:** ゲストスペース作成モードのフォームが表示され、非公開が固定ON
- **確認ポイント:** 通常モードとの違い（非公開が固定）が反映されていること

### 6. `/apps/store` でアプリストア画面が表示される

- **目的:** ルート未実装による 404/Internal Server Error が解消されていることを確認
- **手順:**
  1. ブラウザのアドレスバーに `http://localhost:5173/apps/store` を直接入力
  2. ページが表示されることを確認
- **期待結果:** アプリストア画面が表示される（「はじめから作成」ボタン、テンプレート一覧等）
- **確認ポイント:** 404 や Internal Server Error ではなく、正常なページが表示されること

### 7. ポータルの Options メニューから「アプリを作成」で `/apps/store` に遷移する

- **目的:** ポータルからのナビゲーションが正常に動作することを確認
- **手順:**
  1. ポータル画面（`/portal`）を開く
  2. 右上の「Options」ボタンをクリック
  3. 「アプリを作成」をクリック
- **期待結果:** `/apps/store` に遷移し、アプリストア画面が表示される
- **確認ポイント:** リンク先が正しいこと、遷移後にエラーが出ないこと

### 8. アプリストアの「はじめから作成」でアプリが作成される

- **目的:** 空アプリの作成が正常に動作することを確認
- **手順:**
  1. `/apps/store` にアクセス
  2. 「はじめから作成」ボタンをクリック
- **期待結果:** アプリが作成され、`/apps/{appId}/settings` に遷移する
- **確認ポイント:** エラーなく遷移し、作成したアプリの設定ページが表示されること

### 9. ポータルの Spaces/Apps セクション「Create」ボタンが動作する

- **目的:** Issue 再現手順 Step 4 の「Create app ボタンをクリックしても何も起きない」問題が解消されていることを確認
- **手順:**
  1. ポータル画面（`/portal`）を開く
  2. Spaces セクション下部の「Create space」ボタンをクリック
  3. `/spaces/new` に遷移することを確認
  4. ポータルに戻り、Apps セクション下部の「Create app」ボタンをクリック
  5. `/apps/store` に遷移することを確認
- **期待結果:** 両方のボタンで正しいページに遷移する
- **確認ポイント:** ボタンクリックで無反応ではなく、適切なページに遷移すること
