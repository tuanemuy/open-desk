### [I-001] ルートindex.tsxが return null のリダイレクト専用ページ
- **ファイル:** `app/routes/index.tsx:7-9`
- **カテゴリ:** 不完全な制御フロー
- **根拠:** loaderでリダイレクトするため通常到達しないが、フォールバックUIがない。React Router v7の仕様上意図的な設計として許容される可能性あり。

### [I-002] 通知・検索ページのフィルタリングがクライアントサイドのみ
- **ファイル:** `app/routes/notifications/index.tsx`, `app/routes/search/index.tsx`
- **カテゴリ:** 不完全な制御フロー
- **根拠:** フィルターUIはReact stateで管理されているが、サーバーへのクエリパラメータ送信やloader再呼び出しが未実装。検索ページの「絞り込む」ボタンは `type="button"` でonClickハンドラーもない。

### [I-003] メッセージ一覧ページが最小限のスタブUI
- **ファイル:** `app/routes/messages/index.tsx:9-17`
- **カテゴリ:** spec 未実装
- **根拠:** loaderでリダイレクトされるため表示されない設計だが、リダイレクトが失敗した場合に「メッセージスレッドを読み込んでいます...」が永久に表示される。リダイレクト先もハードコードID。

### [I-004] DB CHECK制約が未実装（アプリケーション層で検証する設計判断）
- **ファイル:** `app/core/adapters/drizzleSqlite/schema.ts`
- **カテゴリ:** spec 未実装
- **根拠:** 設計書に多数のCHECK制約が定義されているが、Drizzle ORM + SQLiteの制約上、全てアプリケーション層での検証に委譲されている。特にビジネスルール系（権限の論理整合性、自己フォロー禁止、ID順序正規化）がドメイン層で確実にカバーされていることの確認を推奨。

### [I-005] DB明示的インデックス4件の省略（UNIQUE制約で暗黙的にカバー）
- **ファイル:** `app/core/adapters/drizzleSqlite/schema.ts`
- **カテゴリ:** spec 未実装
- **対象:** `idx_users_login_name`, `idx_organizations_code`, `idx_apps_code`, `idx_stored_files_file_key`
- **根拠:** 各カラムに `.unique()` が設定されているため暗黙的インデックスは存在する。設計書の明示的な名前付きインデックスとは異なるが、実質的な問題はない。
