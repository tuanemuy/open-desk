# サイトマップ

## 画面一覧

| 画面名 | URL パターン | セクション | 認証 | 概要 |
|--------|-------------|-----------|------|------|
| ログイン | /login | 認証 | 不要 | メール/パスワード認証フォーム |
| ポータル | /k/#/portal | ポータル | 必要 | ホーム画面。お知らせ・通知・スペース・アプリの集約表示 |
| 通知一覧 | /k/#/ntf/mention | 通知 | 必要 | 自分宛通知の一覧・管理 |
| スペース | /k/#/space/{id} | スペース | 必要 | チームコミュニケーション空間 |
| スレッド詳細 | /k/#/space/{id} (SPA内遷移) | スペース | 必要 | スレッド内容表示・コメント投稿 |
| ピープル | /k/#/people/user/{email} | ピープル | 必要 | ユーザープロフィール・ステータス投稿 |
| アプリ一覧 | /k/{app_id}/ | アプリ | 必要 | レコードの一覧表示 |
| レコード詳細 | /k/{app_id}/show#record={record_id} | アプリ | 必要 | レコードの詳細表示・編集 |
| レコード追加 | /k/{app_id}/edit | アプリ | 必要 | 新規レコード作成フォーム |
| アプリ設定 | /k/admin/app/{app_id}/ | アプリ管理 | 必要 | フォーム・ビュー・グラフ・設定の管理 |
| アカウント設定 | (cybozu.com外部画面) | 設定 | 必要 | プロフィール編集・パスワード変更等 |
| OpenDeskシステム管理 | /k/admin/system/ | 管理 | 必要 | OpenDesk全体のシステム設定（アプリ管理、スペース管理、ゲスト管理、アクセス権、カスタマイズ等） |
| cybozu.com共通管理 | /admin/ | 管理 | 必要 | cybozu.com全体の管理（ユーザー管理、セキュリティ、監査ログ、外部連携等） |
| 個人設定（cybozu.com） | /settings/profile | 設定 | 必要 | プロフィール編集、パスワード変更、モバイル設定、ログイン履歴 |
| 個人設定（OpenDesk） | /k/settings?id=1 | 設定 | 必要 | 時刻表記、メール通知、デスクトップ通知の設定 |
| OpenDeskアプリストア | /k/market | アプリ | 必要 | アプリの作成方法選択、テンプレートからの追加 |
| プロセス管理設定 | /k/admin/app/status?app={appId} | アプリ管理 | 必要 | レコードの承認経路・ワークフロー設定 |
| ゲストスペース | /k/#/space/{id}（ゲストスペース） | スペース | 必要 | 社外ユーザーを招待して共同作業できるスペース |
| ゲストユーザー管理 | /k/admin/system/guest/#/ | 管理 | 必要 | ゲストユーザーのライセンス・一覧管理 |
| フォーム設計（フィールド設定） | /k/admin/app/flow?activate=0&app={appId} | アプリ管理 | 必要 | 25種のフィールドタイプの詳細設定ダイアログ |
| アプリ設定詳細 | /k/admin/app/{appId}/ → 設定タブ | アプリ管理 | 必要 | アクセス権、API、Webhook、カスタマイズ、通知等 |
| 一覧ビュー作成・編集 | /k/admin/app/{appId}/ → 一覧タブ | アプリ管理 | 必要 | 表形式/カレンダー/カスタマイズの一覧作成 |
| グラフ作成・編集 | /k/admin/app/{appId}/ → グラフタブ | アプリ管理 | 必要 | 9種のグラフ作成・プレビュー |
| CSV/Excel読み込み | アプリ一覧 → オプション → ファイルから読み込む | アプリ | 必要 | 4ステップのインポートウィザード |
| CSV書き出し | /k/{appId}/exportRecord?view={viewId} | アプリ | 必要 | CSVエクスポート設定画面 |
| 出力されたファイル | /k/downloadList?app={appId} | アプリ | 必要 | エクスポートファイルのダウンロード・管理 |
| メッセージ | /k/#/message/{id1};{id2} | メッセージ | 必要 | ユーザー間の1対1ダイレクトメッセージ |
| 検索結果 | /k/search?keyword={keyword} | 共通 | 必要 | 全体検索/アプリ内検索/スペース内検索の結果表示 |
| 集計結果（グラフ） | /k/{appId}/report?report={reportId} | アプリ | 必要 | レコードデータのグラフ・テーブル集計表示 |
| お知らせ掲示板編集 | /k/#/portal (モーダル) | ポータル | 必要 | ポータルお知らせ掲示板の編集（管理者のみ） |

## 画面遷移

- **ログイン → ポータル**: 認証成功後にリダイレクト
- **ポータル ↔ 各画面**: グローバルナビゲーション・サイドメニューから遷移
- **ポータル → スペース**: スペースウィジェットのリンクから遷移
- **ポータル → アプリ**: アプリウィジェットのリンクから遷移
- **スペース → アプリ**: スペース内アプリ一覧のリンクから遷移
- **アプリ一覧 → レコード詳細**: テーブル行クリックで遷移
- **アプリ一覧 → レコード追加**: 「レコードを追加する」ボタンで遷移
- **パンくずリスト**: アプリ画面では「ポータル > スペース > アプリ」の階層ナビゲーション

## 備考

- SPA構成: URLハッシュベースのルーティング（`#/portal`, `#/space/{id}`, `#/ntf/mention`, `#/people/user/{email}`）
- アプリ画面のみ通常のパスルーティング（`/k/{app_id}/`）
- スペース内のスレッド遷移はSPA内遷移（URLは変わらない）
