# デザイン方針

## 選定方向性

**Clean Neutral** — ミニマル・プロフェッショナル・余白重視

業務アプリケーションプラットフォームとして、コンテンツとデータが主役になるデザイン。装飾を最小限に抑え、情報の階層と余白でビジュアルヒエラルキーを構築する。

## 全体のトーン・雰囲気

- **静かで落ち着いた印象**: 派手な色やグラデーションを使わず、ニュートラルカラーと控えめなブルーアクセントで構成
- **プロフェッショナルだが冷たくない**: 適度な余白と丸み（`--radius-lg: 10px`）で柔らかさを保つ
- **コンテンツファースト**: UIクロム（ヘッダー、ボーダー、ボタン枠）は控えめにし、ユーザーが作成したデータや文章が視覚的に最も目立つ
- **信頼感**: 一貫したカラースケール、予測可能なレイアウト、安定した構造

## レイアウトの原則

### グリッド

- **最大幅**: `1400px`、中央配置
- **ページ左右パディング**: `--space-xl`（32px）
- **カラム構成**: 主要ページは2カラム（メイン 65% / サイドバー 35%）、カラム間ギャップ `--space-xl`
- **カード間ギャップ**: `--space-md`（16px）〜 `--space-lg`（24px）

### 余白

- **カード内パディング**: `--space-lg`（24px）を基準。コンパクトなウィジェットは `--space-md`（16px）
- **セクション間**: `--space-2xl`（48px）
- **余白は惜しまない**: 迷ったら狭くするより広くする

### カード

- **背景**: `--color-bg-card`（白）
- **ボーダー**: `1px solid var(--color-neutral-200)` — シャドウではなくボーダーで区切る
- **角丸**: `--radius-lg`（10px）
- **シャドウ**: 通常状態では使わない。ホバー時やフローティング要素（ドロップダウン、モーダル）にのみ `--shadow-md` を適用

## コンポーネントの方針

### グローバルヘッダー

- 白背景、下ボーダー `--color-neutral-200`
- 高さ `56px`
- ロゴ + ナビゲーション + 検索 + ユーザーアバターを横並び
- ナビリンクはホバーで `--color-bg-section` 背景、`--radius-md` 角丸
- スティッキー配置（`position: sticky; top: 0`）

### ボタン

- **プライマリ**: `--color-primary` 背景、白テキスト、`--radius-md` 角丸
- **セカンダリ**: 白背景、`--color-neutral-200` ボーダー、`--color-neutral-700` テキスト
- **テキストボタン/リンク**: `--color-primary` テキスト、背景なし
- **サイズ**: 高さ 32-36px、パディング `--space-sm` 〜 `--space-md`
- **フォント**: `--weight-medium`（500）、`--text-sm`

### テーブル

- ヘッダー行: `--color-bg-section` 背景、`--weight-medium` テキスト
- ボディ行: 白背景、下ボーダー `--color-neutral-200`
- ホバー: `--color-neutral-100` 背景
- セルパディング: `--space-sm` 縦 × `--space-md` 横
- テキスト: `--text-base`

### フォーム要素

- インプット: 白背景、`1px solid var(--color-neutral-300)` ボーダー、`--radius-sm` 角丸
- フォーカス: `--color-primary` ボーダー（2px）、`--color-primary-lighter` アウトラインリング
- ラベル: `--text-sm`、`--weight-medium`、`--color-neutral-600`
- プレースホルダー: `--color-neutral-400`

### ウィジェット（ポータルサイドバー）

- カード型、上部にウィジェットタイトル（`--text-lg`、`--weight-semibold`）
- フィルタードロップダウンとトグルはタイトル行に配置
- リスト項目は `--space-sm` パディング、下ボーダー区切り

## インタラクションの方針

- **ホバー**: 背景色変化（`--color-neutral-100`）+ `--transition-default`（0.15s）で滑らかに
- **フォーカス**: `2px solid var(--color-primary)` + `2px offset` のアウトライン。キーボードフォーカスは常に視認可能
- **アクティブ/押下**: 若干の明度低下（`--color-primary-dark`）
- **トランジション**: すべてのインタラクティブ要素に `--transition-default` を適用。急な変化を避ける
- **アニメーション**: ドロップダウン展開は `--transition-slow`（0.25s）。過度なアニメーションは使わない

## 画像・アイコンの方針

- **アイコン**: ラインアイコン（stroke-based）。太さ 1.5-2px。色は `--color-neutral-500` または `--color-primary`
- **アバター**: 丸型（`--radius-full`）、サイズ 28-36px、代替表示はイニシャル + `--color-primary-lighter` 背景
- **画像**: 角丸 `--radius-md` でクリップ
- **装飾画像**: 使わない。情報を伝えるための画像のみ

## アクセシビリティ

- **コントラスト比**: WCAG AA 準拠（通常テキスト 4.5:1 以上、大テキスト 3:1 以上）
  - 本文（`--color-neutral-800` on `--color-bg-card`）: 約 12:1 — 十分
  - セカンダリテキスト（`--color-neutral-500` on `--color-bg-card`）: 約 4.6:1 — AA クリア
  - リンク（`--color-primary` on `--color-bg-card`）: 約 4.5:1 — AA ギリギリクリア
- **フォーカスインジケーター**: すべてのインタラクティブ要素に可視的なフォーカスリングを表示
- **カラーのみに依存しない**: ステータスやエラーは色 + アイコン/テキストで表現

## スコープ外

以下はこのデザインフェーズでは扱わない:

- **ダークモード**: 将来的に対応可能な設計（CSS変数ベース）だが、今回は定義しない
- **レスポンシブ対応**: デスクトップ幅（1200px以上）を前提とする。モバイル対応は別フェーズ
- **マイクロインタラクション**: ローディングスピナー、スケルトンスクリーン等の詳細は実装フェーズで決定
- **ダークテーマのアプリ設定画面**: 管理画面のデザインテーマ切替機能自体は対象だが、ダークテーマのビジュアル定義はしない
