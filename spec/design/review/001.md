# レビュー #001: UX・一貫性・トークン準拠

Phase: /critique (Step 1)

## 全体的な印象

Clean Neutral の方向性は正しく反映されている。ミニマルで落ち着いたトーン、カード型レイアウト、控えめなブルーアクセント。ただし **13画面が4つの並列エージェントで作成されたため、画面間の一貫性に深刻な問題がある**。

## 対応が必要な問題

### P1: グローバルヘッダーが2パターン存在する（高）

**何が**: 画面によってヘッダーのCSS実装が完全に異なる（Pattern A / Pattern B）

| 項目 | Pattern A (portal, notifications, space, space-thread, people, message) | Pattern B (app-list, record-detail, record-form, search, app-settings, personal-settings) |
|------|------------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| wrapper class | `.header-inner` / `.global-header-inner` | `.header-inner` |
| nav markup | `<nav><a>` (flat) | `<nav><ul><li><a>` (list) |
| nav gap | `--space-xs` | `--space-md` |
| nav link padding | `--space-sm --space-md` | `--space-xs --space-sm` |
| search style | Pill型、SVGアイコン、neutral-50 bg | 角型、絵文字アイコン、card bg |
| search height | 36px | 34px |
| avatar | border あり、`--color-primary-darker` | border なし、`--color-primary-dark` |

**なぜ重要か**: プロダクトとして統一感がない。ページ遷移で明らかに違和感が出る。
**修正**: Pattern A をベースに全画面のヘッダーを統一する。

### P2: `color: white` がハードコードされている（中）

**何が**: ボタンテキスト等で `color: white` がそのまま使われている（全13ファイル）
**なぜ重要か**: トークンシステムの一貫性が崩れる。ダークモード対応時に問題になる。
**修正**: `--color-on-primary: oklch(1.0 0 0)` トークンを追加し、全ファイルで参照する。

### P3: 未定義のOKLCH値がハードコードされている（中）

**何が**: `oklch(0.93 0.03 250)` が portal.html と notifications.html の `.notification-item.unread:hover` で使用。トークンに定義なし。
**修正**: `--color-primary-lighter` を使うか、新トークンを追加する。

### P4: 6px padding が頻出（低）

**何が**: `padding: 6px` がトークンにない値だが、ボタンやツールバーで頻出。
**修正**: `--space-xs`(4px) か `--space-sm`(8px) に寄せるか、`--space-1.5: 6px` トークンを追加。

### P5: フォントサイズ 10px がトークン範囲外（低）

**何が**: space-thread.html、app-settings.html で `font-size: 10px` 使用。`--text-xs` の最小値(11px)より小さい。
**修正**: `--text-xs` を使用する。

## 修正対象

- [x] P1: グローバルヘッダー統一 → 全13ファイルをPattern A（portal.html基準）に統一
- [x] P2: `--color-on-primary` トークン追加 → 全13ファイルで `color: white` → `var(--color-on-primary)` に修正、tokens.md にも追加
- [x] P3: 未定義OKLCH値の置換 → portal.html, notifications.html の `oklch(0.93 0.03 250)` → `var(--color-primary-lighter)` に修正
- [ ] P4: 6px padding（軽微、実装フェーズで対応可）
- [ ] P5: 10px font-size（軽微、実装フェーズで対応可）
