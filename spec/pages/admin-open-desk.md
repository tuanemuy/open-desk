# OpenDeskシステム管理

- URL: `/k/admin/system/`
- 認証: 必要（システム管理者権限）
- セクション: 管理

## 目的

OpenDesk全体のシステム設定を管理する画面。アプリ管理、スペース管理、ゲストユーザー管理、アクセス権、カスタマイズ等を設定する。

## アクセス方法

ヘッダーの歯車アイコン（設定ボタン） → 「OpenDeskシステム管理」

## アプリ管理

ライセンス使用状況と管理権限のあるアプリの一覧を確認する画面。

| 項目名 | 型 | 説明 |
|--------|-----|------|
| ライセンスの使用状況 | テーブル | アプリ数（上限1000）、1アプリの1日APIリクエスト数（上限10000）、カスタマイズ可能アプリ数 |
| アプリの一覧 | テーブル | ID、アプリ名、設定、所属スペース、アプリグループ、ステータス、レコードの最終更新日、レコード数、フィールド数、1日のAPIリクエスト数、APIトークン数、Webhook数、参照しているアプリ数、添付ファイル、カスタマイズ有無、アクセス可能な通常ユーザー数、ゲストユーザー数、アプリ管理者数、作成者、作成日時、設定の最終更新者、設定の最終更新日時 |
| CSV形式でダウンロードする | ボタン | アプリ一覧をCSVで出力 |
| 手動更新データを取得 | ボタン | 一部カラムのデータを取得 |

|--------|-----|------|

| アプリグループの管理 | チェックボックス | アプリグループの管理権限 |
| アプリの作成 | チェックボックス | アプリ作成権限（デフォルトEveryoneに許可） |
| アプリの管理 | チェックボックス | アプリ管理権限（デフォルトEveryoneに許可） |
| スペースの作成 | チェックボックス | スペース作成権限（デフォルトEveryoneに許可） |
| ゲストスペースの作成 | チェックボックス | ゲストスペース作成権限 |

| スマートフォン用のJavaScriptファイル | ファイル追加 | URL指定またはアップロード（最大20MB） |
| PC用のCSSファイル | ファイル追加 | URL指定またはアップロード（最大20MB） |
| スマートフォン用のCSSファイル | ファイル追加 | URL指定またはアップロード（最大20MB） |

## 特記事項

- ヘッダーメニューの「設定」ボタンからアクセスする（歯車アイコン）
- cybozu.com共通管理者には全権限が自動付与される
- OpenDesk AI関連の検討中機能がいくつか存在（AIにアプリ設定をレビュー、AIでアプリ検索等）
