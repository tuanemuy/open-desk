# ピープル（プロフィール）

- URL: `/k/#/people/user/{email}`
- 認証: 必要
- セクション: ピープル

## 目的

ユーザーの個人プロフィール表示とステータス的な書き込み（投稿）機能を提供する。

## レイアウト

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー（検索は「全体検索」） |
| プロフィールヘッダー | ユーザー名(h2)、メールアドレス、プロフィール詳細リンク、カバー画像設定リンク、プロフィール編集リンク |
| 投稿エリア | 投稿フォーム（フォーカスで展開するリッチテキストエディタ） |

## 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| 投稿テキスト | リッチテキストエディタ | - | - | フォーカスで展開、プレースホルダ「投稿する」 |

投稿フォームツールバー: 宛先指定、ファイル添付、絵文字、太字、斜体、下線、文字色、背景色、文字サイズ、リンク、元に戻す/やり直す、リスト、左/中央揃え、フォーマット削除

## アクション

| ラベル | 種類 | 動作 | 備考 |
|--------|------|------|------|
| プロフィール詳細 | link | cybozu.comアカウント設定画面に遷移（別画面） | |
| カバー画像を設定する | link | カバー画像設定ダイアログ（モーダル） | 自分のページのみ |
| プロフィールを編集する | link | cybozu.comアカウント設定画面に遷移（別画面） | 自分のページのみ |
| フォロー | link | フォロー/フォロー解除のトグル | 他ユーザーのページのみ |
| 個人メッセージ | link | メッセージ画面（`/k/#/message/{id1};{id2}`）に遷移 | 他ユーザーのページのみ |
| キャンセル | button | 投稿フォーム閉じ | |
| 書き込む | button | 投稿実行 | |

## カバー画像設定ダイアログ（モーダル）

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| ファイル選択 | file input | - | 最大5MB | 画像ファイルアップロード |

アクション: 参照/ファイルを選択 / キャンセル / 保存 / Close

## プロフィール詳細（cybozu.comアカウント設定）

「プロフィール詳細」「プロフィールを編集する」は両方ともcybozu.comの同一アカウント設定画面に遷移。

### 表示セクション

| セクション | 項目 |
|-----------|------|
| コメント | 自分用メモ/メッセージ（「変更」ボタンで編集） |
| 基本情報 | 表示名、名前、よみがな、組織、誕生日、入社日、従業員ID、タイムゾーン、言語 |
| 連絡先情報 | メールアドレス、携帯電話、電話番号、内線 |
| その他 | 別言語での表示名、URL、利用中のサービス |

### サイドバーナビゲーション

- プロフィール
- ログイン名とパスワード
- モバイルからのアクセス
- ログイン履歴

## 状態・表示切替

| 条件 | 表示変化 |
|------|---------|
| 自分のプロフィールページ | 「カバー画像を設定する」「プロフィールを編集する」リンクが表示。「フォロー」「個人メッセージ」は非表示 |
| 他ユーザーのプロフィールページ | 「フォロー」リンクと「個人メッセージ」リンクが表示。「カバー画像を設定する」「プロフィールを編集する」は非表示 |
| 投稿フォームにフォーカス | リッチテキストエディタが展開（ツールバー + テキストエリア + キャンセル/書き込むボタン表示） |
| フォーカス外 | プレースホルダ表示のみ |

## 備考

- 他ユーザーのページに「フォロー」リンクが存在する（クリックでフォロー/フォロー解除のトグル動作）
- 他ユーザーのページに「個人メッセージ」リンクが存在し、クリックでメッセージ画面（`/k/#/message/{id1};{id2}`）に遷移する
