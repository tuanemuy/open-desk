# 個人設定

- セクション: 設定

## 目的

ユーザー自身のプロフィール、パスワード、通知設定等を管理する画面群。cybozu.comアカウント設定とOpenDesk個人設定の2階層に分かれる。

---

## cybozu.comアカウント設定

- URL: `/settings/profile`
- アクセス方法: ヘッダー右上のアカウントメニューボタン → 「アカウント設定」

### メニュー構成（左サイドナビ）

| メニュー名 | URL | 目的 |
|---|---|---|
| プロフィール | `/settings/profile` | 基本情報・連絡先等の編集 |
| ログイン名とパスワード | `/settings/auth` | ログイン名表示、パスワード変更 |
| モバイルからのアクセス | `/settings/remote` | モバイルアプリの設定情報送信 |
| ログイン履歴 | `/settings/session` | 有効セッション管理・ログイン履歴閲覧 |

### プロフィール画面

UIパターン: セクションごとに「変更」ボタンがあり、クリックするとインライン編集フォームが展開される。「保存」「キャンセル」ボタンで閉じる。

#### コメント

| 項目名 | 型 | 必須 | 制約 | 説明 |
|---|---|---|---|---|
| コメント | textarea | 任意 | 自由入力 | 自分用メモやプロフィール閲覧者へのメッセージ |

### ログイン名とパスワード画面

- URL: `/settings/auth`

| 項目名 | 型 | 必須 | 制約 | 説明 |
|---|---|---|---|---|
| ログイン名 | 表示のみ | - | - | 現在のログイン名（メールアドレス） |
| 現在のパスワード | password | 必須 | 自由入力 | パスワード変更時の認証用 |
| 新しいパスワード | password | 必須 | 自由入力 | 新しいパスワード |
| 新しいパスワード（確認用） | password | 必須 | 自由入力 | 確認入力 |

### モバイルからのアクセス画面

- URL: `/settings/remote`

| 項目名 | 型 | 必須 | 制約 | 説明 |
|---|---|---|---|---|
| アプリ選択: OpenDeskモバイル | checkbox | 任意 | - | 利用するモバイルアプリの選択 |
| メールアドレス | textbox | 必須 | 自由入力 | 設定情報の送信先 |
| メールアドレス（確認用） | textbox | 必須 | 自由入力 | 確認入力 |

手順は4ステップで説明（ダウンロード → アプリ選択 → メール送信 → ログイン）。

## OpenDesk個人設定

- URL: `/k/settings?id=1`
- アクセス方法: ヘッダーの歯車アイコン → 「個人設定」
- 説明: 「時刻表記やメール通知の設定を行うことができます。ここで保存した設定は自分だけに適用されます。」

| 項目名 | 型 | 必須 | 選択肢 | デフォルト | 説明 |
|---|---|---|---|---|---|
| 時刻表記 | dropdown(button) | 任意 | 12時間表記 / 24時間表記 | 24時間表記 | 時刻の表示形式 |
| メール通知 | radio | 任意 | 受信する / 受信しない | 受信する | メール通知の有効/無効 |
| メール通知の対象 | radio | 任意 | 自分宛の通知のみ / すべての通知 | 自分宛の通知のみ | 通知対象の範囲（メール通知「受信する」時のサブ設定） |
| メール通知の形式 | radio | 任意 | HTML形式 / テキスト形式 | HTML形式 | メール通知の形式（メール通知「受信する」時のサブ設定） |
| デスクトップ通知 | radio | 任意 | 有効にする / 無効にする | 無効にする | ブラウザのデスクトップ通知 |

- 明示的な「保存」ボタンは存在しない（設定変更は即時反映、auto-save）
- デスクトップ通知はGoogle ChromeまたはMicrosoft Edgeでのみ利用可能
- システム管理者がメール通知機能を無効にしている場合、メール通知関連の設定は非表示
- 「戻る」ボタンでポータルに戻る

## 共通UIパターン

| パターン | 説明 |
|---|---|
| セクション + 「変更」ボタン → インライン編集 | cybozu.comプロフィール画面で共通。各セクションが閲覧モードと編集モードを持つ |
| 管理者管理項目の disabled 表示 | 表示名、名前、よみがな、メールアドレス等はdisabledのテキストボックスとして表示 |
| DescriptionList (dl/dt/dd) | プロフィール情報の一覧表示 |
| ラジオボタングループ | OpenDesk個人設定の通知設定。fieldset+legendで囲む |
| カスタムドロップダウン(button型) | 時刻表記。HTMLのselect要素ではなくbuttonとlistboxの組み合わせ |
| Date Picker（カレンダー） | 誕生日・入社日。ダイアログ型カレンダー |
