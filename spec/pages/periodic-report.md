# 定期レポート

- 位置: アプリ設定 > グラフ編集画面 > 定期レポートセクション
- 認証: 必要
- セクション: アプリ > 設定 > グラフ

## 目的

グラフの集計結果を定期的にスナップショットとして自動記録し、過去の推移を閲覧可能にする機能。メール配信機能ではない。

## 設定の場所

グラフ編集画面の**最下部**に独立セクションとして配置。グラフ名・集計方法・プレビューの下に「定期レポート」セクション（h3見出し）がある。

## 設定項目（初回設定時）

| 項目名 | 型 | デフォルト | 備考 |
|--------|------|-----------|------|
| 集計結果を定期的に記録する | checkbox | OFF | 有効にすると詳細設定が展開 |
| 集計間隔 | dropdown | 毎月 | 毎年/毎四半期/毎月/毎週/毎日/毎時 |
| 日付/曜日/分（サブ項目） | dropdown | 間隔による | 集計間隔に応じて動的表示（後述） |
| 時刻 | 時(spinbutton) + 分(spinbutton) | 空（必須） | 毎時以外で表示 |
| タイムゾーン表示 | 静的テキスト | - | 「(UTC+00:00) GMT」 |
| 次回集計日時 | 静的テキスト | - | UTC + ローカルTZ表示。時刻設定後に表示 |

### 注意文

「記録された集計結果が30件を超えると、古い記録が削除されます。定期レポートを一度有効にすると、このグラフの設定は変更できなくなります。」

## 集計間隔ごとの動的UI

| 集計間隔 | サブ項目1 | サブ項目2 | 時刻 |
|----------|-----------|-----------|------|
| 毎年 | 日付テキスト入力 + 日付選択ボタン | - | 時:分 |
| 毎四半期 | 四半期月選択（3択） | 日選択（1日〜31日+末日） | 時:分 |
| 毎月 | 日選択（1日〜31日+末日） | - | 時:分 |
| 毎週 | 曜日選択（日〜土） | - | 時:分 |
| 毎日 | - | - | 時:分 |
| 毎時 | 分選択（00/10/20/30/40/50分、10分刻み） | - | なし |

### 四半期月の選択肢

- 1月 4月 7月 10月
- 2月 5月 8月 11月
- 3月 6月 9月 12月

### 日の選択肢

1日〜31日 + 末日（計32オプション）

## 有効化後のUI変化

定期レポートを保存後に再度編集画面を開くと、UIが変化する:

| 変更点 | 説明 |
|--------|------|
| チェックボックス → ラジオボタン | 「実行中」/「停止中」の切替に変化 |
| グラフ名 | **唯一の編集可能項目** |
| その他の全設定項目 | **disabled（変更不可）** |

## 閲覧側のUI（レポート表示画面）

定期レポートが有効なグラフを選択すると、通常のグラフ表示に加えて以下のUIが追加:

| 要素 | 型 | 説明 |
|------|------|------|
| 「集計日：」ラベル | テキスト | 定期レポート固有 |
| 開始日 | dropdown | 記録済み集計日から選択（未記録時は「--」） |
| 「から」 | テキスト | 期間セパレーター |
| 終了日 | dropdown | 記録済み集計日から選択（未記録時は「--」） |

## バリデーション

| 条件 | エラーメッセージ |
|------|-----------------|
| 時刻が未設定 | 「必須です。」（赤背景インラインエラー + 画面上部alertバナー） |
| 毎年の日付が未設定 | 「必須です。」 |
