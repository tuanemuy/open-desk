# ゲストスペース

- セクション: スペース
- 認証: 必要

## 目的

社外ユーザー（ゲストユーザー）を招待して社内メンバーと共同作業できるスペース機能。通常スペースとは別枠で管理され、ライセンス・権限・認証がすべて独立している。

## 通常スペースとの違い

| 項目 | 通常スペース | ゲストスペース |
|---|---|---|
| 公開設定 | 公開/非公開を選択可能 | 常に非公開（変更不可） |
| メンバー | 社内ユーザーのみ | 社内ユーザー + ゲストユーザー |
| ライセンス枠 | スペース数（上限500） | ゲストスペース数（上限500、別枠） |
| 作成権限 | 「スペースの作成」権限（デフォルトEveryone ON） | 「ゲストスペースの作成」権限（デフォルトEveryone OFF） |
| ゲストユーザーライセンス | 不要 | 「OpenDesk ゲストユーザー」として別契約が必要 |

## ゲストスペース作成フロー

### アクセス方法

ポータル → スペースウィジェットの「+」ボタン → 「ゲストスペースを作成」

### 作成ダイアログ

「ゲストスペースの作成」ダイアログが表示。「はじめから作る」またはテンプレートを選択。

### 基本設定タブ

| 項目名 | 型 | 必須 | 説明 |
|---|---|---|---|
| スペース名 | テキスト入力 | 必須 | スペースの名前 |
| 非公開 | チェックボックス | - | 常にON/変更不可（disabled） |
| スペースのポータルと複数のスレッドを使用する | チェックボックス | 任意 | マルチスレッド形式にするか（デフォルトOFF） |
| スペースの参加/退会、スレッドのフォロー/フォロー解除を禁止する | チェックボックス | 任意 | メンバーの自由な参加/退会を制限（デフォルトOFF） |
| アプリ作成できるユーザーをスペースの管理者に限定する | チェックボックス | 任意 | アプリ作成権限を管理者に限定（デフォルトOFF） |
| カバー画像 | 画像選択 | 任意 | プリセット画像（28種類）またはファイルアップロード（最大5MB） |

### 参加メンバータブ

| 項目名 | 型 | 説明 |
|---|---|---|
| 組織やグループから選択 | リンク/ボタン | 組織・グループ単位でメンバーを追加 |
| ユーザー検索 | テキスト入力 | ユーザー名で検索して追加（ゲストユーザーも追加可能） |
| メンバー一覧テーブル | テーブル | ユーザー/組織/グループ、管理者（チェックボックス）、下位組織も含める、削除 |

## ゲストユーザー管理

- URL: `/k/admin/system/guest/#/`
- アクセス: OpenDeskシステム管理 → ゲストユーザー管理

### ライセンスの使用状況

| 項目名 | 型 | 説明 |
|---|---|---|
| 試用期間中のゲストユーザー数 | 数値（表示のみ） | 試用中のゲストユーザー数 |
| 有料ゲストユーザー数 | 数値（表示のみ） | 課金対象のゲストユーザー数 |
| 有料ゲストユーザー数の契約数 | 数値（表示のみ） | ゲストユーザーライセンスの契約数 |

自社のOpenDeskアカウントをゲストアカウントと共通化したゲストユーザーは、有料ゲストユーザー数にカウントされない。

### ゲストユーザー一覧

| カラム名 | 型 | 説明 |
|---|---|---|
| 編集ボタン | ボタン | 各ゲストユーザーの設定変更画面へ |
| 会社 | テキスト | ゲストユーザーの所属会社 |
| 名前 | テキスト | ゲストユーザーの氏名 |
| メールアドレス | テキスト | ログイン用メールアドレス |
| ステータス | テキスト | 利用状態（有効/停止等） |
| 最終ログイン日時 | 日時 | 最後にログインした日時 |
| 所属するゲストスペース | テキスト | 参加しているゲストスペース名 |
| ライセンス | テキスト | ライセンスの種類/状態 |
| 試用期限 | 日時 | 試用期間の期限 |
| CSV形式でダウンロードする | ボタン | 一覧をCSVで出力 |

### ゲストユーザー追加方法

- ゲストスペースの設定画面からメールアドレスで招待する方式
- 管理画面自体にはゲストユーザーの直接追加UIはない

---

## ゲストユーザーの認証

- URL: `/k/admin/system/guestauth/`

| 項目名 | 型 | 説明 |
|---|---|---|
| ゲストユーザーの認証に二段階認証を利用する | チェックボックス | 有効にするとログイン時にメールで確認コードを送信（デフォルトOFF） |

認証方式:
- 通常: メールアドレス + パスワード
- 二段階認証: 上記 + メールベースのワンタイムコード

---

## ゲストユーザーの権限制限

| 項目 | 通常ユーザー | ゲストユーザー |
|---|---|---|
| ポータルへのアクセス | 可 | 不可 |
| 通常スペースへのアクセス | 可 | 不可 |
| ゲストスペースへのアクセス | 可 | 参加しているゲストスペースのみ |
| アプリへのアクセス | 全てのアプリ（権限に応じて） | ゲストスペース内のアプリのみ |
| ピープル機能 | 利用可 | 利用不可 |
| 全体検索 | 利用可 | 利用不可（スペース内検索のみ） |
| スペースの作成 | 可（権限に応じて） | 不可 |
| OpenDeskシステム管理 | 可（管理者のみ） | 不可 |

## 特記事項

- OpenDeskシステム管理 > 利用する機能の選択 で「ゲストスペース機能を利用する」チェックボックスにより機能全体を無効化/有効化可能（デフォルトON）
- スペーステンプレートはゲストスペースにも適用可能
