# フィールドタイプ詳細設定

- URL: `/k/admin/app/flow?activate=0&app={appId}` (フォーム設計画面)
- 認証: 必要（アプリ管理者権限）
- セクション: アプリ管理

## 目的

アプリのフォーム設計画面で各フィールドを配置する際に、フィールドごとの詳細設定を行う。ダブルクリックまたは設定アイコン（歯車）からダイアログを開く。

---

## フィールドパレット構成

フォーム設計画面の左パネルにフィールドパレットが表示される。3カテゴリに分類。

### カテゴリ1: データフィールド（20種）

2列配置:

| 左列 | 右列 |
|------|------|
| ラベル | 文字列（1行） |
| リッチエディター | 文字列（複数行） |
| 数値 | 計算 |
| ラジオボタン | チェックボックス |
| 複数選択 | ドロップダウン |
| 日付 | 時刻 |
| 日時 | 添付ファイル |
| リンク | ユーザー選択 |
| 組織選択 | グループ選択 |
| 関連レコード一覧 | ルックアップ |

### カテゴリ2: レイアウト・構造フィールド（4種）

| 左列 | 右列 |
|------|------|
| スペース | 罫線 |
| グループ | テーブル |

### カテゴリ3: システムフィールド（5種）

| 左列 | 右列 |
|------|------|
| レコード番号 | 作成者 |
| 作成日時 | 更新者 |
| 更新日時 | |

## 全フィールド共通の設定項目

全フィールドに共通して存在（レイアウト要素を除く）:

| 項目名 | 型 | 説明 |
|--------|------|------|
| フィールド名 | テキスト入力（必須） | フォーム上に表示されるラベル |
| フィールド名を表示しない | チェックボックス（デフォルトOFF） | フォーム上でラベルを非表示にする |
| フィールドコード | テキスト（自動生成・編集可能リンク付き、必須） | API等で使用する内部識別子 |

ダイアログ下部には「ヘルプ」リンク、「キャンセル」「保存」ボタンが常に表示。

| 必須項目にする | チェックボックス | OFF | |

| 文字数（最小） | テキスト入力（整数） | 空 | |
| 文字数（最大） | テキスト入力（整数） | 空 | |
| 初期値 | テキスト入力 | 空 | |

### 文字列（複数行）

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 必須項目にする | チェックボックス | OFF | |

### リッチエディター

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|

| 初期値 | リッチテキストエディター | 空 | ツールバー付きWYSIWYGエディター |

初期値エディターのツールバー: 太字、斜体、下線、文字色、背景色、文字サイズ（普通がデフォルト）、リンク、リスト、インデント、配置、取り消し線、フォーマット削除

### 数値

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 桁区切りを表示する | チェックボックス | OFF | 1,000のようにカンマ区切り |
| 必須項目にする | チェックボックス | OFF | |
| 値の重複を禁止する | チェックボックス | OFF | |
| 値の制限（最小） | テキスト入力（整数） | 空 | |
| 値の制限（最大） | テキスト入力（整数） | 空 | |
| 初期値 | テキスト入力 | 空 | |
| 小数点以下の表示桁数 | テキスト入力 | 空 | |
| 単位記号 | テキスト入力 | 空 | 例: ¥, km, 円 |
| 単位記号の位置 | ラジオボタン | 前に付ける | 「前に付ける（例：¥100）」/「後ろに付ける（例：100km）」 |

### 計算

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 計算式 | コンボボックス/式エディター（必須） | 空 | 「関数を挿入する」「フィールドコードを挿入する」ボタン付き |
| 計算式を表示しない | チェックボックス | OFF | |
| 表示形式 | ラジオボタン（7択） | 数値（例：1000） | 下記参照 |
| 小数点以下の表示桁数 | テキスト入力 | 空 | |
| 単位記号 | テキスト入力 | 空 | |
| 単位記号の位置 | ラジオボタン | 前に付ける | |

**表示形式の選択肢**:
1. 数値（例：1000）— デフォルト
2. 数値（例：1,000）— 桁区切りあり
3. 日時（例：2012-08-06 2:03）
4. 日付（例：2012-08-06）
5. 時刻（例：2:03）
6. 時間（例：26時間3分）
7. 時間（例：1日2時間3分）

ヘルプリンク: 「計算式の書き方」「利用できる関数」「便利に使おうガイドブック vol.02 計算編」

## 選択系フィールド

### ラジオボタン

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 項目と順番 | テキスト入力リスト（並び替え可能） | sample1, sample2 | 各項目に「追加する」「削除する」リンク付き |
| 並び | ラジオボタン | 横 | 「横」/「縦」 |
| 初期値 | ドロップダウン | sample1 | 項目リストから選択 |

特記: 「必須項目にする」がない（必ず1つ選択される）。初期値は最初の項目がデフォルト。

### チェックボックス

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 必須項目にする | チェックボックス | OFF | |
| 項目と順番 | テキスト入力リスト（並び替え可能） | sample1, sample2 | 各項目に追加/削除リンク付き |
| 並び | ラジオボタン | 横 | 「横」/「縦」 |
| 初期値 | チェックボックスリスト | 全てOFF | 複数選択可能 |

### 複数選択

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 必須項目にする | チェックボックス | OFF | |
| 項目と順番 | テキスト入力リスト（並び替え可能） | sample1〜sample4 | 各項目に追加/削除リンク付き |
| 初期値 | チェックボックスリスト | 全てOFF | 複数選択可能 |

特記: チェックボックスと異なり「並び」設定がない。表示形式はリストボックス型。デフォルト項目数が4つ。

### ドロップダウン

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 必須項目にする | チェックボックス | OFF | |
| 項目と順番 | テキスト入力リスト（並び替え可能） | sample1, sample2 | 各項目に追加/削除リンク付き |
| 初期値 | ドロップダウン | ----- | 未選択状態「-----」がデフォルト |

特記: ラジオボタンと異なり未選択状態（-----）が可能。

## システムフィールド

### レコード番号

共通設定（フィールド名 + フィールドコード）のみ。自動採番。

### 作成者 / 作成日時 / 更新者 / 更新日時

共通設定（フィールド名 + フィールドコード）のみ。自動入力。「複製」メニューなし。フォームに配置しなくても一覧やAPIでは自動的に利用可能。
