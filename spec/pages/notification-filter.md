# 通知の絞り込み

- URL: `/k/#/ntf/mention`（通知一覧画面内）
- 認証: 必要
- セクション: 通知

## 目的

通知の表示フィルタリング条件をカスタム作成し、通知の表示を絞り込む機能。

## アクセス方法

通知一覧画面上部のドロップダウン（デフォルト「自分宛」）をクリック → メニュー最下部の「絞り込みを作成する」をクリック。

## ドロップダウンメニュー構成

| 項目 | 種類 | 備考 |
|------|------|------|
| 自分宛 | ビルトイン | デフォルト選択 |
| あとで読む | ビルトイン | - |
| すべて | ビルトイン | - |
| (カスタム絞り込み) | ユーザー作成 | 「編集」「削除」リンク付きでインライン表示 |
| 絞り込みを作成する | アクション | 最下部に常時表示 |

## 絞り込み設定ダイアログ

モーダルダイアログとして表示。タイトル「絞り込みの設定」。編集時も同じダイアログが既存値プリフィルで開く。

### レイアウト（上から順に）

1. タイトル「絞り込みの設定」+ Close(x)ボタン
2. 絞り込み名テキストボックス
3. 通知の種類ラジオボタン
4. 場所で絞り込むラジオボタン + 場所条件行
5. 送信者で絞り込むセクション
6. キャンセル / 保存ボタン

### 設定項目

| 項目名 | 型 | 必須 | 選択肢 | 備考 |
|--------|------|------|--------|------|
| 絞り込み名 | テキスト | はい | - | 1〜100文字。プレースホルダ「絞り込み名を入力」 |
| 通知の種類 | ラジオ | - | **すべて**（デフォルト）, 自分宛 | - |
| 場所で絞り込む | ラジオ | - | **すべての通知を表示する**, 次の場所からの通知だけ表示（デフォルト）, 次の場所からの通知を除外 | 「すべて」選択時は場所条件行が非表示 |
| 場所条件 - 種類 | dropdown | - | **アプリ**（デフォルト）, スペース, ピープル, メッセージ | 場所フィルター有効時のみ表示 |
| 場所条件 - 対象 | combobox（検索） | - | 種類に応じて「すべてのアプリ」「すべてのスペース」等 | インクリメンタルサーチ |
| 場所条件 - 追加(+) | ボタン | - | - | 複数行追加可能。異なる種類を混在可能 |
| 場所条件 - 削除(-) | ボタン | - | - | 2行以上ある場合に表示 |
| 送信者 - ユーザー検索 | テキスト | - | - | プレースホルダ「ユーザーを検索」+ 検索アイコン |
| 送信者 - 組織やグループから選択 | リンク | - | - | 「ユーザーを選択」サブダイアログを開く |

### ユーザーを選択サブダイアログ

| 要素 | 説明 |
|------|------|
| タブ | 「組織」「グループ」 |
| 左ペイン | 組織/グループの一覧 |
| 右ペイン | 選択組織/グループ内のユーザー一覧 |
| すべて選択 | チェックボックス |
| ボタン | 「キャンセル」「追加」 |

## アクション

| ラベル | 動作 |
|--------|------|
| 保存 | バリデーション通過後に保存。ダイアログが閉じ、作成した絞り込みが適用される |
| キャンセル | ダイアログを閉じる（変更破棄） |
| Close(x) | ダイアログを閉じる |

## バリデーション

| 条件 | エラーメッセージ |
|------|-----------------|
| 絞り込み名が空 | 「1文字以上、100文字以下である必要があります。必須です。」 |

エラー発生時はダイアログ上部に「エラー」トーストが表示され、該当フィールドが赤枠でハイライト。

## 絞り込みの管理

### 編集

ドロップダウン内のカスタム絞り込み横の「編集」リンク → 「絞り込みの設定」ダイアログが既存設定値プリフィルで開く。

### 削除

ドロップダウン内の「削除」リンク → **ドロップダウン内にインラインで**「キャンセル」と「削除する」（赤ボタン）が表示。「削除する」クリックで即座に削除され、フィルタが「自分宛」にリセット。

ビルトインの絞り込み（自分宛、あとで読む、すべて）には編集・削除リンクは表示されない。
