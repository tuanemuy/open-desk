# 通知一覧

- URL: `/k/#/ntf/mention`
- 認証: 必要
- セクション: 通知

## 目的

ユーザー宛の通知を一覧表示・管理する。フィルタリングと表示モード切替が可能。

## レイアウト

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー（共通） |
| ページタイトル | 「通知」(h2) |
| フィルタバー | フィルタ選択 + 未読/既読切替 |
| オプションバー | 「通知にボタンを常に表示する」チェック + 詳細/一覧表示切替 |
| メインコンテンツ | 通知リスト（または「通知はありません。」） |

## 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| 表示する通知を切り替える | listbox | - | - | 選択肢: 「自分宛」(初期)、「あとで読む」、「すべて」、「絞り込みを作成する」 |
| 未読/既読 | toggle | - | - | 「未読」がデフォルト選択 |
| 通知にボタンを常に表示する | checkbox | - | - | checked=false（初期） |

## アクション

| ラベル | 種類 | 動作 | 備考 |
|--------|------|------|------|
| 詳細表示 | link | 通知を詳細モードで表示（左に通知リスト、右にiframe内コンテンツ表示） | |
| 一覧表示 | link | 通知をコンパクトモードで表示（デフォルト） | |
| 絞り込みを作成する | option | カスタムフィルタ作成画面へ | フィルタlistbox内のオプション |

## 各通知アイテムのアクション

| ラベル | 種類 | 動作 |
|--------|------|------|
| あとで読む | button(icon) | 「あとで読む」フラグをトグル |
| 既読にする / 未読にする | button(image) | 既読/未読状態をトグル |

## 詳細表示モードのレイアウト

詳細表示モードでは画面が2ペインに分割される:
- **左ペイン**: 通知リスト（menuitemradio形式、選択状態を持つ）
- **右ペイン**: 選択した通知の詳細コンテンツ（iframe内に元画面の内容を表示。例: ファイル書き出し通知では出力ファイル一覧テーブルが表示）
- 上部にパンくずリスト的なリンクチェーン（スペース名 > アプリ名 > 通知タイプ）が表示

## 状態・表示切替

| 条件 | 表示変化 |
|------|---------|
| URL `/k/#/ntf/mention` | フィルタ「自分宛」が初期選択 |
| フィルタ「すべて」選択 | 全通知を表示 |
| フィルタ「自分宛」選択 | @メンション通知のみ表示 |
| フィルタ「あとで読む」選択 | あとで読むフラグ付き通知のみ |
| 未読トグル選択 | 未読通知のみ表示 |
| 既読トグル選択 | 既読通知のみ表示 |
| 詳細表示選択 | 通知をリッチ表示（プレビュー付き）に切替 |
| 一覧表示選択 | 通知をコンパクトリスト表示に切替 |
| 通知がない場合 | 「通知はありません。」テキスト表示 |
