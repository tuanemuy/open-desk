# レコードのコメント機能

- URL: `/k/{appId}/show#record={recordId}` （コメントタブ）
- 認証: 必要
- セクション: アプリ > レコード詳細

## 目的

レコードに対してチームメンバーがコメントでコミュニケーションを取る機能。レコード詳細画面下部のタブパネルで提供される。

## レイアウト

レコード詳細画面の下部に配置。タブ切替パネルで「コメント」と「変更履歴」の2タブ構成。

| 要素 | 位置 | 説明 |
|------|------|------|
| タブバー | エリア上部 | 「コメント」タブ（デフォルト選択）と「変更履歴」タブ |
| コメント投稿フォーム | タブ直下 | 折りたたみ式。未展開時はプレースホルダー「コメントする」が表示 |
| コメント一覧 | フォームの下 | 投稿されたコメントのリスト表示。空の場合「コメントはありません。」 |

## 投稿フォーム

### 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|------|------|----------------|------|
| コメント入力欄 | textbox（contenteditable相当） | はい | 空欄は投稿不可（サイレント） | プレースホルダー「コメントする」。複数行入力可能 |
| 宛先指定 | ツールバーボタン | いいえ | - | クリックで入力欄に「@」が挿入される |

**注意**: 添付ファイル機能はコメント投稿フォーム内には存在しない（メッセージやスレッドのリッチテキストエディタとは異なる）。

### アクション

| ラベル | 種類 | 動作 |
|--------|------|------|
| 書き込む | ボタン | コメントを投稿 |
| キャンセル | ボタン | 入力内容を破棄してフォームを折りたたむ |

## コメント表示

各コメントは以下の要素で構成される。

| 要素 | 説明 |
|------|------|
| コメント番号 | 先頭に「1:」のような通し番号 |
| 投稿者名 | ボタン形式。クリックでプロフィールダイアログ表示 |
| 投稿日時 | リンク形式。時刻表示（例: "1:15"）。クリックで該当コメントへのアンカー |
| コメント本文 | プレーンテキスト表示 |
| アクションエリア | いいね数リンク、いいね！ボタン、返信、全員に返信、リンク、削除 |

### 投稿者プロフィールダイアログ

投稿者名ボタンをクリックすると表示される。

| 要素 | 説明 |
|------|------|
| プロフィール画像 | ユーザーアバター |
| ユーザー名 | - |
| 「ピープル」リンク | ピープル画面へ遷移 |
| 「プロフィール詳細」リンク | プロフィール詳細へ遷移 |

## コメントアクション

| ラベル | 種類 | 動作 |
|--------|------|------|
| いいね！ | ボタン（トグル） | コメントに「いいね」を付与。クリック後「いいね！を取り消す」に切替 |
| いいね！を取り消す | ボタン（トグル） | いいねを取り消す |
| いいね数リンク | リンク | クリックで「いいね！と言っている人」ポップアップ表示 |
| 返信 | ボタン | 投稿フォームを展開し、元コメント投稿者への@メンションを自動挿入（自分自身への返信時は空） |
| 全員に返信 | ボタン | 投稿フォームを展開し、全参加者への@メンションを自動挿入（参加者が自分のみの場合は空） |
| リンク | ボタン | コメントのパーマリンクURLをテキストボックスで表示 |
| 削除 | ボタン | インライン確認「削除します。よろしいですか?」→「削除する」or「キャンセル」 |

### パーマリンク形式

```
https://{domain}/k/{appId}/show#record={recordId}&comment={commentId}
```

## @メンション機能

| 項目 | 内容 |
|------|------|
| 起動方法 | ツールバーの「宛先指定」ボタンをクリック |
| 動作 | テキスト入力欄のカーソル位置に「@」が挿入される |
| サジェスト | @の後に文字を入力するとサジェストリストが表示される（IME連携/keydownイベント検知） |
| 返信ボタン連動 | 元コメント投稿者への@メンションが自動挿入（自分自身は除外） |
| 全員に返信連動 | コメントスレッドの全参加者への@メンションが自動挿入 |

## バリデーション

| 条件 | 動作 |
|------|------|
| 空のコメント投稿 | 「書き込む」ボタンをクリックしても何も起きない（サイレントバリデーション） |
| 文字数制限 | 明示的なエラーメッセージや文字数カウンターは確認されず |

## 特記事項

- **コメントの編集機能は存在しない**。投稿後は削除のみ可能
- コメントはリッチテキストではなくプレーンテキスト
- 添付ファイル機能なし（メッセージやスレッドとは異なる）
- 削除はインライン確認（ブラウザダイアログではない）
