# ファイル管理アプリ

- URL: `/k/3/`
- 認証: 必要
- セクション: アプリ
- アプリID: 3

## 目的

文書や提案資料、画像などのファイルを共有するアプリ。全文検索でPDFファイル等の中身まで検索したり、ファイルの更新履歴を残したりすることもできる。

## レイアウト（一覧画面）

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー（検索は「アプリ内検索」に切替） |
| パンくずリスト | ポータル > スペース:あなたのチームのコミュニケーションスペース > アプリ:ファイル管理 |
| アプリ説明エリア | お気に入りボタン + 説明表示トグル |
| ツールバー | ビュー切替、絞り込み、集計、レコード追加、アプリ設定、オプション |
| データテーブル | ページング情報 + テーブル本体 |

## データテーブルのカラム

| カラム名 | 備考 |
|---------|------|
| タイトル | 文字列（1行） |
| ファイル | 添付ファイル |
| 作成者 | 自動入力 |
| 作成日時 | 自動入力 |

## レコード追加/編集フォーム

| 項目名 | フィールドコード | 型 | 必須 | バリデーション | 備考 |
|--------|----------------|-----|------|--------------|------|
| タイトル | Title | 文字列（1行） | 任意 | なし | |
| ファイル | File | 添付ファイル | 任意 | 最大1GB | サムネイルサイズ150 |
| 説明 | Description | 文字列（複数行） | 任意 | なし | |
| 作成者 | Createdby | 作成者 | 自動 | 自動入力 | * マーク付き |
| 作成日時 | Createdtime | 作成日時 | 自動 | 自動入力 | * マーク付き |
| **テーブル: 変更内容メモ** | | サブテーブル | | | |
| 　日付 | Date | 日付 | 任意 | なし | テーブル内 |
| 　変更内容 | ModifiedContents | 文字列（1行） | 任意 | なし | テーブル内 |
| 　変更者 | Modifiedby | ユーザー選択 | 任意 | なし | テーブル内、組織/グループからも選択可 |

※ 全フィールド空のまま保存可能（必須フィールドなし）

## インライン編集・削除（一覧画面）

テーブル各行の最右カラムに以下のボタンが表示される（アプリの高度な設定で「インライン編集」が有効の場合）:

| ラベル | 種類 | 動作 |
|--------|------|------|
| 編集する | button | 該当行をインライン編集モードに切替 |
| 削除する | button | 確認ダイアログ後にレコード削除 |

また、各行の先頭セルに「レコードの詳細を表示する」リンクが存在する。

## アプリ設定

管理者権限でアクセス可能。以下のタブ/セクション構成:

| タブ | 内容 |
|------|------|
| フォーム | フィールド配置のドラッグ&ドロップエディタ |
| 一覧 | ビューの設定 |
| グラフ | グラフ設定 |
| 設定 | 下記参照 |

**設定タブの詳細**:

| セクション | 項目 |
|-----------|------|
| 一般設定 | アイコンと説明 / デザインテーマ / プロセス管理 |
| 通知 | アプリの条件通知 / レコードの条件通知 / リマインダーの条件通知 |
| カスタマイズ/サービス連携 | プラグイン / JavaScript・CSSでカスタマイズ / APIトークン / Webhook |
| アクセス権 | アプリ / レコード / フィールド |
| その他の設定 | カテゴリー / 言語ごとの名称 / レコードのタイトル / 高度な設定 / アクション |
| 運用管理 | アプリの動作テスト / テンプレートDL / スペース変更 / 参照アプリ / メンテナンスモード / 設定変更履歴 |
| アプリの削除 | アプリを削除する |

## 絞り込みダイアログ

- 条件: フィールド選択 + 演算子 + 値（複数条件追加可能）
- ソート: フィールド選択（デフォルト「作成日時」）+ 昇順/降順（デフォルト「降順」）、複数ソート可
- アクション: キャンセル / 保存 / 適用

## 集計ダイアログ

グラフの種類: 横棒グラフ / 縦棒グラフ / 円グラフ / 折れ線グラフ / クロス集計表 / その他
