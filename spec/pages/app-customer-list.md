# 顧客リストアプリ

- URL: `/k/4/`
- 認証: 必要
- セクション: アプリ
- アプリID: 4

## 目的

会社名、担当者名、連絡先などお客様の情報を登録し、チームで共有するアプリ。キーワード検索、地域等の条件での絞り込み、リストのCSV入出力等が可能。

## レイアウト（一覧画面）

ファイル管理アプリと同一構造（共通アプリコンポーネント）。

パンくずリスト: ポータル > スペース:あなたのチームのコミュニケーションスペース > アプリ:顧客リスト

## データテーブルのカラム

| カラム名 | 備考 |
|---------|------|
| レコード番号 | 自動採番 |
| 会社名 | 文字列（1行） |
| 部署名 | 文字列（1行） |
| 担当者名 | 文字列（1行） |
| 住所 | 文字列（1行） |

## レコード追加/編集フォーム

| 項目名 | フィールドコード | 型 | 必須 | バリデーション | 備考 |
|--------|----------------|-----|------|--------------|------|
| レコード番号 | record_no | レコード番号 | 自動 | 自動採番 | * マーク付き |
| 会社名 | 文字列__1行_ | 文字列（1行） | 任意 | なし | |
| 部署名 | 文字列__1行__0 | 文字列（1行） | 任意 | なし | |
| 担当者名 | 文字列__1行__2 | 文字列（1行） | 任意 | なし | |
| 郵便番号(数字のみ) | Zipcode | 文字列（1行） | 任意 | maxLength: 7 | 「7文字以下」表示 |
| TEL(数字のみ) | TEL | 文字列（1行） | 任意 | なし | |
| FAX(数字のみ) | FAX | 文字列（1行） | 任意 | なし | |
| 住所 | Address | 文字列（1行） | 任意 | なし | |
| 顧客ランク | ドロップダウン | ドロップダウン | 任意 | 選択肢: A, B, C | デフォルト「-----」（未選択） |
| メールアドレス | Mail | 文字列（1行） | 任意 | なし | |
| 会社ロゴ | 添付ファイル_0 | 添付ファイル | 任意 | 最大1GB | サムネイルサイズ150 |
| 備考 | 文字列__複数行_ | 文字列（複数行） | 任意 | なし | |

※ 全フィールド空のまま保存可能（必須フィールドなし）

### フォームレイアウト（行・カラム配置）

| 行 | カラム構成 |
|-----|---------|
| 行1 | レコード番号（フル幅） |
| 行2 | 会社名 / 部署名 / 担当者名（3カラム横並び） |
| 行3 | 郵便番号 / TEL / FAX（3カラム横並び） |
| 行4 | 住所 / 顧客ランク（2カラム横並び） |
| 行5 | メールアドレス / 会社ロゴ（2カラム横並び） |
| 行6 | 備考（フル幅） |

## ビュー切替

| ビュー名 | 備考 |
|---------|------|
| 顧客一覧 | デフォルト |
| 顧客ランクA | 顧客ランクAでフィルタ |
| （すべて） | ビルトイン（全レコード表示） |

## アクション

ファイル管理アプリと同一（共通アプリコンポーネント）。ビュー切替のデフォルトは「顧客一覧」。

## アプリ設定

ファイル管理アプリと同一構成（OpenDesk共通テンプレート）。

## 絞り込み・集計

ファイル管理アプリと同一の構成。デフォルトは「すべてのレコード」「作成日時 降順」。
