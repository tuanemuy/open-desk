# お知らせ掲示板の編集（ポータル）

- URL: `/k/#/portal`（URL変化なし、モーダルダイアログとして表示）
- 認証: 必要（システム管理者/cybozu.com共通管理者のみ）
- セクション: ポータル

## 目的

ポータルトップに表示されるお知らせ掲示板の内容（タイトル + 本文）を編集する。

## アクセス方法

ポータル画面 > お知らせセクション > 「お知らせ掲示板を編集する」リンクをクリック。

## 編集権限

- **OpenDeskシステム管理者** または **cybozu.com共通管理者** のみ編集可能
- 一般ユーザーには「お知らせ掲示板を編集する」リンク自体が表示されない
- ポータル設定ダイアログ（オプション > 表示中のポータルの設定）から、お知らせ掲示板の表示/非表示自体を切り替えることも可能（管理者のみ）

## ダイアログレイアウト

| 要素 | 説明 |
|------|------|
| ダイアログヘッダー | 「お知らせ掲示板の編集」(h2) + Close(X)ボタン |
| タイトル入力欄 | テキスト入力。デフォルト値「お知らせ」 |
| ツールバー | 17個のツール |
| 本文エディタ | contenteditable WYSIWYGリッチテキストエディタ |
| フッター | 「キャンセル」ボタン + 「保存」ボタン |

## 入力項目

| 項目名 | 型 | 必須 | 備考 |
|--------|------|------|------|
| タイトル（掲示板名） | text input | - | デフォルト「お知らせ」。ポータルのお知らせセクション見出し(h3)に反映 |
| 本文 | contenteditable（リッチテキスト） | - | WYSIWYGエディタ。HTML形式で保存 |

## リッチテキストエディタ ツールバー

| # | ツール名 | 種類 | 詳細 |
|---|---------|------|------|
| 1 | アプリ貼り付け | button | OpenDeskアプリのレコード一覧/グラフを埋め込み。サブダイアログで「すべてのアプリ」「お気に入り」タブ + アプリ検索 |
| 2 | ファイルを添付する | button | ファイルアップロード（最大1GB） |
| 3 | 絵文字 | button | 絵文字パレット（160個）をポップアップ表示 |
| 4 | 太字 | button | - |
| 5 | 斜体 | button | - |
| 6 | 下線 | button | - |
| 7 | 文字色 | button(expand) | カラーパレット（8x8 = 64色） |
| 8 | 文字背景色 | button(expand) | カラーパレット（8x8 = 64色） |
| 9 | 文字サイズ | listbox | 小さい(10px), 普通(13px, デフォルト), やや大きい(18px), 大きい(32px) |
| 10 | リンク | button | リンク挿入/編集ダイアログ |
| 11 | 元に戻す | button | Undo |
| 12 | やり直す | button | Redo |
| 13 | 番号なしリスト | button | 箇条書き |
| 14 | 番号付きリスト | button | - |
| 15 | 左揃え | button | - |
| 16 | 中央揃え | button | - |
| 17 | フォーマット削除 | button | 書式クリア |

### アプリ貼り付けダイアログ

- タブ: 「すべてのアプリ」/「お気に入り」
- アプリ検索テキストボックス
- アプリリスト（アイコン + アプリ名）
- キャンセル / OK

### リンク挿入ダイアログ

- タイトル: textbox
- リンク先タブ: 「Webサイト」（URL入力 + 確認ボタン）/ 「メールアドレス」
- 「リンク先を新しいタブで開く」checkbox
- OK / Cancel

### 添付ファイルダイアログ

- ファイル選択ボタン（最大1GB）
- キャンセル / 添付

## アクション

| ラベル | 種類 | 動作 |
|--------|------|------|
| Close(X) | button | ダイアログを閉じる（変更破棄） |
| キャンセル | button | ダイアログを閉じる（変更破棄） |
| 保存 | button（primary, 青） | 編集内容を保存してダイアログを閉じる |

## プレビュー機能

プレビュー機能は存在しない。エディタ自体がWYSIWYGのため、編集中にリアルタイムで表示結果を確認できる。

## スペースのお知らせ編集との違い

| 比較項目 | ポータルお知らせ掲示板 | スペースお知らせ編集 |
|---------|---------------------|-------------------|
| タイトル入力欄 | **あり**（掲示板名を変更可能） | なし（タイトル固定） |
| 宛先指定ボタン | なし | **あり**（メンバーへの通知用） |
| アプリ貼り付け | あり | あり |
| ファイル添付 | あり（最大1GB） | あり |
| 編集権限 | システム管理者/cybozu.com共通管理者のみ | スペース管理者 |
| 影響範囲 | OpenDesk全体（全ユーザーに表示） | 当該スペース内のみ |
