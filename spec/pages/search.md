# 検索機能

- URL: `/k/search?keyword={キーワード}`
- 認証: 必要
- セクション: 共通

## 目的

OpenDesk内のレコード・スレッド・ピープル・メッセージ等を横断的に検索する機能。コンテキスト（現在の画面）に応じて全体検索/アプリ内検索/スペース内検索が自動切替される。

## 検索モード

### 検索入力欄の自動切替

ヘッダー右上の検索コンボボックスは、現在の画面に応じてaria-labelが自動切替される。

| 現在の画面 | 検索モード | aria-label |
|-----------|-----------|------------|
| ポータル | 全体検索 | 「全体検索」 |
| アプリ画面 | アプリ内検索 | 「アプリ内検索」 |
| スペース画面 | スペース内検索 | 「スペース内検索」 |

### サジェスト動作

キーワード入力するとlistboxがドロップダウン表示。カテゴリ別にサジェストが表示される:
- 「ピープル」カテゴリ: ユーザー名 + 「個人メッセージ」リンク
- 「スレッド」カテゴリ: スレッドタイトル一覧
- 末尾に「検索結果をさらに表示」リンク

## 検索結果画面

### A. 全体検索

- URL: `/k/search?keyword={キーワード}`

#### 2つのモード

1. **OpenDesk全体を検索（全文検索モード）**: 左サイドバーに絞り込みフィルター + 右メインに結果リスト
2. **タイトル検索モード**: タブ切替式（アプリ/スペース/スレッド/ピープル）、各タブにマッチ件数表示

#### 全文検索のフィルター項目

| フィルター | 型 | 説明 |
|-----------|------|------|
| 種類 - レコード | checkbox | レコード本体 |
| 種類 - レコードコメント | checkbox | レコードへのコメント |
| 種類 - スペース・スレッド | checkbox | スペースとスレッドの内容 |
| 種類 - ピープル | checkbox | ユーザー情報 |
| 種類 - メッセージ | checkbox | 個人メッセージ |
| 種類 - 添付ファイル | checkbox | 添付ファイル |
| 作成日の範囲（開始） | textbox + カレンダーボタン | 日付ピッカーで開始日指定 |
| 作成日の範囲（終了） | textbox + カレンダーボタン | 日付ピッカーで終了日指定 |
| 作成者 | combobox + 検索ボタン | ユーザーをサジェスト検索で指定 |
| 組織やグループから選択 | button | 組織/グループから作成者を選択 |
| 絞り込む | button | フィルター適用 |

#### タイトル検索のタブ別表示

| タブ | 表示内容 |
|------|----------|
| アプリ(N) | タイトルにキーワードを含むアプリ一覧 |
| スペース(N) | タイトルにキーワードを含むスペース一覧 |
| スレッド(N) | スレッドアイコン + タイトル + 所属スペース名 |
| ピープル(N) | ユーザーアイコン + ユーザー名 + 「メッセージ」「ピープル」リンク |

### B. アプリ内検索

- URL: `/k/search?keyword={キーワード}&app={アプリID}`
- 上部に「OpenDesk全体を検索」リンク（全体検索への切替）
- スコープ表示: 「アプリ：{アプリ名}」内を検索」

### C. スペース内検索

- URL: `/k/search?keyword={キーワード}&space={スペースID}`
- 上部に「OpenDesk全体を検索」リンク（全体検索への切替）
- スコープ表示: 「スペース：{スペース名}」内を検索」

## 種類フィルターのモード別比較

| 種類チェックボックス | 全体検索 | アプリ内検索 | スペース内検索 |
|---------------------|---------|-------------|---------------|
| レコード | あり | あり | あり |
| レコードコメント | あり | あり | あり |
| スペース・スレッド | あり | なし | あり |
| ピープル | あり | なし | なし |
| メッセージ | あり | なし | なし |
| 添付ファイル | あり | あり | あり |

## 結果表示形式

各結果アイテムの構成:
- アイコン: 結果種類を示す画像
- タイトルリンク: 「{アプリ名} {レコード番号}」形式 またはスレッドタイトル
- スニペット: キーワードが `<strong>` でハイライトされたテキスト抜粋
- 所属情報: アプリ名 or スペース名
- 作成者: リンク付きユーザー名
- 作成日時: "YYYY-MM-DD HH:MM" 形式

## モード切替方法

| 切替方向 | 方法 |
|----------|------|
| ポータル → 全体検索 | ヘッダーの検索欄にキーワード入力してEnter |
| アプリ画面 → アプリ内検索 | ヘッダーの検索欄（自動で「アプリ内検索」に切替）にキーワード入力してEnter |
| スペース画面 → スペース内検索 | ヘッダーの検索欄（自動で「スペース内検索」に切替）にキーワード入力してEnter |
| アプリ内/スペース内 → 全体検索 | 検索結果画面上部の「OpenDesk全体を検索」リンク |
| 全文検索 ↔ タイトル検索 | 検索結果画面内の「OpenDesk全体を検索」/「タイトル検索」リンクで切替 |

## URLパラメータ

| パラメータ | 説明 | 例 |
|-----------|------|------|
| `keyword` | 検索キーワード（URLエンコード） | `keyword=%E3%83%86%E3%82%B9%E3%83%88` |
| `app` | アプリ内検索時のアプリID | `app=4` |
| `space` | スペース内検索時のスペースID | `space=2` |
| `groupTypes` | 種類フィルター | `groupTypes=RECORD` |
