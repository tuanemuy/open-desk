# ブックマーク機能

- 位置: グローバルヘッダーの「ブックマーク」ボタン（星アイコン）
- 認証: 必要
- セクション: 共通

## 目的

OpenDesk内の任意のページをブックマークし、素早くアクセスするための機能。ヘッダーからドロップダウンパネルとして展開される。

## パネルレイアウト

| 要素 | 説明 |
|------|------|
| トリガー | ヘッダーナビの「ブックマーク」ボタン（expanded属性でトグル） |
| パネル上部 | 「このページをブックマークする」ボタン（+アイコン） |
| タブバー | 3タブ構成（tablist） |
| タブパネル | 選択中タブのブックマーク一覧（tabpanel） |

## タブ構成

| タブ | 分類対象 | リスト構造 |
|------|----------|-----------|
| アプリ | アプリのURL（`/k/{id}/`） | アプリごとにアコーディオン展開/折畳み可能。ヘッダー行に「アプリ名」+「現在のビュー名」、子にブックマーク項目リスト |
| 検索結果 | 検索結果URL（`/k/search?...`） | フラットなリスト。各項目にリンク+削除ボタン |
| その他 | 上記以外のURL（ポータル、スペース等） | フラットなリスト。各項目にリンク+削除ボタン |

## ブックマーク追加

### 操作手順

1. ブックマークパネルを開く
2. 「このページをブックマークする」をクリック
3. **「ページのブックマーク」ダイアログ**が表示

### 追加ダイアログの入力項目

| 項目名 | 型 | 必須 | 備考 |
|--------|------|------|------|
| 名前 | テキスト | はい | 自動でページタイトルが入力（編集可能） |
| URL | テキスト | はい | 自動で現在のページURLが入力（編集可能） |

ボタン: 「キャンセル」/「OK」

### ページ種別ごとの自動入力

| ページ | 名前の自動入力 | 分類先タブ |
|--------|---------------|-----------|
| ポータル | `ポータル` | その他 |
| アプリ一覧 | `{アプリ名} - レコードの一覧` | アプリ |
| 検索結果 | `{検索キーワード} - 検索結果` | 検索結果 |
| スペース | `{スペース名}` | その他 |

追加完了時、ヘッダーにトースト通知「ブックマークに保存されました。」が表示される。

## ブックマーク削除

1. 各ブックマーク項目の右側にある「削除する」ボタンをクリック
2. **インラインポップオーバー**で確認が表示（ブラウザダイアログではない）
   - テキスト: 「削除します。よろしいですか？」
   - ボタン: 「キャンセル」/「削除する」
3. 「削除する」クリックで即座に削除
4. タブ内の全項目が削除されると「ブックマークはありません。」に戻る

## 並び替え

ドラッグハンドルや並び替えUIは存在しない。表示順は追加順と推定。

## 状態・表示切替

| 状態 | 表示 |
|------|------|
| パネル閉 | 「ブックマーク」ボタン（expanded=false） |
| パネル開 | ドロップダウンパネル表示 |
| タブ空 | 「ブックマークはありません。」 |
| タブに項目あり | リスト表示 |
| アプリアコーディオン折畳み | アプリ名のみ |
| アプリアコーディオン展開 | アプリ名 + ビュー名 + 子ブックマークリスト |
| 削除確認表示 | インラインポップオーバー |

## 「お気に入り」機能との違い

アプリページの「お気に入り」ボタン、スペースページの「お気に入りに追加」ボタンは、ブックマークとは**別の機能**。
- お気に入り: ポータルのアプリ/スペース一覧での表示順に影響。クリックで即時トグル（ダイアログなし）
- ブックマーク: ヘッダーのブックマークパネルから管理。任意のページURLを保存可能
