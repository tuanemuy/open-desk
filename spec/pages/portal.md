# ポータル

- URL: `/k/#/portal`
- 認証: 必要
- セクション: ポータル

## 目的

OpenDeskのホーム画面。お知らせ掲示板、通知、スペース一覧、アプリ一覧を集約表示し、各機能へのハブとなる。

## レイアウト

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー（共通） |
| ページタイトルバー | 「ポータル」見出し + 「オプション」ボタン |
| メインコンテンツ左（幅広） | お知らせ掲示板エリア |
| メインコンテンツ右上 | 通知ウィジェット |
| メインコンテンツ右中 | スペースウィジェット |
| メインコンテンツ右下 | アプリウィジェット |

## お知らせ掲示板

- 見出し「お知らせ」(h3)
- 「お知らせ掲示板を編集する」リンク（管理者権限で編集可能）
- コンテンツはリッチテキスト(HTML)形式: テキスト、画像、リンクを含む
- デフォルトではOpenDeskの使い方ガイド（アプリ作成手順の説明 + スクリーンショット画像）が表示
- 最終更新表示: 「YYYY/M/D H:MM ユーザー名」

## 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| 全体検索 | combobox | - | - | ヘッダー右端、入力するとサジェスト表示 |
| 表示する通知を切り替える | listbox | - | - | 通知ウィジェット内。選択肢:「すべて」(デフォルト)、「自分宛」、「あとで読む」、(カスタム絞り込み名 ※「編集」「削除」アクション付き)、「絞り込みを作成する」 |
| 未読/既読 切替 | toggle | - | - | 通知ウィジェット内 |
| スペースの一覧を切り替える | listbox | - | - | 選択肢:「参加中のスペース」(デフォルト)、「お気に入りのスペース」(「編集」アクション付き)、「最近開いたスペース」、「作成したスペース」、「すべてのスペース」、「参加中のゲストスペース」 |
| アプリの一覧を切り替える | listbox | - | - | 選択肢:「すべてのアプリ」(デフォルト)、「お気に入りのアプリ」(「編集」アクション付き)、「最近開いたアプリ」、「作成したアプリ」、「最近公開されたアプリ」 |

## アクション

| ラベル | 種類 | 動作 | 備考 |
|--------|------|------|------|
| オプション | button(expand) | ポータルオプションメニュー表示（下記参照） | |
| お知らせ掲示板を編集する | link | お知らせ掲示板の編集画面へ | 管理者権限 |
| スペース「+」ボタン | button(expand) | 「スペースを作成」「ゲストスペースを作成」メニュー | |
| スペースリンク | link | スペース詳細画面へ | |
| アプリを作成する | button | アプリ作成画面へ | |
| アプリリンク | link | 各アプリ画面へ | |

## ポータルオプションメニュー

| ラベル | 種類 | 動作 |
|--------|------|------|
| スペースを作成 | menuitem | スペース作成ダイアログ表示 |
| ゲストスペースを作成 | menuitem | ゲストスペース作成ダイアログ表示 |
| アプリを作成 | menuitem | アプリストア画面へ遷移 |
| --- | separator | |
| 表示中のポータルの設定 | menuitem | ポータル表示設定ダイアログ（お知らせ掲示板の表示/非表示等） |
| ポータル管理 | menuitem | ポータル管理画面 |

## 通知ウィジェットの各通知項目

各通知アイテムには以下のアクション要素が含まれる:
- 「既読にする」ボタン（画像アイコン）: クリックで既読状態に切替
- 通知リンク: クリックで通知元画面に遷移

## 状態・表示切替

| 条件 | 表示変化 |
|------|---------|
| 通知なし | 「通知はありません。」テキスト表示 |
| スペース「+」クリック | メニュー展開（スペースを作成/ゲストスペースを作成） |
| 通知フィルタ切替 | 通知ウィジェットの表示内容が変化 |
| 未読/既読切替 | 通知ウィジェットの表示内容が変化 |
