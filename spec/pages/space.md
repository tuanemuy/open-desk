# スペース

- URL: `/k/#/space/{id}`
- 認証: 必要
- セクション: スペース

## 目的

チーム単位のコミュニケーションとアプリ管理の集約拠点。お知らせ掲示板、スレッド（テーマ別ディスカッション）、アプリ一覧、メンバー管理を提供する。

## レイアウト（ポータルビュー）

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー（検索は「スペース内検索」に切替） |
| スペースヘッダー | スペース名(h2リンク)、オプションボタン、お気に入り追加ボタン、公開/非公開ラベル |
| メインコンテンツ左（幅広） | お知らせセクション（リッチテキスト表示 + 編集リンク） |
| サイドバー右 | スレッド一覧、アプリ一覧、ピープル（メンバー一覧）、関連リンク |

## レイアウト（スレッド詳細ビュー）

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー |
| 左サイドバー | スレッド一覧、アプリ一覧、ピープル |
| メインエリア | スレッドタイトル(h3)、投稿者名+時刻、編集リンク、スレッド本文、投稿フォーム |

## 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| スペース内検索 | combobox | - | - | 絞り込み検索 |
| アプリの一覧を切り替える | listbox | - | - | 「すべてのアプリ」がデフォルト |

## アクション

| ラベル | 種類 | 動作 | 備考 |
|--------|------|------|------|
| オプション | button(dropdown) | オプションメニュー展開 | |
| お気に入りに追加 | button | お気に入りトグル | |
| スペースの本文を編集 | link | お知らせ編集ダイアログ（モーダル） | |
| スレッドを作成 | link | スレッド作成フォーム（インラインフォーム） | |
| スレッド名リンク | link | スレッド詳細ビュー（SPA内遷移） | |
| アプリ追加（+アイコン） | clickable | アプリ追加機能 | |
| ピープル追加（+アイコン） | clickable | メンバー追加機能 | |
| 関連リンク追加（+アイコン） | clickable | 関連リンク追加機能 | |

## オプションメニュー

| ラベル | 動作 |
|--------|------|
| スレッドを追加 | スレッド作成フォーム表示 |
| アプリを追加 | アプリ追加機能 |
| 関連リンクを管理 | 関連リンク管理 |
| スペースを退会 | スペース退会処理 |
| メンバーを管理 | メンバー管理画面 |
| スペースを設定 | スペース設定ダイアログ（モーダル） |
| テンプレートを作成 | テンプレート作成 |
| スペースを削除 | スペース削除（破壊的操作） |

## お知らせ編集ダイアログ（モーダル）

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| 本文 | リッチテキストエディタ | - | - | WYSIWYGエディタ。ツールバー: 宛先指定、アプリ貼り付け、ファイル添付、絵文字、書式設定全般 |

アクション: キャンセル / 保存 / Close

## スレッド作成フォーム（インラインフォーム）

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| スレッドのタイトル | textbox | - | - | スレッド名 |
| 本文 | リッチテキストエディタ | - | - | プレースホルダ「本文」 |
| 通知チェック | checkbox | - | - | 「スレッドの作成をスペース参加メンバーに「自分宛」で通知する」 |

説明文: 「メンバーへのお知らせや共有事項などを掲示します。リンクや画像のほか、アプリのレコードの一覧や、グラフを貼り付けることもできます。」

アクション: キャンセル / スレッドを作成

## スレッド詳細ビュー

### ヘッダーアクション

| ラベル | 種類 | 動作 |
|--------|------|------|
| スレッドを追加 | link | スレッド追加 |
| フォローを解除 | link | スレッドフォロー解除 |
| サイドパネルを非表示にする/表示する | link | サイドパネル表示切替 |
| (オプションボタン) | button(dropdown) | 「スレッドを削除」menuitemを含むドロップダウン |

※ 「編集」リンクはヘッダーアクションバーではなく、スレッド本文の投稿者名・時刻と同じ行に表示される。

### コメント投稿フォーム

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| 投稿テキスト | リッチテキストエディタ | - | - | フォーカスで展開、プレースホルダ「投稿する」 |

ツールバー: 宛先指定、ファイル添付、絵文字、書式設定全般（お知らせ/スレッド作成と異なり「アプリ貼り付け」ボタンなし）

アクション: キャンセル / 書き込む

### コメントアクション

各コメントには以下のアクションリンクが表示される:

| ラベル | 動作 |
|--------|------|
| いいね！ | コメントに「いいね」を付与（トグル） |
| 返信 | 投稿フォームを展開し、元コメント投稿者への@メンション自動挿入 |
| 全員に返信 | 投稿フォームを展開し、全参加者への@メンション自動挿入 |
| アクション | 「アクションを作成する」サブメニューが表示（スレッドコメント→アプリレコード転記） |
| リンク | コメントのパーマリンク表示 |
| 削除 | インライン確認後にコメント削除 |

## スペース設定ダイアログ（モーダル）

2タブ構成: 「基本設定」「参加メンバー」

### 基本設定タブ

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| スペース名 | textbox | - | - | |
| 参加メンバーだけにこのスペースを公開する | checkbox | - | - | 非公開設定 |
| スペースのポータルと複数のスレッドを使用する | checkbox | - | - | checked=true, disabled（変更不可） |
| スペースの参加/退会、スレッドのフォロー/フォロー解除を禁止する | checkbox | - | - | |
| アプリ作成できるユーザーをスペースの管理者に限定する | checkbox | - | - | ヒントボタン付き |
| カバー画像 | プリセット選択 or ファイルアップロード | - | 最大5MB | 26個のプリセット + カスタム画像 |
| ポータル表示コンテンツ（お知らせ） | checkbox | - | - | checked=true |
| ポータル表示コンテンツ（スレッド） | checkbox | - | - | checked=true |
| ポータル表示コンテンツ（アプリ） | checkbox | - | - | checked=true |
| ポータル表示コンテンツ（ピープル） | checkbox | - | - | checked=true |
| ポータル表示コンテンツ（関連リンク） | checkbox | - | - | checked=true |

注記: 「※モバイル版にも適用されます。」

### 参加メンバータブ

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|-----|------|--------------|------|
| ユーザー検索 | textbox + link | - | - | メンバー検索 |
| 組織やグループから選択 | link | - | - | 組織/グループ選択画面へ |

メンバーテーブル:

| カラム | 説明 |
|--------|------|
| ユーザー/組織/グループ | メンバー名（アイコン付き） |
| 管理者 | checkbox（管理者権限付与） |
| 下位組織も含める | 組織メンバーの場合に有効 |
| 操作 | 「削除する」リンク |
