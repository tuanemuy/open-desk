# レコード一覧のオプションメニュー

- 位置: アプリのレコード一覧画面のヘッダー内
- 認証: 必要
- セクション: アプリ > レコード一覧

## 目的

レコード一覧画面の表示設定やデータ入出力機能を提供するメニュー。

## メニュー全項目

「オプション」ボタン（`<button>` 要素、`expanded` 属性でトグル）をクリックすると表示される。

| # | メニュー項目名 | 種別 | 動作 | 備考 |
|---|---------------|------|------|------|
| 1 | 表示件数 | menuitem（サブメニューあり） | クリックでサブメニュー展開 | - |
| 2 | 先頭行を固定表示 | menuitemcheckbox | クリックでトグル（ON/OFF） | デフォルト: ON |
| - | *(セパレータ)* | separator | - | - |
| 3 | ファイルに書き出す | menuitem | 書き出し設定画面へ遷移 | → csv-export.md参照 |
| 4 | ファイルから読み込む | menuitem | 読み込み画面へ遷移 | → csv-import.md参照 |

### 表示件数サブメニュー

menuitemradio形式（ラジオボタン）:
- **20**（デフォルト, checked）
- 40
- 60
- 80
- 100

選択するとレコード一覧の1ページあたり表示件数が変更される。

### 先頭行を固定表示

- デフォルト: ON（checked=true）
- ONの場合、テーブルのヘッダー行がスクロール時に固定表示される
- クリック後メニューは閉じる

## 「レコードの一括削除」について

現在の環境ではオプションメニューに「レコードの一括削除」は**表示されていない**。レコード一覧画面にはチェックボックスによる複数選択UIがなく、個別削除のみ対応。

## アプリ種別によるメニューの違い

顧客リスト（ID:4）とファイル管理（ID:3）で比較した結果、**アプリ種別による違いはなし**。両アプリとも同一のオプションメニュー構成。

## 補足: アプリ設定メニュー（「オプション」とは別）

「アプリを設定」リンクの横にあるドロップダウンメニュー。一覧画面と詳細画面で内容が異なる。

### 一覧画面版

- この一覧の設定を開く
- *(セパレータ)*
- 現在の列幅をアプリ設定に保存
- *(セパレータ)*
- **アプリ設定**（ラベル）
- フォーム / 一覧 / グラフ / 設定 / 一般設定 / 通知 / カスタマイズ／サービス連携 / アクセス権 / その他の設定

### 詳細画面版

- フォームの設定を開く
- *(セパレータ)*
- **アプリ設定**（ラベル）
- フォーム / 一覧 / グラフ / 設定 / 一般設定 / 通知 / カスタマイズ／サービス連携 / アクセス権 / その他の設定
