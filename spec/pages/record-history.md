# レコードの変更履歴

- URL: `/k/{appId}/show#record={recordId}&tab=history`
- 認証: 必要
- セクション: アプリ > レコード詳細

## 目的

レコードの変更履歴を時系列で表示し、各バージョンの差分確認や過去バージョンへの復元を行う機能。レコード詳細画面下部のタブパネルで提供される。

## レイアウト

- レコード詳細画面の下部にある**タブ切替パネル**（tablistロール）
- 「コメント」タブと「変更履歴」タブの2つで構成
- 「変更履歴」タブ選択時、コメントエリアの代わりに変更履歴リストが表示される
- 先頭に「最新のバージョンを表示する」リンクが常時表示
- **並び順: 新しい順**（最新バージョンが上）

## 各履歴エントリの表示内容

| 表示項目 | 内容 | 備考 |
|----------|------|------|
| バージョン番号 | `3:` のように数字+コロン | 作成時がバージョン1、編集ごとにインクリメント |
| 変更者アバター | ユーザーアイコン画像（36px） | - |
| 変更者名 | ボタン要素（`aria-expanded`） | クリックでプロフィールポップアップ表示 |
| 変更日時 | 短縮表記（例: `1:13`） | title属性に完全日時（例: `2026/4/5 1:13`） |
| 変更概要（差分） | フィールドごとのインライン差分表示 | 後述の差分表示方法を参照 |
| アクションリンク | 「変更箇所を表示する」「このバージョンに戻す」 | バージョンにより表示が異なる |

## 差分表示

差分はインラインで変更履歴リスト内に直接表示される（別画面遷移なし）。

### テキストフィールドの変更（文字レベル差分）

- フィールドラベル付きで表示: 「会社名: 」
- 削除部分: 薄赤背景（#ffe6e6）+ 取り消し線（`<del>`）
- 挿入部分: 薄緑背景（#e6ffe6）（`<ins>`）
- 共通部分: そのまま表示（`<span>`）
- 例: `東京都` ~~`千代田`~~（赤） `渋谷`（緑） `区`

### 空フィールドへの値追加（追記パターン）

「メールアドレス: 「test@example.com」が追記されました。」のように日本語テキストで説明。

### レコード作成（バージョン1）

「レコードが作成されました。」と表示。

## アクション

| ラベル | 種類 | 動作 | 表示条件 |
|--------|------|------|----------|
| 最新のバージョンを表示する | リンク | レコード本体を最新バージョンに戻す | 履歴リスト先頭に常時表示 |
| 変更箇所を表示する | リンク | レコード本体の変更フィールドを緑色（#e6ffe6）でハイライト表示 | 変更があるバージョン（バージョン2以降） |
| このバージョンに戻す | リンク | 確認ダイアログ後、レコードをこのバージョンに復元 | バージョン2以降（最新以外） |
| 最初のバージョンを表示する | リンク | レコード本体をバージョン1のデータで表示 | バージョン1のエントリのみ |
| 最初のバージョンに戻す | リンク | 確認ダイアログ後、レコードを初期状態に復元 | バージョン1（最新バージョンが2以上の場合） |
| 変更者名 | ボタン | プロフィールポップアップ表示 | 全バージョン |

## バージョン復元

- 「このバージョンに戻す」「最初のバージョンに戻す」でレコードを過去バージョンに復元可能
- ブラウザネイティブの確認ダイアログ（`window.confirm`）で復元前に確認
- 最新バージョン（現在のバージョン）には復元リンクは表示されない

## URL体系

| パターン | 用途 |
|----------|------|
| `#record={id}&tab=history` | 変更履歴タブを表示 |
| `#record={id}&tab=history&revision={version}` | 特定バージョンのレコード内容を表示 |
| `#record={id}&tab=comments` | コメントタブを表示 |

## 特記事項

- 変更履歴のフィルタリング・検索機能は存在しない
- 履歴は全件が時系列（新しい順）で一括表示される
- 変更履歴がない場合（新規作成直後）: バージョン1のみ表示、「レコードが作成されました。」
- 「変更箇所を表示する」クリック時、レコード本体エリアで変更フィールドのセルに緑背景が適用される
- バージョン選択時、URLハッシュに `&revision={version}` が追加される
