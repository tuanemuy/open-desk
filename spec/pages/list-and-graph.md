# 一覧ビュー・グラフ 作成・編集画面

- URL: `/k/admin/app/{appId}/` → 一覧タブ / グラフタブ
- 認証: 必要（アプリ管理者権限）
- セクション: アプリ管理

## 目的

アプリのレコードデータを一覧表示するビューと、集計・可視化するグラフを作成・編集する。

---

## A. 一覧ビュー

### 一覧タブの管理画面

| 要素 | 説明 |
|------|------|
| 一覧を追加する | 「+」アイコンリンク → 新規作成画面 |
| 作成済みの一覧 | テーブル形式（一覧名 + 操作：編集/複製/削除） |

ビルトイン一覧（「作業者が自分」「すべて」）は複製・削除がdisabled。

### 一覧の種類

| 種類 | 説明 |
|------|------|
| 表形式 | レコードを表形式で一覧表示 |
| カレンダー形式 | 日付フィールドに基づきカレンダー表示 |
| カスタマイズ | HTML/JS/CSSでカスタム一覧を構築 |

### 共通設定項目

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 一覧名 | テキスト入力（必須） | 一覧1（新規時） | |
| レコード一覧の表示形式 | ラジオボタン | 表形式 | 表形式/カレンダー形式/カスタマイズ |
| 絞り込み > 条件 | ドロップダウン + 条件追加 | すべてのレコード | フィールド選択 → 演算子 → 値。複数条件可 |
| 絞り込み > ソート | ドロップダウン + 順序 + 条件追加 | レコード番号/降順（新規）| フィールド + 昇順/降順。複数ソート可 |

### 表形式の固有設定

| 項目名 | 型 | 説明 |
|--------|------|------|
| フィールド選択（左パネル） | フィールドリスト + 検索テキストボックス | 利用可能フィールド一覧。クリックまたはD&Dで右側に追加 |
| すべて追加ボタン | ボタン | 全フィールドを一括追加 |
| 選択済みフィールド（右パネル） | D&Dリスト | 表示フィールドの順序。各項目に「削除」ボタン |
| すべてクリアボタン | ボタン | 選択済みフィールドを全解除 |
| オプション | 展開/折りたたみ | 追加表示オプション |

既に選択済みのフィールドは左パネルでdisabled表示。

### カレンダー形式の固有設定

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 日付 | ドロップダウン | 更新日時 | カレンダーの日付に使用するフィールド（日付/日時型のみ） |
| タイトル | ドロップダウン | レコード番号 | カレンダー上に表示するフィールド |

フィールド選択パネル（左右パネル）は表示されない。

### カスタマイズの固有設定

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 一覧ID | 表示のみ（自動付番） | 自動生成 | API等で参照する識別子 |
| 一覧を表示する範囲 | ラジオボタン | PC版とモバイル版で表示する | 「PC版のみ」「PC版とモバイル版」 |
| HTML | テキストエリア | 空 | カスタム一覧のHTML |
| ページネーションを表示する | チェックボックス | ON | |

注意メッセージ: 「OpenDeskのアップデートにより、適用したJavaScript / CSSファイルが動作しなくなる場合があります。」

## B. グラフ

### グラフタブの管理画面

| 要素 | 説明 |
|------|------|
| グラフを追加 | 「+」アイコンリンク → 新規作成画面 |
| 作成済みのグラフ | テーブル形式（グラフがない場合は「作成済みのグラフはありません。」） |

### グラフ種別

| グラフ種別 | サブタイプ | 説明 |
|-----------|----------|------|
| 横棒グラフ | 集合/積み上げ/100%積み上げ | |
| 縦棒グラフ | 集合/積み上げ/100%積み上げ | |
| 円グラフ | なし | 構成比表示 |
| 折れ線グラフ | なし | 推移表示 |
| クロス集計表 | なし | 大項目と中項目の両方が必須 |
| 表 | なし | 集計値をHTMLテーブルで表示 |
| 面グラフ | 積み上げなし/積み上げ/100%積み上げ | |
| 曲線グラフ | なし | 曲線の折れ線 |
| 曲線面グラフ | なし | 曲線の面グラフ |

### グラフ共通設定項目

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| グラフ名 | テキスト入力（必須） | グラフ1 | |
| グラフの種類 | ドロップダウン | 横棒グラフ | 9種類から選択 |
| サブタイプ | ドロップダウン | 種別による | 棒グラフ・面グラフのみ表示 |
| 分類する項目 | ドロップダウン + 条件追加 | 大項目: 作成者 | 大項目/中項目/小項目を追加可能 |
| 集計方法 | ドロップダウン + 条件追加 | レコード数 | レコード数/最大値/最小値等 |
| 条件（絞り込み） | ドロップダウン + 条件追加 | すべてのレコード | |
| ソート | ドロップダウン + 順序 + 条件追加 | 集計値/降順 | |
| プレビュー | 表示エリア | リアルタイム表示 | 「一部のデータだけを基にしています」注記付き |
| 定期レポート | チェックボックス | OFF | 「集計結果を定期的に記録する」 |

### ソートフィールドの選択肢

集計値 / 大項目 / 中項目 / 小項目

### グラフ種別ごとの設定差異

| 設定 | 横棒/縦棒 | 円 | 折れ線 | クロス集計表 | 表 | 面 | 曲線/曲線面 |
|------|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| サブタイプ | 3択 | - | - | - | - | 3択 | - |
| 分類項目の必須条件 | 大項目のみ | 大項目のみ | 大項目のみ | 大項目+中項目 | 大項目のみ | 大項目のみ | 大項目のみ |
| 集計方法の条件追加 | あり | あり | あり | なし | あり | あり | あり |

### プレビュー機能

全グラフ種別でリアルタイムプレビュー表示。データがない場合は「データがありません。」と表示。
