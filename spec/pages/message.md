# メッセージ

- URL: `/k/#/message`, `/k/#/message/{userId1};{userId2}`
- 認証: 必要
- セクション: メッセージ

## 目的

特定ユーザーとの1対1のダイレクトメッセージ機能。ピープル機能と連動しており、OpenDeskシステム管理で「ピープル機能とメッセージ機能を利用する」を有効にしている場合のみ使用可能。

## 重要な特徴

- **独立した「一覧画面」は存在しない**。`/k/#/message` にアクセスすると最後に開いたメッセージスレッドが直接表示される
- メッセージは**1対1固定**。グループメッセージは不可（グループでのやりとりはスペーススレッドを使用）
- 宛先入力欄はなく、URLの `{userId1};{userId2}` で暗黙的に決定される
- ゲストユーザーとのメッセージ不可（「ゲストユーザーとの連絡には、ゲストスペースをご利用ください。」と表示）

## レイアウト

| 領域 | 内容 |
|------|------|
| ヘッダー | グローバルヘッダー共通 |
| メインコンテンツ上部 | 相手ユーザーアバター + 見出し「{相手ユーザー名}とのメッセージ」 |
| メッセージ入力欄 | リッチテキストエディタ（折りたたみ式） |
| メッセージ一覧 | 送受信済みメッセージの時系列表示。空の場合は入力欄のみ |
| サイドバー | なし |

## メッセージ入力フォーム

折りたたみ状態ではプレースホルダー「メッセージを送る」のみ表示。クリックでリッチテキストエディタが展開される。

### 入力項目

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|------|------|----------------|------|
| 本文 | リッチテキスト（contenteditable） | はい | 空欄不可 | リッチテキストエディタ |
| 添付ファイル | ファイル | いいえ | - | ツールバーの「ファイルを添付する」ボタンから |

| 文字サイズ | フォントサイズ | ドロップダウン: 小さい, 普通(デフォルト), やや大きい, 大きい |

## アクション

| ラベル | 種類 | 動作 | 備考 |
|--------|------|------|------|
| 送信 | ボタン（プライマリ, 青） | メッセージを送信、スレッドに追加 | - |
| キャンセル | ボタン（セカンダリ） | 入力フォームを折りたたむ | - |

## アクセス経路

| アクセス方法 | 説明 |
|--------------|------|
| 他ユーザーのピープルページ | `/k/#/people/user/{loginName}` のアクションバーにある「個人メッセージ」リンク |
| 全体検索結果 | ピープル検索結果の「メッセージ」リンク |
| 通知 | メッセージ通知からの遷移 |
| 直接URL | `/k/#/message/{userId1};{userId2}` |

## 状態・表示切替

| 条件 | 結果 |
|------|------|
| 自分自身のプロフィールページ | 「フォロー」「個人メッセージ」リンクは非表示。代わりに「カバー画像を設定する」「プロフィールを編集する」が表示 |
| 他ユーザーのプロフィールページ | 「フォロー」と「個人メッセージ」リンクが表示。「カバー画像を設定する」「プロフィールを編集する」は非表示 |
| メッセージ入力欄（折りたたみ） | プレースホルダー「メッセージを送る」のみ表示 |
| メッセージ入力欄（展開） | リッチテキストツールバー + テキストエリア + キャンセル/送信ボタン |
| ゲストユーザー間 | メッセージ不可。「ゲストユーザーとの連絡には、ゲストスペースをご利用ください。」と表示 |
| ピープル・メッセージ機能無効時 | 「ピープル機能とメッセージ機能は無効です。」エラー |
| メッセージスレッドが空 | テキスト入力欄のみ表示 |

## 検索でのメッセージ

全体検索ページ（`/k/search?keyword=...`）の種類フィルターに「メッセージ」チェックボックスがある。

| フィルター項目 | 型 | 説明 |
|----------------|------|------|
| 種類: メッセージ | チェックボックス | メッセージ内容を検索対象に含める |
| 作成日の範囲 | 日付レンジ | 開始日 - 終了日（カレンダーピッカー） |
| 作成者 | ユーザー選択 | ユーザー検索/組織・グループから選択 |

通知一覧の「絞り込みの設定」でも場所フィルターに「メッセージ」を指定可能。

## 管理者設定

| 設定画面 | URL | 設定項目 |
|----------|-----|----------|
| OpenDeskシステム管理 > 利用する機能の選択 | `/k/admin/system/feature/` | 「ピープル機能とメッセージ機能を利用する」チェックボックス |

機能を無効にしても、既存のピープルとメッセージのデータは保持される。

## URL体系

| パターン | 用途 |
|----------|------|
| `/k/#/message` | メッセージトップ（最後に開いたスレッドを表示） |
| `/k/#/message/{id1};{id2}` | 特定ユーザー間のメッセージスレッド（id1, id2はユーザーID） |

## 共通コンポーネント

- リッチテキストエディタ（スペーススレッド投稿、ピープル投稿と共通のツールバー構成）
- 絵文字ピッカー（3タブ構成: 顔文字/絵文字1/絵文字2）
- リンク挿入ダイアログ
- ファイル添付
