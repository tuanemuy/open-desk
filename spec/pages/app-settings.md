# アプリ設定詳細画面

- URL: `/k/admin/app/{appId}/` → 設定タブ
- 認証: 必要（アプリ管理者権限）
- セクション: アプリ管理

## 目的

アプリのアクセス権、API連携、カスタマイズ、通知など各種詳細設定を管理する。

## 設定タブの全体構成

| セクション | 設定項目 |
|-----------|---------|
| 一般設定 | アイコンと説明、デザインテーマ、プロセス管理 |
| 通知 | アプリの条件通知、レコードの条件通知、リマインダーの条件通知 |
| カスタマイズ／サービス連携 | プラグイン、JavaScript/CSSでカスタマイズ、APIトークン、Webhook |
| アクセス権 | アプリ、レコード、フィールド |
| その他の設定 | カテゴリー、言語ごとの名称、レコードのタイトル、高度な設定、アクション |
| 運用管理 | アプリの動作テスト、テンプレートダウンロード、スペース変更、参照アプリ、メンテナンスモード、設定変更の履歴 |
| アプリの削除 | アプリを削除する |

全画面共通のアクションボタン: 「アプリの設定に戻る」リンク / 「キャンセル」ボタン / 「保存」ボタン

## アクセス権設定

### アプリのアクセス権

- URL: `/k/admin/app/acl/app?app={appId}`

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| ユーザー/組織/グループ追加 | コンボボックス検索 + 「組織やグループから選択」ボタン | - | アクセス権の対象を追加 |
| レコード閲覧 | チェックボックス | ON | |
| レコード追加 | チェックボックス | ON | |
| レコード編集 | チェックボックス | ON | |
| レコード削除 | チェックボックス | ON | |
| アプリ管理 | チェックボックス | 作成者ON, Everyone OFF | |
| ファイル読み込み | チェックボックス | 作成者ON, Everyone OFF | |
| ファイル書き出し | チェックボックス | 作成者ON, Everyone OFF | |

操作: ユーザー検索で行追加 → チェックボックスで権限設定 → D&Dで並び替え → 保存
制約: 最下行のEveryoneは削除不可。

### レコードのアクセス権

- URL: `/k/admin/app/acl/record?app={appId}`

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| レコードの条件 | ドロップダウン + 条件追加 | すべてのレコード | フィールド条件でフィルタ |
| ユーザー/組織/グループ | コンボボックス + 「フォームのフィールドを追加」 | Everyone | |
| 閲覧 | チェックボックス | ON | |
| 編集 | チェックボックス | ON | |
| 削除 | チェックボックス | ON | |

操作: 「追加する」ボタン → 条件行追加 → D&Dで並び替え（上から順に評価）
制約: 通知先にフォームフィールド（ユーザー選択型等）を指定可能。

### フィールドのアクセス権

- URL: `/k/admin/app/acl/field?app={appId}`

| 項目名 | 型 | 説明 |
|--------|------|------|
| フィールド | ドロップダウン | 対象フィールドを選択 |
| ユーザー/組織/グループ | コンボボックス | |
| 閲覧 | チェックボックス | |
| 編集 | チェックボックス | |

制約: フィールド単位の制御（閲覧・編集のみ、削除はなし）。

## APIトークン設定

- URL: `/k/admin/app/apitoken?app={appId}`

| 項目名 | 型 | 説明 |
|--------|------|------|
| APIトークン | 自動生成（表示のみ） | 「生成する」ボタンで生成 |
| アクセス権 | チェックボックス群 | トークンに付与する操作権限 |
| メモ | テキスト入力 | トークンの用途を記録 |

操作: 「生成する」ボタン → テーブルに行追加 → アクセス権設定 → メモ入力 → 保存
利用方法: ヘッダ `X-Cybozu-API-Token` で利用。説明文にcurlの使用例が記載。
外部リンク: OpenDesk開発者向けドキュメント、cybozu developer network

---

## Webhook設定

- URL: `/k/admin/app/webhook?app={appId}`

### 一覧画面

テーブル形式（有効/無効、Webhook URL、説明）。「追加する」リンクで追加画面に遷移。「保存」ボタンなし。

### 追加・編集画面

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 説明 | テキストボックス | 空 | |
| Webhook URL | テキストボックス（必須） | 空 | HTTPS必須（https://プレフィックス固定） |
| レコードの追加 | チェックボックス | OFF | |
| レコードの編集 | チェックボックス | OFF | |
| レコードの削除 | チェックボックス | OFF | |
| コメントの書き込み | チェックボックス | OFF | |
| ステータスの更新 | チェックボックス | OFF | |
| このWebhookを有効にする | チェックボックス | ON | |

## JavaScript/CSSカスタマイズ設定

- URL: `/k/admin/app/customize?app={appId}`

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 適用範囲 | ラジオボタン（3択） | すべてのユーザーに適用 | 「すべてのユーザーに適用」「アプリ管理者だけに適用」「適用しない」 |
| PC用 JavaScriptファイル | URL指定 or アップロード | なし | |
| PC用 CSSファイル | URL指定 or アップロード | なし | |
| スマートフォン用 JavaScriptファイル | URL指定 or アップロード | なし | |
| スマートフォン用 CSSファイル | URL指定 or アップロード | なし | |

操作: 「URL指定で追加」（URL入力欄が展開）or「アップロードして追加」（ファイル選択）→ 保存
制約: アップロードファイル最大20MB。PC用とスマートフォン用で別管理。
外部リンク: OpenDeskコーディングガイドライン、開発者向けドキュメント

---

## プラグイン設定

- URL: `/k/admin/app/{appId}/plugin/#/`

テーブル形式（状態、プラグイン名、設定、説明）。「追加する」リンクで利用可能なプラグイン一覧から選択。

操作: 追加 → 設定 → 削除
制約: プラグインの登録はOpenDeskシステム管理画面から行う（システム管理権限が必要）。アプリ画面からは登録済みプラグインのみ追加可能。「保存」ボタンなし。

---

## アクション設定（レコード再利用）

- URL: `/k/admin/app/action?app={appId}`

### 一覧画面

テーブル形式（並び替え、アクション名、コピー先のアプリ、最終更新者、最終更新日時）。「作成する」リンク。

### 作成・編集画面

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| アクション名 | テキストボックス（必須） | 空 | レコード詳細画面に表示されるボタン名 |
| コピー元 | 表示のみ | 現在のアプリ | |
| コピー先 | テキストボックス + アプリ選択ボタン（必須） | 空 | データの転記先アプリ |
| フィールドの関連付け | コピー元/コピー先のドロップダウンペア | 1行 | フィールド間のマッピング |
| アクションの利用者 | ユーザー検索 + 組織/グループ選択 | Everyone | |
| アクションを利用できる条件 | ドロップダウン + 条件追加 | すべてのレコード | |

制約: 同じアプリへの自己転記も可能。型が一致するフィールドのみマッピング可能。D&Dで表示順変更。

## 通知設定

### アプリの条件通知

- URL: `/k/admin/app/notification?app={appId}&trigger=app`

| 項目名 | 型 | 説明 |
|--------|------|------|
| 通知先 | ユーザー検索 / 組織グループ選択 / フォームフィールド選択 | 初期値: 更新者、作成者、作業者 |
| レコード追加 | チェックボックス | |
| レコード編集 | チェックボックス | |
| コメント書き込み | チェックボックス | |
| ステータスの更新 | チェックボックス | |
| ファイル読み込み | チェックボックス | |
| コメント追跡チェック | チェックボックス（デフォルトON） | コメント書き込みユーザーが自動的に通知受信 |

制約: 自分自身が行った操作は通知対象外（一部条件がdisabled）。

### レコードの条件通知

- URL: `/k/admin/app/notification?app={appId}&trigger=record`

| 項目名 | 型 | 説明 |
|--------|------|------|
| レコードの条件 | フィールド条件式（フィールド選択 + 演算子 + 値） | 通知トリガー条件 |
| 通知先 | ユーザー / 組織 / グループ / フォームフィールド | |

例: 「費用 >= 1,000,000」のとき担当部署に通知。

### リマインダーの条件通知

- URL: `/k/admin/app/notification?app={appId}&trigger=reminder`

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| リマインドの条件 | 日付/日時フィールド + 相対期間（N日前/後等） | - | リマインドの起算条件 |
| 通知先 | ユーザー / 組織 / グループ / フォームフィールド | - | |
| リマインド時刻のタイムゾーン | ドロップダウン | (UTC+09:00) 大阪、札幌、東京 | |

制約: 日付/日時フィールドが必要。例: 「締切の3日前に担当者に通知」。

## 共通UIパターン

- **ユーザー/組織/グループの選択**: コンボボックス検索 + 「組織やグループから選択」ボタン + オプション「フォームのフィールドを追加」
- **条件指定**: ドロップダウン「すべてのレコード」 + 「条件を追加」ボタン
- **テーブル行の操作**: D&Dで並び替え、行の削除ボタン
- **ヘルプ**: 各画面にヘルプリンク + ガイドブックリンク
