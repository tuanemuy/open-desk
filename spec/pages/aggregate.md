# 集計結果画面（グラフ表示）

- URL: `/k/{appId}/report?report={reportId}`
- 認証: 必要
- セクション: アプリ > グラフ

## 目的

レコードデータをグラフ・テーブル形式で集計・可視化する。

## レイアウト

| 領域 | 内容 |
|------|------|
| 共通ヘッダー | OpenDeskグローバルナビ |
| アプリヘッダー | アプリ名、パンくずリスト、説明文 |
| ツールバー左 | 一覧ビュー切替ドロップダウン / グラフビュー切替ドロップダウン |
| ツールバー中央 | 「絞り込む」ボタン / 「集計する」ボタン |
| ツールバー右 | 「+」(レコード追加) / 歯車(アプリ設定) / 「...」(オプション) |
| グラフ設定バー | グラフ種類ドロップダウン / サブタイプドロップダウン |
| グラフ表示エリア | SVGベースのグラフ描画（画面幅いっぱい） |
| 凡例 | グラフ下部 |

## グラフ種類

結果画面のドロップダウンから即時切替可能（ページ遷移なし）。

| グラフ種類 | サブタイプ |
|-----------|-----------|
| 横棒グラフ | 集合 / 積み上げ / 100%積み上げ |
| 縦棒グラフ | 集合 / 積み上げ / 100%積み上げ |
| 円グラフ | なし |
| 折れ線グラフ | - |
| クロス集計表 | なし（大項目+中項目が必須） |
| 表 | なし（テーブル形式: カテゴリ / 集計値 / 「レコードの一覧を表示する」リンク） |
| 面グラフ | - |
| 曲線グラフ | - |
| 曲線面グラフ | - |

## グラフ要素

- 軸ラベル（X軸: 分類項目名、Y軸: 集計値名）
- 目盛り（数値）
- 凡例（グラフ下部）
- 円グラフ: ラベルに「カテゴリ名: 値 (パーセント%)」形式

## アクション

| アクション | 場所 | 説明 |
|-----------|------|------|
| グラフ種類切替 | グラフ設定バー | ドロップダウンで9種類のグラフ即時切替 |
| サブタイプ切替 | グラフ設定バー | 集合/積み上げ/100%積み上げ（棒グラフ系のみ） |
| 保存済みグラフ切替 | ツールバー | グラフビュードロップダウンから切替 |
| 絞り込む | ツールバー | フィルタ条件設定 |
| 集計する | ツールバー | 集計ダイアログを開く |
| CSV形式で書き出す | オプションメニュー(...) | 集計結果のCSVエクスポート |
| レコードを追加する | ツールバー(+) | 新規レコード追加 |
| ドリルダウン | グラフセグメントクリック | 該当レコード一覧に遷移 |
| レコードの一覧を表示する | 表ビュー各行 | 該当レコード一覧に遷移 |

## ドリルダウン

グラフのバー/セグメントをクリックすると、該当カテゴリのレコード一覧にフィルタ遷移。URL形式: `?q=f{fieldId} in ("{value}")`

## 集計ダイアログ

「集計する」ボタンから開く。

### 構成

| セクション | 内容 |
|-----------|------|
| グラフの種類 | グラフ種類 + サブタイプ |
| 分類する項目 | 大項目（オートコンプリート付きドロップダウン）、追加ボタンで中項目追加可能 |
| 集計方法 | レコード数 / 最大値 / 最小値（数値フィールドがあれば合計・平均等も） |
| 条件 | 「すべてのレコード」or フィルタ条件（複数条件追加可能） |
| ソート | ソートキー(集計値等) + 昇順/降順 |
| プレビュー | 右側にリアルタイムプレビュー表示（「一部のデータだけを基にしています」注記） |
| おすすめ | データがある場合、自動でおすすめグラフを表示 |

### アクション

| ラベル | 動作 |
|--------|------|
| 適用 | 一時的にグラフを適用（保存なし） |
| 保存する | 「グラフの保存」ダイアログでグラフ名を付けて保存 |
| グラフ選択に戻る | グラフ種類選択画面に戻る |
