# ドメイン設計レビュー #1

## 指摘事項

### Record ドメイン
1. **LOOKUP/REFERENCE_TABLE の FieldValue 型が未定義** — App ドメインで定義された FieldType に対応する FieldValue が Record ドメインに存在しない

### AccessControl ドメイン
2. **guestSpaceCreate のデフォルト値が未記載** — デフォルト false であることを明記すべき
3. **Field ACL のデフォルト動作が不明確** — ルール未定義フィールドのデフォルト権限を明記すべき

### Space ドメイン
4. **Thread に notifyOnCreate フィールドが欠落** — スレッド作成時の通知チェックボックスに対応するフィールドがない
5. **SpaceAnnouncement の body 最大長が未定義**
6. **SpaceTemplate のフィールドが不完全** — アプリ一覧、関連リンク、お知らせ内容が含まれていない

### Notification ドメイン
7. **NotificationFilter に isBuiltIn フラグが欠落** — ビルトインフィルタの編集・削除不可を表現できない
8. **場所条件・送信者条件の結合ロジックが未定義** — OR/AND の仕様を明記すべき
9. **Notification の title/content 最大長が未定義**

### People ドメイン
10. **Profile の自動作成タイミングが曖昧** — ユーザー作成時の連動作成に統一すべき

### Message ドメイン
11. **DirectMessage のアプリ埋め込み禁止を型で表現すべき**
12. **MessageThread の participantIds ソート保証がコンストラクタに未記載**

### File ドメイン
13. **FileKey の UUID/英数字 形式の区別が型レベルで表現されていない**

### Search ドメイン
14. **PDF テキスト抽出の責務が不明確** — SearchIndexProvider の責務として明記すべき
