# プロセス管理

プロセス管理機能を有効にしたアプリでのみ使用可能。

## 作業者更新

`PUT /k/v1/record/assignees.json`

レコードの作業者を更新する。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| app | 数値または文字列 | 必須 | アプリID |
| id | 数値または文字列 | 必須 | レコードID |
| assignees | 文字列の配列 | 必須 | 作業者に設定するユーザーのログイン名の配列。空配列で作業者をクリア。最大100件。 |
| revision | 数値または文字列 | 任意 | 期待するリビジョン番号。`-1` または省略でバリデーションスキップ。 |

### レスポンス

| プロパティ | 型 | 説明 |
|---|---|---|
| revision | 文字列 | 変更後のレコードのリビジョン番号 |

### 必要なアクセス権

- アプリの管理者権限
- アプリのレコード閲覧権限
- 対象レコードの閲覧権限

### 制限事項

- プロセス管理機能を有効にしたアプリでのみ使用可能
- 変更履歴はレコードのリビジョン履歴に記録される
- 作業者を1人しか設定できないステータスに複数ユーザーを指定するとエラー

### リクエスト例

```bash
curl -X PUT 'https://sample.cybozu.com/k/v1/record/assignees.json' \
  -H 'X-Cybozu-API-Token: API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "app": 1,
    "id": 1,
    "assignees": ["user1", "user2"],
    "revision": 1
  }'
```

### レスポンス例

```json
{
  "revision": "2"
}
```

## ステータス更新（1件）

`PUT /k/v1/record/status.json`

1件のレコードのステータスを更新する（アクションを実行する）。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| app | 数値または文字列 | 必須 | アプリID |
| id | 数値または文字列 | 必須 | レコードID |
| action | 文字列 | 必須 | 実行するアクションの名前。多言語設定時はユーザーの表示言語の名前を指定。現在のステータスに同名のアクションが複数ある場合はエラー。 |
| assignee | 文字列 | 条件付き必須 | 次の作業者に設定するユーザーのログイン名。次のステータスがユーザー選択を必要とし選択可能ユーザーが存在する場合、または初期ステータスに戻す際に作業者設定がある場合に必須。 |
| revision | 数値または文字列 | 任意 | 期待するリビジョン番号。`-1` または省略でバリデーションスキップ。 |

### レスポンス

| プロパティ | 型 | 説明 |
|---|---|---|
| revision | 文字列 | ステータス変更後のリビジョン番号。アクション実行とステータス変更の2回分で **リビジョンが2つ増加** する。 |

### 必要なアクセス権（ユーザー認証）

- アプリのレコード閲覧権限
- レコード・フィールドの閲覧権限
- 作業者が未設定または自分が作業者であること（「作業者以外も実行可能」なアクションを除く）

### 必要なアクセス権（APIトークン認証）

- アプリのレコード閲覧権限
- レコード・フィールドの閲覧権限
- 作業者が未設定または「Administrator」が作業者であること

### 制限事項

- プロセス管理機能を有効にしたアプリでのみ使用可能

### リクエスト例

```bash
curl -X PUT 'https://sample.cybozu.com/k/v1/record/status.json' \
  -H 'X-Cybozu-API-Token: API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "app": 4,
    "id": 1,
    "action": "申請する",
    "assignee": "user2",
    "revision": 1
  }'
```

### レスポンス例

```json
{
  "revision": "3"
}
```

## ステータス更新（複数）

`PUT /k/v1/records/status.json`

複数のレコードのステータスを一括で更新する。

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| app | 数値または文字列 | 必須 | アプリID |
| records | オブジェクトの配列 | 必須 | ステータスを更新するレコードの一覧。最大100件。 |
| records[].id | 数値または文字列 | 必須 | レコードID |
| records[].action | 文字列 | 必須 | 実行するアクションの名前。多言語設定時はユーザーの表示言語の名前を指定。 |
| records[].assignee | 文字列 | 条件付き必須 | 次の作業者に設定するユーザーのログイン名。ステータス更新（1件）と同じ条件で必須。 |
| records[].revision | 数値または文字列 | 任意 | 期待するリビジョン番号。`-1` または省略でバリデーションスキップ。 |

### レスポンス

| プロパティ | 型 | 説明 |
|---|---|---|
| records | オブジェクトの配列 | 更新結果の配列 |
| records[].id | 文字列 | レコードID |
| records[].revision | 文字列 | ステータス変更後のリビジョン番号（アクション実行+ステータス変更で **リビジョンが2つ増加**） |

### 必要なアクセス権

ステータス更新（1件）と同様。

### 制限事項

- 一度に更新できるレコードは **最大100件**
- プロセス管理機能を有効にしたアプリでのみ使用可能

### リクエスト例

```bash
curl -X PUT 'https://sample.cybozu.com/k/v1/records/status.json' \
  -H 'X-Cybozu-API-Token: API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "app": 1,
    "records": [
      { "id": 1001, "action": "申請する", "assignee": "user2" },
      { "id": 1002, "action": "承認する" }
    ]
  }'
```

### レスポンス例

```json
{
  "records": [
    { "id": "1001", "revision": "3" },
    { "id": "1002", "revision": "9" }
  ]
}
```
