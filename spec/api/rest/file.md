# REST API: ファイル操作

## 1. ファイルのダウンロード

### メソッド・エンドポイント

```
GET /k/v1/file.json
```

- ゲストスペース: `GET /k/guest/{GUEST_SPACE_ID}/v1/file.json`

### 説明

OpenDeskのレコードに添付されたファイルをダウンロードする。ファイルキーはレコード取得APIから取得した値を指定する。

### リクエストパラメータ

| パラメータ | 型 | 必須/任意 | 説明 |
|---|---|---|---|
| fileKey | 文字列 | 必須 | ダウンロード対象ファイルのキー。レコード取得APIで取得した添付ファイルのファイルキーを指定する（例: `201202061155587E339F9067544F1A92C743460E3D12B3297`） |

### レスポンス

- レスポンスヘッダーの `Content-Type` にはダウンロード対象のMIMEタイプが含まれる
- レスポンスボディにはファイルの内容がそのまま返される（バイナリデータ）

### 認証方式

- パスワード認証
- APIトークン認証
- セッション認証
- OAuth認証

### 制限事項

- アプリのレコード閲覧権限が必要
- 対象ファイルが添付されたレコードの閲覧権限が必要
- 対象ファイルが添付されたフィールドの閲覧権限が必要
- このAPIは、OpenDesk REST APIリクエストを送信するAPI（`openDesk.api()`）では実行できない

### ファイルキーの種類

OpenDeskには2種類のファイルキーが存在する:

1. **レコード取得APIで取得するファイルキー**: レコードに添付済みのファイル用（例: `201202061155587E339F9067544F1A92C743460E3D12B3297`）。本APIではこちらを使用する。
2. **ファイルアップロードAPIで取得するファイルキー**: 一時保管領域のファイル用（UUID形式、例: `c15b3870-7505-4ab6-9d8d-b9bdbc74f5d6`）

### リクエスト例

```bash
curl -X GET 'https://sample.cybozu.com/k/v1/file.json?fileKey=201202061155587E339F9067544F1A92C743460E3D12B3297' \
  -H 'X-Cybozu-API-Token: {API_TOKEN}' \
  -o ./sample.txt
```

### レスポンス例

ファイルの内容がバイナリデータとして返される。`-o` オプションなどでファイルに保存する。

## 2. ファイルのアップロード

### メソッド・エンドポイント

```
POST /k/v1/file.json
```

### 説明

ファイルをOpenDeskの一時保管領域にアップロードする。取得したファイルキーを使用して、レコード登録・更新APIでレコードにファイルを添付できる。

### リクエスト形式

- **Content-Type**: `multipart/form-data`
- リクエストボディに `Content-Disposition` を含め、`name` に `file`、`filename` にファイル名を指定する
- 日本語ファイル名はUTF-8でエンコードする必要がある

### リクエストパラメータ

マルチパートフォームデータとしてファイル本体を送信する。明示的なJSONパラメータは不要。

| パラメータ | 型 | 必須/任意 | 説明 |
|---|---|---|---|
| file | ファイル | 必須 | アップロードするファイル（Content-Dispositionのname属性を"file"に設定） |

### レスポンス

| フィールド | 型 | 説明 |
|---|---|---|
| fileKey | 文字列 | アップロードされたファイルのファイルキー（UUID形式） |

### 認証方式

- パスワード認証
- APIトークン認証
- セッション認証
- OAuth認証

### 制限事項

- 一度にアップロードできるファイルは1件のみ
- 一時保管領域のファイルは3日間で自動削除される
- 一時保管領域のファイルもディスク使用量に含まれる
- このAPIは、OpenDesk REST APIリクエストを送信するAPI（`openDesk.api()`）では実行できない

### リクエスト例

```bash
curl -X POST 'https://sample.cybozu.com/k/v1/file.json' \
  -H 'X-Cybozu-API-Token: {API_TOKEN}' \
  -F 'file=@sample.txt'
```

日本語ファイル名の場合:

```bash
curl -X POST 'https://sample.cybozu.com/k/v1/file.json' \
  -H 'X-Cybozu-API-Token: {API_TOKEN}' \
  -F 'file=@"レポート.pdf"'
```

### レスポンス例

```json
{
  "fileKey": "c15b3870-7505-4ab6-9d8d-b9bdbc74f5d6"
}
```

### 使用フロー

1. ファイルアップロードAPIでファイルをアップロードし、`fileKey` を取得する
2. 取得した `fileKey` をレコード登録API（POST /k/v1/record.json）やレコード更新API（PUT /k/v1/record.json）の添付ファイルフィールドに指定する
3. レコードに添付されたファイルをダウンロードするには、レコード取得APIで取得したファイルキーを使用してファイルダウンロードAPI（GET /k/v1/file.json）を実行する
