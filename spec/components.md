# 共通UIコンポーネント

## ナビゲーション

### グローバルヘッダー（banner）

全画面で共通表示。上段と下段の2段構成。

**上段（banner）**:
- 「ロゴ」リンク（OpenDeskロゴ画像、`/k/` へ遷移）
- OpenDesk（h1テキスト）
- ユーザー名リンク + アイコン（ピープル画面へ）
- アカウントメニューボタン（expand）→「アカウント設定」「ログアウト」

**下段（navigation）**:

| 位置 | 要素 | 種類 | 動作 |
|------|------|------|------|
| 左 | サイドメニュー | button(toggle) | サイドパネル展開/折りたたみ |
| 左 | ポータル | link + icon | `/k/#/portal` へ遷移 |
| 左 | 通知一覧 | link + icon | `/k/#/ntf/mention` へ遷移 |
| 左 | ブックマーク | button(expand) | ブックマークパネル表示 |
| 右 | 試用期間表示 | テキスト + link | 「残りN日」+「購入」リンク（試用版のみ） |
| 右 | OpenDeskをはじめる | button | ガイドダイアログ表示（下記参照） |
| 右 | 設定 | button(expand) | 設定ドロップダウンメニュー |
| 右 | ヘルプ | button(expand) | ヘルプドロップダウンメニュー |
| 右 | 検索 | combobox + button | 全体検索/アプリ内検索/スペース内検索（コンテキストで切替） |

### 「OpenDeskをはじめる」ダイアログ

ヘッダーの「OpenDeskをはじめる」ボタンをクリックすると表示されるガイドダイアログ。

**OpenDeskをはじめるセクション:**

| 項目名 | 種類 | 説明 |
|--------|------|------|
| チュートリアル | button | OpenDeskの基本操作を体験 |
| チームメンバーを招待する | button | メンバー招待 |
| サンプルアプリを追加する | link | アプリストアからアプリ追加 |
| Excelからアプリをつくる | link | Excelファイルからアプリ作成 |

**困ったときはセクション:**

| 項目名 | 種類 | 説明 |
|--------|------|------|
| サポートコンテンツ | link | サポート情報 |
| 導入相談カフェを予約する | link | 導入相談の予約 |
| ヘルプ | link | 製品機能ヘルプ |
| お問い合わせ | link | サポート問い合わせ |

### サイドメニュー（トグル展開式ドロワー）

タブの上に「ポータル」リンクが常時表示。その下に3タブ構成:

| タブ | 内容 |
|------|------|
| スペース | 「参加中のスペース」展開ボタン + スペース一覧（リンクリスト、各スペース下に所属アプリも表示） |
| アプリ | 「すべてのアプリ」展開ボタン + アプリ一覧（リンクリスト） |
| ピープル | 「すべてのピープル」展開ボタン + ユーザー一覧（リンクリスト） |

### パンくずリスト

アプリ画面で表示。画面によって階層が変わる:

| 画面 | パンくずリスト |
|------|-------------|
| レコード一覧 | `ポータル > スペース:{スペース名} > アプリ:{アプリ名}` |
| レコード詳細 | `ポータル > スペース:{スペース名} > アプリ:{アプリ名} > 一覧:{ビュー名} > レコード:{レコード番号}` |
| レコード追加 | `ポータル > スペース:{スペース名} > アプリ:{アプリ名}` |

※ 最後の要素はリンクではなくプレーンテキスト。

## 共通パーツ

| コンポーネント | 使用箇所 | 概要 |
|--------------|---------|------|
| 検索バー（combobox） | ヘッダー、アプリ一覧 | テキスト入力 + サジェストドロップダウン。コンテキストで「全体検索」「アプリ内検索」「スペース内検索」に自動切替。サジェスト結果はカテゴリ別（ピープル、スレッド等）に表示。ピープル結果には「個人メッセージ」リンク付き。末尾に「検索結果をさらに表示」リンク |
| ドロップダウンメニュー | 設定、ヘルプ、アカウント、オプション各所 | button(expand) + menuitem リスト。separator で区切り |
| ブックマークパネル | ヘッダー | 3タブ（アプリ/検索結果/その他）+ ブックマーク追加ボタン |
| リッチテキストエディタ（WYSIWYG） | お知らせ編集、スレッド作成/コメント、ピープル投稿 | ツールバー: 宛先指定、アプリ貼り付け（一部）、ファイル添付、絵文字、太字、斜体、下線、文字色、背景色、文字サイズ、リンク、元に戻す/やり直す、リスト、左/中央揃え、フォーマット削除 |
| フォーカス展開型投稿フォーム | スレッドコメント、ピープル投稿 | 通常時はプレースホルダ表示のみ。フォーカスでツールバー + テキストエリア + キャンセル/書き込むボタンが展開 |
| listbox（フィルタ切替） | ポータルウィジェット、通知一覧、スペースアプリ一覧 | ドロップダウン選択式フィルタ |
| 未読/既読トグル | ポータル通知ウィジェット、通知一覧 | クリックで切替 |
| ウィジェットカード | ポータル（通知/スペース/アプリ） | 見出し + 操作ボタン + フィルタ + リスト |
| ページネーション | アプリ一覧 | 「X - Y (Z件中)」テーブル上下に表示 |

## モーダル・ダイアログ

| モーダル名 | トリガー | 内容 |
|-----------|---------|------|
| お知らせ編集 | スペース「スペースの本文を編集」リンク | リッチテキストエディタ + キャンセル/保存 |
| スペース設定 | スペースオプション「スペースを設定」 | 基本設定タブ + 参加メンバータブ |
| カバー画像設定 | ピープル「カバー画像を設定する」リンク | ファイルアップロード + キャンセル/保存 |
| 削除確認 | レコード削除ボタン | 「削除します。よろしいですか?」+ キャンセル/削除する |
| 絞り込み | アプリ「絞り込む」ボタン | 条件設定 + ソート設定 + キャンセル/保存/適用 |
| 集計 | アプリ「集計する」ボタン | グラフ種類選択（横棒/縦棒/円/折れ線/クロス集計表/その他）+ おすすめ |
