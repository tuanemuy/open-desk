# CSV書き出し（エクスポート）フロー

## 目的

OpenDeskアプリのレコードをCSVファイルとして書き出す機能。

## 前提条件

- ログイン済みであること
- 対象アプリへのアクセス権があること

## 書き出しフロー

| # | 画面 | 操作 | 結果 |
|---|------|------|------|
| 1 | レコード一覧 | 「オプション」ボタンをクリック | メニュー展開 |
| 2 | オプションメニュー | 「ファイルに書き出す」をクリック | 書き出し設定画面へ遷移 |
| 3 | 書き出し設定画面 | 各設定項目を構成 | - |
| 4 | 書き出し設定画面 | 「書き出す」をクリック | 「出力されたファイル」画面へ自動遷移 |
| 5 | 出力されたファイル | 処理完了を待つ | ファイルダウンロードリンクが表示 |
| 6 | 出力されたファイル | ファイル名リンクをクリック | CSVファイルをダウンロード |

## 書き出し設定画面

- URL: `/k/{appId}/exportRecord?view={viewId}`
- タイトル: 「ファイルに書き出す」

### レイアウト

1. ヘッダーバー: 「書き出す」ボタン（左）、「キャンセル」リンク（右）
2. 画面タイトル + ヘルプリンク
3. 説明文: 「レコードの一覧をCSVファイルに書き出すことができます。書き出されるレコードは、レコード一覧画面で適用されている絞り込み条件に応じます。」
4. 先頭行チェックボックス
5. 文字コード選択セクション
6. 区切り文字選択セクション
7. フィールド選択エリア（ドラッグ＆ドロップ対応）
8. 出力オプションセクション

### 設定項目

| 項目名 | 型 | 必須 | 選択肢/デフォルト値 | 備考 |
|--------|------|------|---------------------|------|
| 先頭行を項目名にする | checkbox | - | デフォルト: ON | ヘッダー行の出力有無 |
| 文字コード | dropdown | 必須 | **Shift-JIS（日本語）**[デフォルト], Latin1（西ヨーロッパ語）, GBK/GB2312（簡体字中国語）, UTF-8（Unicode）, BOM付きUTF-8（Unicode） | 5択 |
| 区切り文字 | dropdown | 必須 | **カンマ**[デフォルト], セミコロン, タブ, スペース | 4択 |
| 書き出し項目 | ドラッグ＆ドロップ/クリック | 必須（1つ以上） | デフォルトはビュー表示項目 | 「すべて追加」「すべてクリア」ボタンあり。ドラッグで並び替え可能 |
| ユーザー、組織、グループを表示名で出力する | checkbox | - | デフォルト: OFF | ONで子オプション表示 |
| 表示名の出力方法 | radio | 条件付き必須 | **表示名のみを出力**[デフォルト], 表示名を列追加して出力 | 上記チェックON時のみ表示 |
| リッチエディターをテキスト形式で出力する | checkbox | - | デフォルト: OFF | HTML除去 |
| レコードコメントを出力する | checkbox | - | デフォルト: OFF | コメントデータの含有 |

### フィールド選択エリア

- 上部: 利用可能フィールドのチップリスト（ドラッグ＆ドロップ対応）+ 「すべて追加」ボタン
- 中央: 選択済みフィールドのプレビューテーブル（各フィールドが縦カラム表示、データ型プレビュー行あり）
- 下部: 「すべてクリア」ボタン

## 出力されたファイル画面

- URL: `/k/downloadList?app={appId}`

| カラム | 説明 |
|--------|------|
| 書き出し開始日時 | タイムスタンプ |
| 書き出し対象アプリ | アプリ名（ドロップダウンでフィルター可能） |
| 種別 | 「レコード」 |
| 状況 | 「完了」等 |
| 詳細 | ファイル名（ダウンロードリンク）+ ファイルサイズ |
| 削除される日時 | 自動削除日時（3日後） |

- ファイル名形式: `{アプリ名}_{ISO8601タイムスタンプ}.csv`
- 各ファイルに「削除」ボタンあり

## バリデーション

| 条件 | 挙動 |
|------|------|
| 書き出しフィールドが0個 | 「書き出す」ボタンがdisabledになり、クリック不可 |
| 全フィールド追加済み | 「すべて追加」ボタンがdisabledになる |
| 全フィールド未追加 | 「すべてクリア」ボタンが非表示 |

## 特記事項

- **ファイル形式はCSVのみ**。Excel形式の選択肢は存在しない
- 書き出し対象レコードは、レコード一覧画面で適用中の絞り込み条件に従う
- ファイルは**3日間保持**され、その後自動削除される
- 出力ファイルは自分が実行した書き出しのみ閲覧可能
