# アプリ作成フロー

## 目的

新しいOpenDeskアプリを作成するためのフロー。複数の作成方法（はじめから作成、Excel/CSV読み込み、テンプレート、再利用）を提供する。

## 前提条件

- OpenDeskにログイン済み
- アプリ作成権限を保有（デフォルトEveryoneに許可）

## 画面遷移図

```
ポータル (/k/#/portal)
  └─ [アプリを作成する] ボタン
       │
       ▼
OpenDesk アプリストア (/k/market)
  ├─ [はじめから作成] → フォーム設計画面 (/k/admin/app/flow?app={id}#section=form)
  ├─ [Excelを読み込んで作成] → Excel読み込みウィザード (/k/import/excel) (3ステップ)
  ├─ [CSVを読み込んで作成] → CSV読み込みウィザード (/k/import/csv) (3ステップ)
  ├─ [テンプレートファイルを読み込んで作成] → ファイルアップロードダイアログ
  ├─ [ほかのアプリを再利用] → アプリ再利用一覧
  └─ [おすすめアプリ/テンプレートを追加] → 直接アプリ追加
       │
       ▼ (「はじめから作成」の場合)
アプリの設定画面
  ├─ [フォーム] タブ: フィールドのドラッグ&ドロップ
  ├─ [一覧] タブ: レコード一覧ビューの管理
  ├─ [グラフ] タブ: グラフの管理
  └─ [設定] タブ: 各種設定
       │
       ├─ [アプリを公開] → アプリが運用環境にデプロイ
       └─ [作成を中止] → 確認ダイアログ → ポータルに戻る
```

## ステップ

### 1. アプリストア

- URL: `/k/market`
- 起点: ポータルのアプリウィジェット内「アプリを作成する」ボタン

#### 作成方法の選択肢

| 選択肢 | UI要素 | 遷移先 | 説明 |
|--------|--------|--------|------|
| はじめから作成 | button | `/k/admin/app/flow?app={id}#section=form` | 空のフォーム設計画面へ。新規アプリIDが即時発行 |
| Excelを読み込んで作成 | link | `/k/import/excel` | 3ステップウィザード |
| CSVを読み込んで作成 | link | `/k/import/csv` | 3ステップウィザード |
| テンプレートファイルを読み込んで作成 | button | ファイルアップロードダイアログ | エクスポート済みテンプレートを読み込み |
| ほかのアプリを再利用 | link | アプリ再利用画面 | 既存アプリの設定を引き継いで新規作成（上限100件表示） |

#### 左サイドバー: アプリを探す

| カテゴリ | 項目 |
|----------|------|
| 業務で探す | 営業・セールス、顧客サービス・サポート、調達・購買、総務・人事、広報・マーケティング、開発・品質保証、法務・知財、情報システム、全社 |
| 業種で探す | 製造業、卸売業・小売業、情報通信業、建設業、医療・福祉、生活関連サービス業・娯楽業、人材サービス業、士業・コンサル業、不動産業・物品賃貸業、運輸業・郵便業、教育・学習支援業、宿泊業・飲食サービス業、金融業・保険業 |
| 利用シーン | モバイル、ガバナンス、プロジェクト、developer network |

#### おすすめテンプレート

| テンプレート名 | 種別 | 説明 |
|----------------|------|------|
| SFA（営業支援）パック | パック | 顧客情報、担当者情報、案件情報、活動履歴の4アプリ |
| 顧客サポートパック | パック | 顧客管理、問合せ管理、サポートFAQの3アプリ |
| 人事労務パック | パック | 従業員名簿、人事評定管理、配属・異動管理の3アプリ |
| 商品見積書パック | パック | 商品リストと連動した見積書作成 |
| 顧客リスト | 単体 | 会社名・担当者名・連絡先の管理 |
| 日報 | 単体 | 日々の業務内容・報告事項・所感の記録 |
| ファイル管理 | 単体 | 文書・資料・画像の共有。全文検索対応 |
| 案件管理 | 単体 | 案件の確度・金額・活動履歴の管理 |
| 契約書管理 | 単体 | 契約書の作成依頼から確認までワンストップ |
| 問い合わせ管理 | 単体 | 問い合わせ内容・対応履歴の記録 |
| 旅費精算申請 | 単体 | 出張旅費・経費の申請 |
| おすすめ機能体験パック | パック | ルックアップ・関連レコード・テーブル・計算・プロセス管理の5機能を体験 |

### 2. フォーム設計画面（はじめから作成）

- URL: `/k/admin/app/flow?app={id}#section=form`

#### 共通ヘッダー項目（全タブ共通）

| 項目 | 型 | 説明 |
|------|-----|------|
| アプリ名 | textbox (required) | デフォルト「新しいアプリ」。任意に変更可能 |
| アイコンの変更ボタン | button | アプリアイコンを変更 |
| アプリ管理者用メモ | link | メモを追加可能 |
| アプリを公開 | button | 運用環境にデプロイ |
| 作成を中止 | button | 確認ダイアログ「アプリを破棄します。よろしいですか？」→ ポータル |

#### タブ構成

| タブ名 | 目的 |
|--------|------|
| フォーム | フィールドの配置・設計（ドラッグ&ドロップ） |
| 一覧 | レコード一覧ビューの作成・管理。初期状態: 「（すべて）」ビュー1つ |
| グラフ | グラフの作成・管理。初期状態: 空 |
| 設定 | アプリの各種設定 |

### 3. 設定タブの構成

| カテゴリ | 設定項目 |
|----------|----------|
| 一般設定 | アイコンと説明、デザインテーマ、プロセス管理 |
| 通知 | アプリの条件通知、レコードの条件通知、リマインダーの条件通知 |
| カスタマイズ／サービス連携 | プラグイン、JavaScript/CSSでカスタマイズ、APIトークン、Webhook |
| アクセス権 | アプリ、レコード、フィールド |
| その他の設定 | カテゴリー、言語ごとの名称、レコードのタイトル、高度な設定、アクション |
| 運用管理 | アプリの動作テスト、テンプレートとしてダウンロード（公開後のみ）、スペース変更、参照アプリ一覧、メンテナンスモード、設定変更の履歴 |
| アプリの削除 | アプリを削除する |

#### アイコンと説明

| 項目 | 型 | 説明 |
|------|-----|------|
| アイコン | ラジオボタン | プリセットアイコン（48種類）またはアップロード（png/jpg/gif/bmp、最大800KB） |
| アプリの説明 | リッチテキストエディター | 太字、斜体、下線、文字色、背景色、文字サイズ、リンク、リスト、インデント、揃え、取り消し線 |

#### デザインテーマ

| テーマ名 |
|----------|
| 初期設定、レッド、グリーン、ブルー、イエロー、ブラック |

## 特記事項

- 「はじめから作成」クリック時に新しいアプリIDが即座に発行される
- 「アプリを公開」ボタンを押すまでアプリは下書き状態（他ユーザーには非表示）
- 「作成を中止」でアプリが完全に削除されポータルに戻る
- テンプレートダウンロードは公開後のみ利用可能
- Excel/CSV読み込みは3ステップウィザード（ファイル選択 → プレビュー/マッピング → 確認/完了）
- フォーム設計はドラッグ&ドロップ方式
