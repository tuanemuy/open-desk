# CSV/Excel読み込みウィザード

- アクセス元: アプリのレコード一覧画面 → 右上「オプション」ボタン → 「ファイルから読み込む」
- 認証: 必要（ファイル読み込み権限）
- セクション: アプリ

## 目的

CSV/Excelファイルからレコードを一括読み込み（インポート）する。新規追加のほか、既存レコードの更新にも対応。

## ウィザード構成

単一ページ内で4ステップが段階的に表示される（ページ遷移なし）。ステップ3のラジオボタン選択後にステップ4が動的に表示される。

---

### ステップ1: ファイルの指定

| 項目名 | 型 | 説明 |
|--------|------|------|
| ファイル選択 | ファイル入力 + 「ファイルを選択」ラベルボタン | |
| ファイル情報 | 表示のみ | ファイル名とサイズを表示 |

ファイルサイズ制限:
- Excelブック形式: 最大1MB、1,000行まで
- CSV形式: 最大100MB、10万行まで

ヘルプリンク: 「レコード登録・上書き用のファイルの記載形式（OpenDesk ヘルプ）」

---

### ステップ2: データの形式の指定

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 先頭行をファイルの列名として扱う | チェックボックス | ON | OFFにすると「1列目」「2列目」等の連番が列名になる |
| 文字コード | ドロップダウン | Shift-JIS（日本語） | Shift-JIS / Latin1（西ヨーロッパ語） / GBK/GB2312（簡体字中国語） / UTF-8（Unicode） |
| 区切り文字 | ドロップダウン | カンマ | カンマ / スペース / タブ / セミコロン |

**プレビュー表示**:
- 「読み込むファイルのプレビュー」テーブルがリアルタイム更新
- 先頭行ON: CSVヘッダーがカラムヘッダーに
- 先頭行OFF: 連番カラム名で元ヘッダー行もデータ行として表示
- 文字コード不一致時: 文字化けがプレビューに表示（エラーメッセージは出ないが視覚的に判別可能）

---

### ステップ3: 読み込み時の処理の指定

#### アプリへの反映方法（ラジオボタン）

| 選択肢 | 説明 |
|--------|------|
| レコードの追加のみ | 新規レコードの追加のみ |
| レコードの更新と追加 | 既存レコードの更新 + 新規追加 |

**「レコードの更新と追加」選択時の追加UI**:

「レコード更新の設定」セクションが動的に表示される。

| 項目名 | 型 | 説明 |
|--------|------|------|
| 更新キー | ドロップダウン | アプリのフィールドから選択（例: レコード番号） |
| 対応するファイルの列 | ドロップダウン | 更新キー指定後に有効化 |

バリデーション: 更新キー未指定時にエラーメッセージ「更新キーが指定されていません。レコードの更新には更新キーの指定が必要です。」

#### エラー検知時の処理（ラジオボタン）

| 選択肢 | 説明 |
|--------|------|
| 読み込みを継続する | エラー行のみスキップ |
| 読み込みを中止する | エラー行以降の行は読み込まない |

---

### ステップ4: データの対応付け

ステップ3のラジオボタン選択後に動的表示。

#### アプリのフィールドの対応付け

テーブル形式:

| カラム | 説明 |
|--------|------|
| アプリのフィールド | アプリで定義されたフィールド名（読み取り専用） |
| ファイルの列 | ドロップダウン: 「(指定しない)」+ CSVの列名 |
| データの形式 | 日付フィールド等で表示。日付の形式ドロップダウン（デフォルト: YYYY/MM/DD） |

サブテーブル内フィールドも対応付け可能（「テーブル名 > フィールド名」形式で表示）。

#### レコードの作成/更新情報の対応付け

| フィールド | 説明 |
|-----------|------|
| 更新者 | CSVの列名が一致すると自動マッピング |
| 作成者 | ドロップダウンで手動マッピング |
| 更新日時 | 日付形式指定あり |
| 作成日時 | 日付形式指定あり |

**自動マッピング**: CSVの列名とフィールド名/メタ情報名が完全一致する場合、自動的にマッピングされる。

#### 追加オプション

| 項目名 | 型 | デフォルト値 | 説明 |
|--------|------|-------------|------|
| 今回の設定を保存して、次回読み込み時に利用する | チェックボックス | ON | |

---

## フッター（固定表示）

| 要素 | 説明 |
|------|------|
| アプリに戻る | リンク。レコード一覧に戻る |
| キャンセル | ボタン。ウィザードを中止 |
| 読み込む | ボタン。全必須項目選択まではdisabled |

### 「読み込む」ボタンの有効化条件

1. ファイルが選択されている
2. アプリへの反映方法が選択されている
3. エラー検知時の処理が選択されている
4. 「レコードの更新と追加」の場合、更新キーが指定されている
