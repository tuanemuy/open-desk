# 通常スペース作成フロー

## 目的

通常スペース（ゲストスペースではない）を新規作成するフロー。

## 前提条件

- ログイン済みであること
- スペース作成権限があること

## アクセス経路

| 経路 | 手順 |
|------|------|
| ポータルのスペースウィジェット（主要） | ポータル画面右下「スペース」見出し横の「+」ボタン → ドロップダウンメニュー「スペースを作成」 |
| サイドメニュー | スペース一覧の表示のみ。作成ボタンは存在しない |

## 作成フロー

| # | 画面 | 操作 | 結果 |
|---|------|------|------|
| 1 | ポータル | スペースウィジェットの「+」ボタンをクリック | ドロップダウンメニュー表示（「スペースを作成」/「ゲストスペースを作成」） |
| 2 | ドロップダウン | 「スペースを作成」をクリック | テンプレート選択ダイアログ表示 |
| 3 | テンプレート選択 | 「はじめから作る」をクリック | 作成フォームダイアログに切替 |
| 4 | 作成フォーム | 基本設定・参加メンバーを入力 | - |
| 5 | 作成フォーム | 「保存」をクリック | スペース作成、スペース画面へ遷移 |

## テンプレート選択ダイアログ

- タイトル: 「スペースの作成」
- 現状は「はじめから作る」のみ（テンプレートなし）
- 「さらに表示する」リンクあり（非表示状態）

## 作成フォームダイアログ

2タブ構成: 「基本設定」タブと「参加メンバー」タブ

### 基本設定タブ

| 項目名 | 型 | 必須 | バリデーション | 備考 |
|--------|------|------|----------------|------|
| スペース名 | textbox | はい | 1〜128文字。空の場合「必須です。1文字以上、128文字以下である必要があります。」 | - |
| 参加メンバーだけにこのスペースを公開する | checkbox | いいえ | - | デフォルト: OFF（公開） |
| スペースのポータルと複数のスレッドを使用する | checkbox | いいえ | - | ヒント:「一度有効にすると元に戻せません」 |
| スペースの参加/退会、スレッドのフォロー/フォロー解除を禁止する | checkbox | いいえ | - | デフォルト: OFF |
| アプリ作成できるユーザーをスペースの管理者に限定する | checkbox | いいえ | - | ヒント付き |
| カバー画像（プリセット） | 画像選択 | いいえ | - | 28個のプリセット画像 |
| カバー画像（カスタム） | ファイル | いいえ | 最大5MB | 「参照」リンクからアップロード |

### 参加メンバータブ

| 項目名 | 型 | 必須 | 備考 |
|--------|------|------|------|
| 組織やグループから選択 | リンク | いいえ | 「ユーザーを選択」サブダイアログが開く（「組織」「グループ」タブ） |
| ユーザー検索 | textbox + 検索リンク | いいえ | テキスト入力+検索アイコン |
| メンバー一覧テーブル | table | いいえ | 列: ユーザー/組織/グループ, 管理者(checkbox), 下位組織も含める, 削除する |
| 管理者 | checkbox（各メンバー） | いいえ | 作成者はデフォルトで管理者ON |

### アクション

| ラベル | 位置 | 動作 |
|--------|------|------|
| 保存 | ダイアログ右下 | スペースを作成（バリデーションエラー時はエラー表示） |
| キャンセル | ダイアログ左下 | ダイアログを閉じる |
| Close (x) | ダイアログ右上 | ダイアログを閉じる |

## バリデーション

| 条件 | エラーメッセージ | 表示位置 |
|------|------------------|----------|
| スペース名が空 | 「必須です。 1文字以上、128文字以下である必要があります。」 | フィールド直下 + 画面右上にエラーバナー + 基本設定タブに赤いエラーインジケーター |

## ゲストスペース作成との違い

| 観点 | 通常スペース | ゲストスペース |
|------|-------------|---------------|
| メニュー | 「スペースを作成」 | 「ゲストスペースを作成」 |
| ダイアログタイトル | 「スペースの作成」 | 「ゲストスペースの作成」 |
| 公開/非公開 | 選択可能（デフォルト: 公開） | **常に非公開（変更不可）** |
| その他の項目 | 同一 | 同一 |
