# レコード削除 テストケース

UC-R07: 最大100件のレコードを一括削除する。リビジョンチェック付き。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリに1件のレコードが存在する | 1件の recordId を指定して削除する | レコードが削除される | |
| アプリに100件以上のレコードが存在する | 100件の recordId を指定して削除する（上限） | 全100件が削除される | |
| アプリにレコードが存在する | 101件の recordId を指定して削除する（上限超過） | BatchSizeLimitExceededError が返される | |
| アプリにレコードが存在する | 0件（空配列）の recordId を指定して削除する | BatchSizeLimitExceededError が返される（1件以上必要） | |
| アプリにレコードが存在する | 正しいリビジョンを revisions に指定して削除する | レコードが削除される | |
| アプリにレコードが存在する | revisions を省略して削除する | リビジョンチェックがスキップされ、レコードが削除される | |
| アプリにレコードが存在する | revisions に -1 を指定して削除する | リビジョンチェックがスキップされ、レコードが削除される | |
| あるレコードの revision が不一致 | 削除を実行する | RevisionConflictError が返され、全件ロールバックされる | |
| いずれかの recordId のレコードが存在しない | 削除を実行する | RecordNotFoundError が返され、全件ロールバックされる | |
| アプリが存在しない | 削除を実行する | AppNotFoundError が返される | |
| アプリに複数のレコードが存在する | 複数件を正しい条件で削除する | 全件がトランザクションで削除される | |
| アプリに複数のレコードが存在する | バッチの途中でエラーが発生する | 全件ロールバックされ、1件も削除されない | |
