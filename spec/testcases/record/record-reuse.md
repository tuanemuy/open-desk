# レコード再利用 テストケース

UC-R08: 既存レコードのフィールド値をコピーして新規作成用のレコードを生成する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにレコードが存在する | 有効な appId と recordId を指定してレコード再利用を実行する | コピーされたフィールド値が返される（保存はされない） | |
| アプリにレコードが存在する | レコード再利用を実行する | システムフィールド（レコードID、作成者、作成日時、更新者、更新日時）がコピーされない | |
| プロセス管理が有効なアプリにレコードが存在する | レコード再利用を実行する | ステータスが初期ステータスにリセットされる | |
| コピー元レコードが存在しない | レコード再利用を実行する | RecordNotFoundError が返される | |
| アプリが存在しない | レコード再利用を実行する | AppNotFoundError が返される | |
| テキスト、数値、日付、チェックボックス等の複数フィールド型を持つレコードが存在する | レコード再利用を実行する | 各フィールド値が正しくコピーされる | |
| サブテーブルを含むレコードが存在する | レコード再利用を実行する | サブテーブルの行データも正しくコピーされる | |
| 添付ファイルフィールドを持つレコードが存在する | レコード再利用を実行する | 添付ファイルのコピー方針に従ってフィールド値が返される | |
| レコード再利用で返されたフィールド値がある | そのフィールド値を使ってレコード作成を実行する | 新しいレコードとして正常に作成される | |
