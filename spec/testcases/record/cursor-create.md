# カーソル作成 テストケース

UC-R23: 大量データ取得用のカーソルを作成する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにレコードが存在し、ドメインのカーソルが0個 | 有効なパラメータでカーソル作成を実行する | カーソルが作成され、cursorId と totalCount が返される | |
| アプリにレコードが存在する | size を省略してカーソル作成を実行する | size=100（デフォルト）でカーソルが作成される | |
| アプリにレコードが存在する | size=1 を指定してカーソル作成を実行する（境界値：最小） | size=1 でカーソルが作成される | |
| アプリにレコードが存在する | size=500 を指定してカーソル作成を実行する（境界値：最大） | size=500 でカーソルが作成される | |
| アプリにレコードが存在する | size=0 を指定してカーソル作成を実行する（範囲外） | InvalidCursorSizeError が返される | |
| アプリにレコードが存在する | size=501 を指定してカーソル作成を実行する（範囲外） | InvalidCursorSizeError が返される | |
| アプリにレコードが存在する | size=-1 を指定してカーソル作成を実行する（範囲外） | InvalidCursorSizeError が返される | |
| 同一ドメインでカーソルが9個存在する | カーソル作成を実行する | 10個目のカーソルが正常に作成される | |
| 同一ドメインでカーソルが10個存在する | カーソル作成を実行する | CursorLimitExceededError が返される | |
| アプリにレコードが存在する | query を指定してカーソル作成を実行する | クエリ条件に一致するレコードの totalCount が返される | |
| アプリにレコードが存在する | query を省略してカーソル作成を実行する | 全レコードを対象としたカーソルが作成される | |
| アプリにレコードが存在する | fields を指定してカーソル作成を実行する | 指定フィールドのみを返すカーソルが作成される | |
| アプリにレコードが存在する | 構文が不正なクエリを指定する | QuerySyntaxError が返される | |
| アプリにレコードが存在する | カーソル作成が5分以内に完了しない | CursorCreationTimeoutError が返される | |
