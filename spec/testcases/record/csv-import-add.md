# CSVインポート（追加のみ） テストケース

UC-R19: CSVファイルからレコードを新規追加する（ADD_ONLY モード）。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリが存在し、有効なCSVファイルがある | 有効なCSVファイルとフィールドマッピングを指定してインポートを実行する | CsvImportJob が作成され、jobId が返される | |
| アプリが存在し、有効なCSVファイルがある | インポートを実行する | importMode が ADD_ONLY、updateKey が null でジョブが生成される | |
| アプリが存在し、有効なCSVファイルがある | インポートが完了する | ジョブのステータスが COMPLETED になり、processedCount と errorCount が記録される | |
| アプリが存在する | CSVファイルのサイズが100MB（上限）のファイルを指定する | 正常にインポートが開始される | |
| アプリが存在する | CSVファイルのサイズが100MBを超えるファイルを指定する | FileSizeLimitExceededError が返される | |
| アプリが存在する | Excelファイルのサイズが1MB（上限）のファイルを指定する | 正常にインポートが開始される | |
| アプリが存在する | Excelファイルのサイズが1MBを超えるファイルを指定する | FileSizeLimitExceededError が返される | |
| アプリが存在する | CSVファイルの行数が100,000行（上限）のファイルを指定する | 正常にインポートが開始される | |
| アプリが存在する | CSVファイルの行数が100,000行を超えるファイルを指定する | FileSizeLimitExceededError が返される | |
| アプリが存在する | Excelファイルの行数が1,000行（上限）のファイルを指定する | 正常にインポートが開始される | |
| アプリが存在する | Excelファイルの行数が1,000行を超えるファイルを指定する | FileSizeLimitExceededError が返される | |
| アプリが存在する | fieldMappings が空のリストを指定する | FieldMappingEmptyError が返される | |
| アプリが存在しない | インポートを実行する | AppNotFoundError が返される | |
| アプリが存在し、errorHandling=STOP のファイルにバリデーションエラーがある | インポートを実行する | エラー発生時点でインポートが停止し、ジョブが FAILED になる | |
| アプリが存在し、errorHandling=CONTINUE のファイルにバリデーションエラーがある | インポートを実行する | エラー行をスキップしてインポートが継続し、errorCount が記録される | |
| アプリが存在する | encoding=UTF8 を指定してインポートする | UTF-8 エンコーディングでCSVが正しく解析される | |
| アプリが存在する | encoding=SHIFT_JIS を指定してインポートする | Shift_JIS エンコーディングでCSVが正しく解析される | |
| アプリが存在する | delimiter=COMMA を指定してインポートする | カンマ区切りでCSVが正しく解析される | |
| アプリが存在する | delimiter=TAB を指定してインポートする | タブ区切りでCSVが正しく解析される | |
