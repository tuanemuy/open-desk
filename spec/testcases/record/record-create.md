# レコード作成（単体） テストケース

UC-R01: 1件のレコードを新規作成する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリが存在し、必須フィールドが定義されている | 全必須フィールドに有効な値を指定してレコード作成を実行する | レコードが作成され、recordId と revision=1 が返される | |
| アプリが存在し、任意フィールドのみ定義されている | 任意フィールドに値を指定してレコード作成を実行する | レコードが作成され、recordId と revision=1 が返される | |
| アプリが存在する | 複数フィールド（テキスト、数値、日付、チェックボックス等）に値を指定してレコード作成を実行する | 各フィールド値が正しく保存される | |
| アプリが存在する | レコード作成を実行する | 作成者（creatorId）と作成日時（createdAt）がシステムにより自動設定される | |
| アプリが存在する | レコード作成を実行する | RecordHistory がバージョン1で生成され、changedFields が空で保存される | |
| アプリが存在しない | レコード作成を実行する | AppNotFoundError が返される | |
| アプリが存在する | 必須フィールドを未入力でレコード作成を実行する | FieldValidationError が返される | |
| アプリが存在する | フィールド値の型が不一致（数値フィールドに文字列等）でレコード作成を実行する | FieldValidationError が返される | |
| アプリが存在する | 選択肢フィールドに存在しない選択肢を指定してレコード作成を実行する | FieldValidationError が返される | |
| アプリが存在する | 更新不可フィールド（システムフィールド等）に値を書き込もうとする | InvalidFieldUpdateError が返される | |
| アプリが存在し、重複禁止フィールドが定義されている | 既存レコードと同じ値を重複禁止フィールドに指定する | FieldValidationError（一意性違反）が返される | |
| アプリが存在し、重複禁止フィールドが定義されている | 既存レコードと異なる値を重複禁止フィールドに指定する | レコードが正常に作成される | |
| アプリが存在する | fieldValues が空のマップでレコード作成を実行する | FieldValidationError が返される（1つ以上のフィールド値が必要） | |
| アプリが存在する | 文字列フィールドに最大長の値を指定してレコード作成を実行する | レコードが正常に作成される | |
| アプリが存在する | 文字列フィールドに最大長を超える値を指定してレコード作成を実行する | FieldValidationError が返される | |
| アプリが存在する | 数値フィールドに上限値を指定してレコード作成を実行する | レコードが正常に作成される | |
| アプリが存在する | 数値フィールドに上限値を超える値を指定してレコード作成を実行する | FieldValidationError が返される | |
| アプリが存在する | サブテーブルを含むフィールド値でレコード作成を実行する | サブテーブルの行が正しく保存される | |
| アプリが存在する | 存在しないフィールドコードを指定してレコード作成を実行する | FieldValidationError が返される | |
