# ワーカー割り当て変更 テストケース

UC-R11: レコードの作業者を変更する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロセス管理が有効なアプリにレコードが存在する | 1名の作業者を指定してワーカー割り当て変更を実行する | 作業者が設定され、revision が返される | |
| プロセス管理が有効なアプリにレコードが存在する | 100名の作業者を指定してワーカー割り当て変更を実行する（上限） | 全100名が作業者として設定される | |
| プロセス管理が有効なアプリにレコードが存在する | 101名の作業者を指定する（上限超過） | TooManyAssigneesError が返される | |
| プロセス管理が有効なアプリにレコードが存在し、作業者が設定されている | 空配列を指定してワーカー割り当て変更を実行する | 作業者がクリアされる | |
| プロセス管理が有効なアプリにレコードが存在する | 正しいリビジョンを指定してワーカー割り当て変更を実行する | 作業者が変更される | |
| プロセス管理が有効なアプリにレコードが存在する | revision=-1 を指定してワーカー割り当て変更を実行する | リビジョンチェックがスキップされる | |
| プロセス管理が有効なアプリにレコードが存在する | revision を省略してワーカー割り当て変更を実行する | リビジョンチェックがスキップされる | |
| レコードが存在しない | ワーカー割り当て変更を実行する | RecordNotFoundError が返される | |
| レコードの revision が不一致 | ワーカー割り当て変更を実行する | RevisionConflictError が返される | |
| プロセス管理が無効なアプリにレコードが存在する | ワーカー割り当て変更を実行する | ProcessNotEnabledError が返される | |
| プロセス管理が有効なアプリにレコードが存在する | 既存の作業者リストを別の作業者リストに置き換える | 新しい作業者リストで上書きされる | |
| プロセス管理が有効なアプリにレコードが存在する | 0名の作業者（空配列）を指定する | 作業者数が0となり正常に完了する | |
