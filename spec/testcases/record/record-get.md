# レコード取得（単体） テストケース

UC-R03: アプリIDとレコードIDで1件のレコードを取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリとレコードが存在する | 有効な appId と recordId を指定してレコード取得を実行する | 対象レコードの全フィールド値が返される | |
| アプリは存在するが、指定の recordId のレコードが存在しない | レコード取得を実行する | RecordNotFoundError が返される | |
| アプリが存在しない | レコード取得を実行する | AppNotFoundError が返される | |
| アプリとレコードが存在する | 複数のフィールド型（テキスト、数値、日付、添付ファイル等）を持つレコードを取得する | 全フィールド値が正しい型で返される | |
| アプリとレコードが存在し、レコードが更新されている | レコード取得を実行する | 最新のフィールド値とリビジョンが返される | |
| アプリとレコードが存在する | サブテーブルを含むレコードを取得する | サブテーブルの行データが正しく返される | |
| 別のアプリに属するレコードIDを指定する | レコード取得を実行する | RecordNotFoundError が返される | |
