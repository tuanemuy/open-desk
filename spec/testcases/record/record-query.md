# レコード取得（クエリ） テストケース

UC-R04: クエリ条件に一致する複数レコードを取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにレコードが複数存在する | query を省略してレコード取得を実行する | 全レコード（最大500件）が返される | |
| アプリにレコードが複数存在する | 有効なクエリ条件を指定してレコード取得を実行する | 条件に一致するレコードのみが返される | |
| アプリにレコードが複数存在する | fields を指定してレコード取得を実行する | 指定されたフィールドのみが返される | |
| アプリにレコードが複数存在する | fields を省略してレコード取得を実行する | 全フィールドが返される | |
| アプリにレコードが複数存在する | totalCount=true を指定してレコード取得を実行する | records と totalCount が返される | |
| アプリにレコードが複数存在する | totalCount=false を指定してレコード取得を実行する | records が返され、totalCount は null | |
| アプリにレコードが500件以上存在する | クエリで limit を省略する | 最大500件が返される | |
| アプリにレコードが存在する | クエリに order by 句を指定する | 指定された順序でレコードが返される | |
| アプリにレコードが存在する | クエリに offset を指定する | 指定された位置からレコードが返される | |
| アプリにレコードが存在する | クエリに offset=10000 を指定する（上限） | 正常にレコードが返される | |
| アプリにレコードが存在する | クエリに offset=10001 を指定する（上限超過） | QueryValidationError が返される | |
| アプリにレコードが存在する | クエリに関数（LOGINUSER(), NOW() 等）を含める | 関数が executionContext に基づいて解決され、正しい結果が返される | |
| アプリが存在する | 構文が不正なクエリを指定する | QuerySyntaxError が返される | |
| アプリが存在する | 不正な演算子を含むクエリを指定する | QueryValidationError が返される | |
| アプリが存在しない | クエリを実行する | AppNotFoundError が返される | |
| アプリにレコードが存在しない | クエリを実行する | 空の records 配列が返される | |
| アプリにレコードが存在する | クエリに存在しないフィールドコードを指定する | QueryValidationError が返される | |
| アプリにレコードが複数存在する | 複合条件（AND/OR）のクエリを指定する | 条件に一致するレコードのみが返される | |
