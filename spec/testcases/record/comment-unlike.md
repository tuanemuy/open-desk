# コメントいいね取消 テストケース

UC-R16: コメントのいいねを取り消す。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| コメントが存在し、ユーザーがいいね済み | いいねを取り消す | いいねが削除され、正常に完了する | |
| コメントが存在し、ユーザーがいいねしていない | いいねを取り消す | 何もせず正常に完了する（冪等） | |
| コメントが存在しない | いいねを取り消す | CommentNotFoundError が返される | |
| コメントに複数ユーザーのいいねがある | 1ユーザーがいいねを取り消す | 対象ユーザーのいいねのみが削除され、他のユーザーのいいねは残る | |
| コメントが存在し、ユーザーがいいね済み | いいねを取り消した後、再度取り消しを実行する | 何もせず正常に完了する（冪等） | |
