# プロセスステータス変更（単体） テストケース

UC-R09: アクションを実行してレコードのプロセスステータスを遷移させる。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロセス管理が有効なアプリにレコードが存在し、現在のステータスから遷移可能なアクションがある | 有効なアクション名と正しいリビジョンを指定してステータス変更を実行する | ステータスが遷移し、リビジョンが2増加する（アクション実行 + ステータス変更） | |
| プロセス管理が有効なアプリにレコードが存在する | revision=-1 を指定してステータス変更を実行する | リビジョンチェックがスキップされ、ステータスが遷移する | |
| プロセス管理が有効なアプリにレコードが存在する | revision を省略してステータス変更を実行する | リビジョンチェックがスキップされ、ステータスが遷移する | |
| 遷移先ステータスが作業者を要求する | assignee を指定してステータス変更を実行する | 作業者が設定され、ステータスが遷移する | |
| 遷移先ステータスが作業者を要求する | assignee を未指定でステータス変更を実行する | AssigneeRequiredError が返される | |
| レコードが存在しない | ステータス変更を実行する | RecordNotFoundError が返される | |
| レコードの revision が不一致 | ステータス変更を実行する | RevisionConflictError が返される | |
| 現在のステータスから指定アクションが実行不可 | ステータス変更を実行する | InvalidStatusTransitionError が返される | |
| 同名のアクションが複数定義されている | 該当アクション名でステータス変更を実行する | DuplicateActionError が返される | |
| プロセス管理が有効なアプリにレコードが存在する | 存在しないアクション名を指定する | InvalidStatusTransitionError が返される | |
| 遷移先ステータスが作業者を要求しない | assignee を指定してステータス変更を実行する | assignee は無視され、ステータスが正常に遷移する | |
