# プロセスステータス変更（一括） テストケース

UC-R10: 最大100件のレコードのプロセスステータスを一括変更する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロセス管理が有効なアプリに複数のレコードが存在し、全レコードが同一アクションで遷移可能 | 有効なアクション名を指定して一括ステータス変更を実行する | 全レコードのステータスが遷移し、各リビジョンが2増加する | |
| アプリにレコードが存在する | 100件のレコードを一括ステータス変更する（上限） | 全100件のステータスが遷移する | |
| アプリにレコードが存在する | 101件のレコードを一括ステータス変更する（上限超過） | BatchSizeLimitExceededError が返される | |
| アプリにレコードが存在する | 0件（空配列）を一括ステータス変更する | BatchSizeLimitExceededError が返される（1件以上必要） | |
| 遷移先ステータスが作業者を要求する | assignee を指定して一括ステータス変更を実行する | 全レコードに作業者が設定される | |
| 遷移先ステータスが作業者を要求する | assignee を未指定で一括ステータス変更を実行する | AssigneeRequiredError が返される | |
| いずれかのレコードが存在しない | 一括ステータス変更を実行する | RecordNotFoundError が返される | |
| いずれかのレコードでリビジョン不一致 | 一括ステータス変更を実行する | RevisionConflictError が返される | |
| いずれかのレコードで現在のステータスから指定アクションが実行不可 | 一括ステータス変更を実行する | InvalidStatusTransitionError が返される | |
| 全レコードで revision を省略する | 一括ステータス変更を実行する | リビジョンチェックがスキップされ、全レコードのステータスが遷移する | |
| 異なるステータスにある複数のレコードに対して同一アクションを実行する | 一括ステータス変更を実行する | 全レコードで遷移可能であれば成功し、不可能なレコードがあればエラーとなる | |
