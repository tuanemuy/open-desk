# 過去バージョンへの復元 テストケース

UC-R18: レコードを過去のバージョンに復元する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| レコードが複数バージョンの履歴を持つ | 有効なバージョン番号を指定して復元を実行する | レコードのフィールド値が指定バージョンの状態に復元される | |
| レコードが複数バージョンの履歴を持つ | 復元を実行する | リビジョンが増加し、新しい RecordHistory エントリが生成される | |
| レコードが複数バージョンの履歴を持つ | 復元を実行する | 既存の変更履歴は書き換えられない | |
| レコードが複数バージョンの履歴を持つ | 復元を実行する | modifierId と updatedAt が設定される | |
| レコードが存在する | version=1 を指定して復元を実行する（最古のバージョン） | バージョン1の状態に復元される | |
| レコードが存在しない | 復元を実行する | RecordNotFoundError が返される | |
| レコードが存在するが、指定バージョンの履歴が存在しない | 復元を実行する | HistoryVersionNotFoundError が返される | |
| レコードが存在する | version=0 を指定して復元を実行する（不正なバージョン番号） | HistoryVersionNotFoundError が返される | |
| レコードが存在する | 現在のバージョンに存在しないフィールドが過去バージョンに含まれる | 復元フィールド値のバリデーションで FieldValidationError が返される | |
| レコードが複数バージョンの履歴を持つ | 最新バージョンと同じバージョンを指定して復元する | 実質的に変更なしだが、新しいバージョンとして履歴が生成される | |
| レコードが存在し、復元対象バージョンのフィールド値が正しい | 復元を実行した後、再度変更履歴を取得する | 復元エントリが最新の履歴として含まれている | |
