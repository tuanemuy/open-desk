# カーソル削除 テストケース

UC-R25: 不要になったカーソルを明示的に削除する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| カーソルが存在する | カーソル削除を実行する | カーソルが削除される | |
| カーソルが存在しない | カーソル削除を実行する | CursorNotFoundError が返される | |
| カーソルが存在し、まだレコードが残っている（全件取得前） | カーソル削除を実行する | カーソルが削除される（途中破棄） | |
| カーソルが存在する | カーソルを削除した後、同じ cursorId で再度削除を試みる | CursorNotFoundError が返される | |
| カーソルが存在する | カーソルを削除した後、同じ cursorId でレコード取得を試みる | CursorNotFoundError が返される | |
| 有効期限切れのカーソルが存在する | カーソル削除を実行する | カーソルが削除される（期限切れでも削除は可能） | |
