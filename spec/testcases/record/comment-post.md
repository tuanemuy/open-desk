# コメント投稿 テストケース

UC-R12: レコードにプレーンテキストコメントを投稿する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにレコードが存在する | 有効なテキスト（1文字以上）を指定してコメントを投稿する | コメントが作成され、commentId が返される | |
| アプリにレコードが存在する | メンション無しでコメントを投稿する | コメントがメンション無しで正常に作成される | |
| アプリにレコードが存在する | 1件のメンションを含むコメントを投稿する | メンション付きコメントが作成される | |
| アプリにレコードが存在する | 10件のメンションを含むコメントを投稿する（上限） | メンション10件付きコメントが正常に作成される | |
| アプリにレコードが存在する | 11件のメンションを含むコメントを投稿する（上限超過） | TooManyMentionsError が返される | |
| アプリにレコードが存在する | テキストが空文字でコメントを投稿する | CommentTextEmptyError が返される | |
| アプリにレコードが存在する | 1文字のテキストでコメントを投稿する（境界値：最小） | コメントが正常に作成される | |
| アプリにレコードが存在する | 65,535文字のテキストでコメントを投稿する（境界値：最大） | コメントが正常に作成される | |
| アプリにレコードが存在する | 65,536文字のテキストでコメントを投稿する（上限超過） | CommentTextTooLongError が返される | |
| レコードが存在しない | コメントを投稿する | RecordNotFoundError が返される | |
| アプリにレコードが存在する | プレーンテキストのみでHTMLタグを含まないコメントを投稿する | コメントがプレーンテキストとして保存される | |
| アプリにレコードが存在する | creatorId を指定してコメントを投稿する | 投稿者が正しく設定される | |
