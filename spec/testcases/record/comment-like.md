# コメントいいね テストケース

UC-R15: コメントにいいねを付与する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| コメントが存在し、ユーザーがまだいいねしていない | いいねを付与する | いいねが追加され、正常に完了する | |
| コメントが存在し、ユーザーが既にいいね済み | 同じユーザーで再度いいねを付与する | 何もせず正常に完了する（冪等） | |
| コメントが存在しない | いいねを付与する | CommentNotFoundError が返される | |
| コメントが存在する | 異なる複数のユーザーがそれぞれいいねを付与する | 各ユーザーのいいねが個別に記録される | |
| 自分が投稿したコメントが存在する | 自分自身がいいねを付与する | いいねが正常に追加される（自分のコメントへのいいねを許容） | |
