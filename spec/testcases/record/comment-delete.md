# コメント削除 テストケース

UC-R13: 自分が投稿したコメントを削除する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 自分が投稿したコメントが存在する | 自分の requesterId を指定してコメント削除を実行する | コメントが削除される | |
| 他のユーザーが投稿したコメントが存在する | 自分の requesterId を指定してコメント削除を実行する | CommentPermissionDeniedError が返される | |
| コメントが存在しない | コメント削除を実行する | CommentNotFoundError が返される | |
| コメントが存在するが、指定した recordId と関連付けられていない | コメント削除を実行する | CommentNotFoundError が返される | |
| コメントが存在するが、指定した appId と関連付けられていない | コメント削除を実行する | CommentNotFoundError が返される | |
| 自分が投稿したコメントが存在する | コメントを削除した後、同じコメントIDで再度削除を試みる | CommentNotFoundError が返される | |
