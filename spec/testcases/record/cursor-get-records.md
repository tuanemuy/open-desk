# カーソルからレコード取得 テストケース

UC-R24: カーソルを使用してレコードをバッチ取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| カーソルが存在し、有効期限内でまだレコードが残っている | レコード取得を実行する | size 件分のレコードが返され、next=true となる | |
| カーソルが存在し、残りレコードが size 未満 | レコード取得を実行する | 残り全件が返され、next=false となる | |
| カーソルが存在し、次のバッチで全件取得完了する | レコード取得を実行する | レコードが返され、next=false となり、カーソルが自動削除される | |
| カーソルが存在し、有効期限内 | レコード取得を実行する | カーソルのアクセス時刻が更新される（touch） | |
| カーソルが存在し、前回アクセスから10分以内 | レコード取得を実行する | 正常にレコードが返される | |
| カーソルが存在し、前回アクセスから10分超過 | レコード取得を実行する | CursorExpiredError が返される | |
| カーソルが存在しない | レコード取得を実行する | CursorNotFoundError が返される | |
| カーソルで全件取得が完了済み（自動削除後） | 同じ cursorId でレコード取得を実行する | CursorNotFoundError が返される | |
| カーソルが作成された直後 | 初回のレコード取得を実行する | 最初の size 件が返される | |
| カーソルが存在し、有効期限内 | 連続してレコード取得を繰り返す | オフセットが順次進み、全レコードを走査できる | |
