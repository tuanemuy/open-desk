# CSVエクスポート テストケース

UC-R21: レコードをCSVファイルとして非同期で書き出す。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにレコードが存在する | 有効な exportFields を指定してエクスポートを実行する | CsvExportJob が作成され、jobId が返される | |
| アプリにレコードが存在する | エクスポートを実行する | ジョブの expiresAt が createdAt の3日後に設定される | |
| アプリにレコードが存在する | エクスポートジョブが完了する | ステータスが COMPLETED になり、fileName と fileSize が記録される | |
| アプリにレコードが存在する | viewId を指定してエクスポートを実行する | ビューの絞り込み条件に基づいたレコードのみがエクスポートされる | |
| アプリにレコードが存在する | viewId を省略してエクスポートを実行する | 全レコードがエクスポートされる | |
| アプリにレコードが存在する | includeHeader=true を指定してエクスポートする | ヘッダ行を含むCSVファイルが生成される | |
| アプリにレコードが存在する | includeHeader=false を指定してエクスポートする | ヘッダ行を含まないCSVファイルが生成される | |
| アプリにレコードが存在する | includeComments=true を指定してエクスポートする | コメントを含むCSVファイルが生成される | |
| アプリにレコードが存在する | includeComments=false（デフォルト）でエクスポートする | コメントを含まないCSVファイルが生成される | |
| アプリが存在する | exportFields が空のリストを指定する | NoFieldsSelectedError が返される | |
| アプリが存在しない | エクスポートを実行する | AppNotFoundError が返される | |
| アプリにレコードが存在する | エクスポート処理中にエラーが発生する | ジョブのステータスが FAILED になる | |
| アプリにレコードが存在する | encoding=UTF8, delimiter=COMMA を指定してエクスポートする | UTF-8 カンマ区切りのCSVファイルが生成される | |
| アプリにレコードが存在する | encoding=SHIFT_JIS, delimiter=TAB を指定してエクスポートする | Shift_JIS タブ区切りのCSVファイルが生成される | |
| アプリにレコードが存在する | エクスポートを実行する | 非同期で処理され、jobId が即座に返される（完了を待たない） | |
