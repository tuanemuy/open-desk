# 変更履歴取得 テストケース

UC-R17: レコードの変更履歴一覧を取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| レコードが存在し、複数回更新されている | 変更履歴取得を実行する | 全ての変更履歴が新しいバージョン順で返される | |
| レコードが存在し、1回も更新されていない（作成直後） | 変更履歴取得を実行する | バージョン1の変更履歴（作成時の履歴）のみが返される | |
| レコードが存在し、フィールド値が変更されている | 変更履歴取得を実行する | 各バージョンの FieldDiff が正しく記録されている | |
| レコードが存在しない | 変更履歴取得を実行する | RecordNotFoundError が返される | |
| レコードが存在し、過去バージョンへの復元が行われている | 変更履歴取得を実行する | 復元操作も新しいバージョンとして履歴に含まれている | |
| レコードが存在し、プロセスステータスが変更されている | 変更履歴取得を実行する | ステータス変更の履歴も含まれている | |
