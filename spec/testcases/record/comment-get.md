# コメント取得 テストケース

UC-R14: レコードに紐づくコメントを取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| レコードに複数のコメントが存在する | デフォルト設定（order=desc, offset=0, limit=10）でコメント取得を実行する | 最新10件のコメントが降順で返される | |
| レコードに複数のコメントが存在する | order=asc を指定してコメント取得を実行する | コメントが昇順（古い順）で返される | |
| レコードに複数のコメントが存在する | order=desc を指定してコメント取得を実行する | コメントが降順（新しい順）で返される | |
| レコードに15件のコメントが存在する | offset=0, limit=10 でコメント取得を実行する | 10件のコメントが返され、older=true となる | |
| レコードに15件のコメントが存在する | offset=10, limit=10 でコメント取得を実行する | 5件のコメントが返され、newer=true, older=false となる | |
| レコードに5件のコメントが存在する | offset=0, limit=10 でコメント取得を実行する | 5件のコメントが返され、older=false, newer=false となる | |
| レコードにコメントが存在しない | コメント取得を実行する | 空の comments 配列が返され、older=false, newer=false となる | |
| レコードが存在しない | コメント取得を実行する | RecordNotFoundError が返される | |
| レコードに複数のコメントが存在する | limit を省略してコメント取得を実行する | デフォルトの10件が返される | |
| レコードに複数のコメントが存在する | limit=10 を超える値を指定する | 最大10件が返される | |
| レコードに1件のコメントが存在する | offset=0, limit=10 でコメント取得を実行する | 1件のコメントが返され、older=false, newer=false となる | |
