# フィールド更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにフィールドが存在する | label を変更する | ラベルが変更され、fieldId・fieldCode・label・fieldType・updatedAt が返却される | |
| アプリにフィールドが存在する | fieldCode を新しい一意な値に変更する | フィールドコードが変更される | |
| アプリにフィールドが存在する | noLabel を true に変更する | ラベル非表示が設定される | |
| アプリにフィールドが存在する | required を true に変更する（設定可能なフィールドタイプ） | 必須設定が有効になる | |
| アプリにフィールドが存在する | unique を true に変更する（設定可能なフィールドタイプ） | ユニーク設定が有効になる | |
| アプリにフィールドが存在する | defaultValue を設定する | 初期値が設定される | |
| アプリにフィールドが存在する | defaultValue を null に設定する | 初期値がクリアされる | |
| アプリにフィールドが存在する | properties を変更する | プロパティが変更される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| - | 存在しない fieldId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | フィールドを更新する | ビジネスルール違反エラーが返される | |
| システムフィールドが存在する | システムフィールドの fieldCode を変更する | ビジネスルール違反エラーが返される | |
| 同一 fieldCode のフィールドが既に存在する | その fieldCode に変更する | ビジネスルール違反エラーが返される | |
| 保存後にイミュータブルなプロパティを持つフィールド | そのプロパティを変更する | ビジネスルール違反エラーが返される | |
| - | required を設定できないフィールドタイプに required: true を設定する | バリデーションエラーが返される | |
| - | unique を設定できないフィールドタイプに unique: true を設定する | バリデーションエラーが返される | |
| - | properties にフィールドタイプと不一致の値を指定する | バリデーションエラーが返される | |
