# アプリグループ更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリグループ管理権限（appGroupManageable）を持つ、アプリグループが存在する | name のみ変更して更新する | name が更新された DTO が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する、他にデフォルトグループがある | isDefault を true に変更して更新する | isDefault が true に設定され、既存のデフォルトグループの isDefault が false に変更される | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在しデフォルトグループである | isDefault を false に変更して更新する | isDefault が false に変更された DTO が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | appIds を指定して更新する（有効なアプリ ID リスト） | appIds が一括置換された DTO が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | appIds を空配列で更新する | appIds が空配列に置換された DTO が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | name, isDefault, appIds をすべて指定して更新する | すべてのフィールドが更新された DTO が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | 何も指定せずに更新する | 変更されず、現在のアプリグループの DTO が返る | |
| 操作者がアプリグループ管理権限を持つ | name を1文字に変更する | 正常に更新される（下限境界値） | |
| 操作者がアプリグループ管理権限を持つ | name を128文字に変更する | 正常に更新される（上限境界値） | |
| 操作者がアプリグループ管理権限を持たない一般ユーザー | アプリグループを更新する | SystemPermissionDeniedError が返る | |
| 操作者がアプリグループ管理権限を持つ | 存在しない appGroupId を指定して更新する | AppGroupNotFoundError が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | name を空文字に変更する | EmptyAppGroupNameError が返る | |
| 操作者がアプリグループ管理権限を持つ、アプリグループが存在する | name を129文字に変更する | AppGroupNameTooLongError が返る | |
