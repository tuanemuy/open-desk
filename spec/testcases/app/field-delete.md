# フィールド削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリにユーザー作成フィールドが存在し、他から参照されていない | フィールドを削除する | フィールドが削除され、deletedFieldIds が返却される | |
| グループフィールドが存在し、内部に3つのフィールドがある | グループフィールドを削除する | グループと内部フィールド計4件が連鎖削除される | |
| サブテーブルフィールドが存在し、内部に2つのフィールドがある | サブテーブルフィールドを削除する | サブテーブルと内部フィールド計3件が連鎖削除される | |
| フィールド削除後 | フォームレイアウトを確認する | レイアウトが自動調整されている | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| - | 存在しない fieldId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | フィールドを削除する | ビジネスルール違反エラーが返される | |
| システムフィールド（レコード番号等） | 削除する | ビジネスルール違反エラーが返される | |
| ルックアップフィールドから参照されているフィールド | 削除する | ビジネスルール違反エラーが返される | |
| 関連レコード一覧から参照されているフィールド | 削除する | ビジネスルール違反エラーが返される | |
