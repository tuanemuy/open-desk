# アプリ作成（白紙） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリ数が上限未満 | name のみ指定して白紙アプリを作成する | PREVIEW 状態のアプリが作成され、appId・name・status="PREVIEW"・revision・createdAt が返却される | |
| スペースが存在する | spaceId を指定して白紙アプリを作成する | 指定スペースに紐づくアプリが作成される | |
| スペースとスレッドが存在する | spaceId・threadId を指定して白紙アプリを作成する | 指定スペースのスレッドに紐づくアプリが作成される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | name に65文字以上の文字列を送信する | バリデーションエラーが返される | |
| - | name にちょうど1文字を指定する | アプリが正常に作成される（境界値） | |
| - | name にちょうど64文字を指定する | アプリが正常に作成される（境界値） | |
| 存在しないスペースのID | 存在しない spaceId を指定して作成する | バリデーションエラーが返される | |
| spaceId が未指定 | threadId のみを指定して作成する | バリデーションエラーが返される（spaceId なしに threadId は設定不可） | |
| アプリ数が上限（1,000件）に達している | 白紙アプリを作成する | ビジネスルール違反エラーが返される | |
| アプリ数が999件 | 白紙アプリを作成する | アプリが正常に作成される（境界値：上限直前） | |
