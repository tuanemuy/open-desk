# アプリ取消（リバート） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリに未デプロイの変更がある | アプリをリバートする | preview 環境の変更が破棄され、production 設定に復元される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | リバートする | ビジネスルール違反エラーが返される | |
| アプリに未デプロイの変更がない | リバートする | ビジネスルール違反エラーが返される | |
| フィールド追加・ビュー変更など複数の未デプロイ変更がある | リバートする | すべての変更が破棄され、最後のデプロイ時点の設定に戻る | |
