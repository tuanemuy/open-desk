# アプリグループ一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリグループ閲覧権限（appGroupViewable）を持つ、アプリグループが複数件存在する | デフォルトの offset・limit でアプリグループ一覧を取得する | アプリグループ一覧と totalCount が返る | |
| 操作者がアプリグループ管理権限（appGroupManageable）を持つ | アプリグループ一覧を取得する | 管理権限でもアクセス可能で、アプリグループ一覧が返る | |
| 操作者がアプリグループ閲覧権限を持つ、アプリグループが0件 | アプリグループ一覧を取得する | 空配列と totalCount: 0 が返る | |
| 操作者がアプリグループ閲覧権限を持つ、アプリグループが150件存在する | offset: 0, limit: 100 で取得する | 先頭100件が返り、totalCount: 150 が返る | |
| 操作者がアプリグループ閲覧権限を持つ、アプリグループが150件存在する | offset: 100, limit: 100 で取得する | 残り50件が返り、totalCount: 150 が返る | |
| 操作者がアプリグループ閲覧権限を持つ、デフォルトグループと通常グループが存在する | アプリグループ一覧を取得する | isDefault の値が正しく含まれたアプリグループ一覧が返る | |
| 操作者がアプリグループ閲覧権限を持つ、アプリが所属するグループが存在する | アプリグループ一覧を取得する | appIds にアプリ ID が含まれたアプリグループ一覧が返る | |
| 操作者にアプリグループ閲覧権限も管理権限もない | アプリグループ一覧を取得する | SystemPermissionDeniedError が返る | |
