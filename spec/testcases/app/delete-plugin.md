# プラグイン削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理権限を持つ、プリインストール済みでないプラグインが存在する | プラグインを削除する | プラグインが削除される | |
| 操作者が cybozu.com 共通管理者である（systemAdmin 権限なし）、プリインストール済みでないプラグインが存在する | プラグインを削除する | cybozu.com 共通管理者でも削除可能で、正常に削除される | |
| 操作者がシステム管理権限を持つ、無効状態のプラグインが存在する（プリインストール済みでない） | プラグインを削除する | 無効状態のプラグインも正常に削除される | |
| 操作者がシステム管理権限を持たない一般ユーザー | プラグインを削除する | SystemPermissionDeniedError が返る | |
| 操作者がシステム管理権限を持つ | 存在しない pluginId を指定して削除する | PluginNotFoundError が返る | |
| 操作者がシステム管理権限を持つ、プリインストール済みプラグイン（isPreinstalled: true）が存在する | プラグインを削除する | PreinstalledPluginError が返る | |
