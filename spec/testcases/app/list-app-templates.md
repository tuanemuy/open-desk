# アプリテンプレート一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリ作成権限（appCreate）を持つ、テンプレートが複数件存在する | デフォルトの offset・limit でアプリテンプレート一覧を取得する | テンプレート一覧と totalCount が返る | |
| 操作者がアプリ作成権限を持つ、テンプレートが0件 | アプリテンプレート一覧を取得する | 空配列と totalCount: 0 が返る | |
| 操作者がアプリ作成権限を持つ、テンプレートが150件存在する | offset: 0, limit: 100 で取得する | 先頭100件が返り、totalCount: 150 が返る | |
| 操作者がアプリ作成権限を持つ、テンプレートが150件存在する | offset: 100, limit: 100 で取得する | 残り50件が返り、totalCount: 150 が返る | |
| 操作者がアプリ作成権限を持つ、テンプレートが150件存在する | offset: 150, limit: 100 で取得する | 空配列と totalCount: 150 が返る | |
| 操作者がアプリ作成権限を持つ、sourceAppId が設定されたテンプレートが存在する | テンプレート一覧を取得する | sourceAppId を含むテンプレート情報が返る | |
| 操作者がアプリ作成権限を持たない一般ユーザー | アプリテンプレート一覧を取得する | SystemPermissionDeniedError が返る | |
