# アプリ削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリが存在する | アプリを削除する | アプリが DELETED 状態に変更され、appId・status="DELETED"・deletedAt が返却される | |
| PREVIEW 状態のアプリが存在する | アプリを削除する | アプリが DELETED 状態に変更される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが既に DELETED 状態 | 再度削除する | ビジネスルール違反エラーが返される | |
| アプリにレコードデータが存在する | アプリを削除する | 論理削除のため復元可能な状態で削除される | |
