# アプリ復元 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| DELETED 状態のアプリが存在し、アプリ数が上限未満 | アプリを復元する | アプリが ACTIVE 状態に変更され、appId・status="ACTIVE"・restoredAt が返却される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態でない（ACTIVE 状態） | 復元する | ビジネスルール違反エラーが返される | |
| アプリが DELETED 状態でない（PREVIEW 状態） | 復元する | ビジネスルール違反エラーが返される | |
| アプリ数が上限（1,000件）に達している | DELETED アプリを復元する | ビジネスルール違反エラーが返される | |
