# フィールド追加 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリが存在する | 有効なフィールドタイプ・コード・ラベルを指定してフィールドを追加する | フィールドが追加され、fieldId・fieldCode・label・fieldType が返却される | |
| アプリが存在する | layoutPosition を指定せずにフィールドを追加する | フォーム末尾にフィールドが追加される | |
| アプリが存在する | layoutPosition を指定してフィールドを追加する | 指定位置にフィールドが配置される | |
| アプリが存在する | required: true を指定して文字列1行フィールドを追加する | 必須フィールドとして追加される | |
| アプリが存在する | unique: true を指定して文字列1行フィールドを追加する | ユニークフィールドとして追加される | |
| アプリが存在する | defaultValue を指定してフィールドを追加する | 初期値が設定されたフィールドが追加される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | フィールドを追加する | ビジネスルール違反エラーが返される | |
| 同一 fieldCode のフィールドが既に存在する | 同じ fieldCode でフィールドを追加する | ビジネスルール違反エラーが返される | |
| - | fieldCode に不正な形式（日本語、記号等）を指定する | バリデーションエラーが返される | |
| - | fieldType にシステムフィールドを指定する | バリデーションエラーが返される | |
| - | required を設定できないフィールドタイプに required: true を指定する | バリデーションエラーが返される | |
| - | unique を設定できないフィールドタイプ（例: リッチエディタ）に unique: true を指定する | バリデーションエラーが返される | |
| - | properties がフィールドタイプと不一致の値を指定する | バリデーションエラーが返される | |
| サブテーブルが存在する | サブテーブル内に配置不可のフィールドをサブテーブルに配置する | ビジネスルール違反エラーが返される | |
| レイアウトの整合性が崩れる操作 | フィールドを追加する | ビジネスルール違反エラーが返される | |
