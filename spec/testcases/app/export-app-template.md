# アプリテンプレートファイル書き出し テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリ作成権限（appCreate）を持つ、テンプレートが存在する | テンプレートをファイルとして書き出す | file（ArrayBuffer）と fileName が返る | |
| 操作者がアプリ作成権限を持つ、sourceAppId が設定されたテンプレートが存在する | テンプレートをファイルとして書き出す | ソースアプリ情報を含むファイルが正常に書き出される | |
| 操作者がアプリ作成権限を持つ、sourceAppId が null のテンプレートが存在する | テンプレートをファイルとして書き出す | 正常にファイルが書き出される | |
| 操作者がアプリ作成権限を持たない一般ユーザー | テンプレートをファイルとして書き出す | SystemPermissionDeniedError が返る | |
| 操作者がアプリ作成権限を持つ | 存在しない templateId を指定して書き出す | AppTemplateNotFoundError が返る | |
| 操作者がアプリ作成権限を持つ、テンプレートが存在するがファイル書き出し処理が失敗する | テンプレートをファイルとして書き出す | AppTemplateExportError が返る | |
