# アクション設定 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| コピー元アプリとコピー先アプリが存在する | actionId=null（新規）、actionName・destinationAppId・fieldMappings を指定してアクションを作成する | アクションが作成され、actionId・actionName・destinationAppId が返却される | |
| 既存のアクションが存在する | actionName を変更する | アクション名が変更される | |
| 既存のアクションが存在する | destinationAppId を別のアプリに変更する | コピー先アプリが変更される | |
| 既存のアクションが存在する | fieldMappings を変更する | フィールドマッピングが変更される | |
| 既存のアクションが存在する | allowedEntities を設定する | 利用可能なユーザー/組織/グループが設定される | |
| 既存のアクションが存在する | filterCondition を設定する | 利用条件が設定される | |
| 既存のアクションが存在する | index を変更する | 表示順序が変更される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | アクションを設定する | ビジネスルール違反エラーが返される | |
| - | 存在しない destinationAppId を指定する | バリデーションエラーが返される | |
| - | actionName を空文字で送信する | バリデーションエラーが返される | |
| - | 存在しない actionId を指定する | バリデーションエラーが返される | |
| - | fieldMappings のコピー元フィールドコードが存在しない | バリデーションエラーが返される | |
| - | fieldMappings のコピー先フィールドコードが存在しない | バリデーションエラーが返される | |
| フィールドマッピングのコピー元とコピー先の型が異なる | アクションを設定する | ビジネスルール違反エラーが返される | |
