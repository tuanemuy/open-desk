# アプリ作成（Excel/CSV） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリ数が上限未満 | 有効な Excel ファイル（.xlsx）と name を指定してアプリを作成する | ヘッダーからフィールドが生成された PREVIEW 状態のアプリが作成され、fieldCount が返却される | |
| アプリ数が上限未満 | 有効な CSV ファイル（.csv）と name を指定してアプリを作成する | ヘッダーからフィールドが生成された PREVIEW 状態のアプリが作成される | |
| スペースが存在する | spaceId も指定してファイルからアプリを作成する | 指定スペースに紐づくアプリが作成される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | name に65文字以上の文字列を送信する | バリデーションエラーが返される | |
| - | 不正な形式のファイル（例: テキストファイル）を送信する | バリデーションエラーが返される | |
| - | ヘッダーが空のファイルを送信する | バリデーションエラーが返される | |
| - | 存在しない spaceId を指定する | バリデーションエラーが返される | |
| アプリ数が上限（1,000件）に達している | ファイルからアプリを作成する | ビジネスルール違反エラーが返される | |
| - | fileType に "EXCEL" を指定して .xlsx ファイルを送信する | 正常にアプリが作成される | |
| - | fileType に "CSV" を指定して .csv ファイルを送信する | 正常にアプリが作成される | |
