# アプリテンプレート削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリ管理権限（appManage）を持つ、テンプレートが存在する | テンプレートを削除する | テンプレートが削除される | |
| 操作者がアプリ管理権限を持つ、sourceAppId が設定されたテンプレートが存在する | テンプレートを削除する | 正常に削除され、ソースアプリには影響がない | |
| 操作者がアプリ管理権限を持たない一般ユーザー | テンプレートを削除する | SystemPermissionDeniedError が返る | |
| 操作者がアプリ管理権限を持つ | 存在しない templateId を指定して削除する | AppTemplateNotFoundError が返る | |
