# アプリ設定更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリが存在する | name を変更する（正しい revision 指定） | アプリ名が変更され、revision が増加し、appId・revision・updatedAt が返却される | |
| ACTIVE 状態のアプリが存在する | code を設定する（重複なし） | アプリコードが設定される | |
| ACTIVE 状態のアプリが存在する | code を null に設定する | アプリコードがクリアされる | |
| ACTIVE 状態のアプリが存在する | description を設定する | 説明が設定される | |
| ACTIVE 状態のアプリが存在する | description を null に設定する | 説明がクリアされる | |
| ACTIVE 状態のアプリが存在する | theme を6種類のいずれかに変更する | テーマが変更される | |
| ACTIVE 状態のアプリが存在する | featureFlags を更新する | 機能フラグが更新される | |
| ACTIVE 状態のアプリが存在する | firstMonthOfFiscalYear を 4 に設定する | 会計年度開始月が4月に設定される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| - | revision が現在の値と一致しない（古い値） | ビジネスルール違反エラー（楽観的ロック競合）が返される | |
| アプリが DELETED 状態 | アプリ設定を更新する | ビジネスルール違反エラーが返される | |
| 別のアプリが同一の code を使用している | その code を設定する | ビジネスルール違反エラーが返される | |
| - | name を空文字に変更する | バリデーションエラーが返される | |
| - | name に65文字以上を指定する | バリデーションエラーが返される | |
| - | description に10,001文字以上を指定する | バリデーションエラーが返される | |
| - | description にちょうど10,000文字を指定する | 正常に設定される（境界値） | |
| - | firstMonthOfFiscalYear に 0 を指定する | バリデーションエラーが返される | |
| - | firstMonthOfFiscalYear に 13 を指定する | バリデーションエラーが返される | |
| - | firstMonthOfFiscalYear に 1 を指定する | 正常に設定される（境界値） | |
| - | firstMonthOfFiscalYear に 12 を指定する | 正常に設定される（境界値） | |
