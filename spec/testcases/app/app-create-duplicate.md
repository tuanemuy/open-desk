# アプリ作成（既存アプリ再利用） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| コピー元アプリが存在し、アプリ数が上限未満 | sourceAppId と name を指定してアプリを複製する | 設定がコピーされた PREVIEW 状態のアプリが作成される（レコードデータはコピーされない） | |
| コピー元アプリとスペースが存在する | spaceId も指定してアプリを複製する | 指定スペースに紐づくアプリが作成される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | name に65文字以上の文字列を送信する | バリデーションエラーが返される | |
| - | 存在しない sourceAppId を指定する | バリデーションエラーが返される | |
| - | 存在しない spaceId を指定する | バリデーションエラーが返される | |
| アプリ数が上限（1,000件）に達している | 既存アプリを複製する | ビジネスルール違反エラーが返される | |
| コピー元アプリにフォーム・ビュー・グラフ設定がある | アプリを複製する | フォーム・ビュー・グラフの設定がすべてコピーされる | |
