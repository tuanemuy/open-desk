# プラグイン一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理権限を持つ、プラグインが複数件存在する（プリインストール含む） | デフォルトの offset・limit でプラグイン一覧を取得する | プラグイン一覧と totalCount が返る | |
| 操作者が cybozu.com 共通管理者である（systemAdmin 権限なし） | プラグイン一覧を取得する | cybozu.com 共通管理者でもアクセス可能で、プラグイン一覧が返る | |
| 操作者がシステム管理権限を持つ、プラグインが0件 | プラグイン一覧を取得する | 空配列と totalCount: 0 が返る | |
| 操作者がシステム管理権限を持つ、プラグインが150件存在する | offset: 0, limit: 100 で取得する | 先頭100件が返り、totalCount: 150 が返る | |
| 操作者がシステム管理権限を持つ、プラグインが150件存在する | offset: 100, limit: 100 で取得する | 残り50件が返り、totalCount: 150 が返る | |
| 操作者がシステム管理権限を持つ、有効・無効の両方のプラグインが存在する | プラグイン一覧を取得する | isActive の値が正しく含まれたプラグイン一覧が返る | |
| 操作者がシステム管理権限を持つ、プリインストール済みプラグインが存在する | プラグイン一覧を取得する | isPreinstalled: true のプラグインが含まれる | |
| 操作者がシステム管理権限を持つ、アプリにインストール済みのプラグインが存在する | プラグイン一覧を取得する | installedAppIds にアプリ ID が含まれたプラグイン一覧が返る | |
| 操作者がシステム管理権限を持たない一般ユーザー | プラグイン一覧を取得する | SystemPermissionDeniedError が返る | |
