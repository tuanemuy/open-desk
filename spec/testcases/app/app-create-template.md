# アプリ作成（テンプレート） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テンプレートが存在し、アプリ数が上限未満 | テンプレートIDと name を指定してアプリを作成する | テンプレートの設定がコピーされた PREVIEW 状態のアプリが作成される | |
| テンプレートとスペースが存在する | spaceId も指定してアプリを作成する | 指定スペースに紐づくアプリが作成される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | name に65文字以上の文字列を送信する | バリデーションエラーが返される | |
| - | 存在しない templateId を指定する | バリデーションエラーが返される | |
| - | 存在しない spaceId を指定する | バリデーションエラーが返される | |
| アプリ数が上限（1,000件）に達している | テンプレートからアプリを作成する | ビジネスルール違反エラーが返される | |
| - | name にちょうど1文字を指定する | アプリが正常に作成される（境界値） | |
| - | name にちょうど64文字を指定する | アプリが正常に作成される（境界値） | |
