# アプリカテゴリ設定 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリが存在する | isEnabled=true, カテゴリーツリーを指定して設定する | カテゴリーが有効化され、appId・isEnabled・categories・revision が返却される | |
| カテゴリーが有効なアプリ | isEnabled=false に変更する | カテゴリーが無効化される | |
| カテゴリーが有効なアプリ | 新規カテゴリーを追加する | カテゴリーが追加される | |
| カテゴリーが有効なアプリ | 既存カテゴリーの名前を変更する | カテゴリー名が変更される | |
| カテゴリーが有効なアプリ | カテゴリーを別の親の下に移動する | カテゴリーが移動される | |
| カテゴリーが有効なアプリ | カテゴリーを削除する | カテゴリーが削除される | |
| カテゴリーが未設定のアプリ | 新規にカテゴリーを設定する | 新しいカテゴリー設定が作成される | |
| カテゴリーが有効なアプリ | 子カテゴリーを持つ階層構造を設定する | 階層構造のカテゴリーが作成される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | カテゴリーを設定する | ビジネスルール違反エラーが返される | |
| revision が現在の値と一致しない | カテゴリーを設定する | ビジネスルール違反エラー（楽観的ロック競合）が返される | |
| - | カテゴリー名を空文字で指定する | バリデーションエラーが返される | |
