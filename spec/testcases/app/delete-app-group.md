# アプリグループ削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がアプリグループ管理権限（appGroupManageable）を持つ、アプリグループが存在する | アプリグループを削除する | アプリグループが削除される | |
| 操作者がアプリグループ管理権限を持つ、アプリが所属するアプリグループが存在する | アプリグループを削除する | アプリグループが削除され、所属アプリは削除されない | |
| 操作者がアプリグループ管理権限を持つ、デフォルトのアプリグループが存在する | デフォルトアプリグループを削除する | 正常に削除される | |
| 操作者がアプリグループ管理権限を持たない一般ユーザー | アプリグループを削除する | SystemPermissionDeniedError が返る | |
| 操作者がアプリグループ管理権限を持つ | 存在しない appGroupId を指定して削除する | AppGroupNotFoundError が返る | |
