# 多言語名設定 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ACTIVE 状態のアプリが存在する | scope=GENERAL, itemKey, language="en", value を指定して翻訳を設定する | 翻訳が設定され、appId・translationCount・revision が返却される | |
| ACTIVE 状態のアプリが存在する | 複数の翻訳を一括で設定する | すべての翻訳が設定される | |
| 既存の翻訳がある | value を空文字で送信する | 対応する翻訳が削除される（デフォルト名称が使用される） | |
| 多言語設定が未設定のアプリ | 新規に翻訳を設定する | 新しい多言語設定が作成される | |
| - | scope=FORM で翻訳を設定する | フォーム関連の翻訳が設定される | |
| - | scope=VIEW で翻訳を設定する | ビュー関連の翻訳が設定される | |
| - | scope=PROCESS で翻訳を設定する | プロセス関連の翻訳が設定される | |
| - | scope=REPORT で翻訳を設定する | レポート関連の翻訳が設定される | |
| - | scope=CATEGORY で翻訳を設定する | カテゴリー関連の翻訳が設定される | |
| - | scope=ACTION で翻訳を設定する | アクション関連の翻訳が設定される | |
| - | language="ja" で翻訳を設定する | 日本語翻訳が設定される | |
| - | language="zh" で翻訳を設定する | 中国語（簡体字）翻訳が設定される | |
| - | language="zh-TW" で翻訳を設定する | 中国語（繁体字）翻訳が設定される | |
| - | language="vi" で翻訳を設定する | ベトナム語翻訳が設定される | |
| - | language="id" で翻訳を設定する | インドネシア語翻訳が設定される | |
| - | language="th" で翻訳を設定する | タイ語翻訳が設定される | |
| - | 存在しない appId を指定する | バリデーションエラーが返される | |
| アプリが DELETED 状態 | 翻訳を設定する | ビジネスルール違反エラーが返される | |
| revision が現在の値と一致しない | 翻訳を設定する | ビジネスルール違反エラー（楽観的ロック競合）が返される | |
| - | scope に無効な値を指定する | バリデーションエラーが返される | |
| - | language に対応言語でない値（例: "fr"）を指定する | バリデーションエラーが返される | |
| - | itemKey に存在しない項目を参照する値を指定する | バリデーションエラーが返される | |
