# 未使用ファイル削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効期限切れの TEMPORARY ファイルが複数件存在する | 現在日時を指定して未使用ファイル削除を実行する | 期限切れファイルがストレージとメタデータの両方から削除され、削除件数が返る | |
| 有効期限切れの TEMPORARY ファイルが0件 | 未使用ファイル削除を実行する | deletedCount: 0 が返る | |
| TEMPORARY ファイルと PERMANENT ファイルが混在し、一部の TEMPORARY が期限切れ | 未使用ファイル削除を実行する | 期限切れの TEMPORARY ファイルのみ削除され、PERMANENT ファイルと期限内の TEMPORARY ファイルは残る | |
| ストレージからの一括削除が部分的に失敗する | 未使用ファイル削除を実行する | エラーがログに記録され、メタデータ削除は成功分のみ反映される | |
| 有効期限がちょうど now と一致する TEMPORARY ファイルが存在する | 未使用ファイル削除を実行する | 期限切れ判定の境界値が正しく処理される | |
| 大量の期限切れ TEMPORARY ファイルが存在する | 未使用ファイル削除を実行する | 全件が正常に一括削除される | |
