# ブックマーク作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効な userId が存在する | 有効な name と url でブックマークを作成する | ブックマークが作成され、URL パターンからカテゴリが自動判定され、DTO が返る | |
| 有効な userId が存在する | アプリの URL でブックマークを作成する | カテゴリが APP に判定され、appId が設定される | |
| 有効な userId が存在する | 検索結果の URL でブックマークを作成する | カテゴリが SEARCH に判定される | |
| 有効な userId が存在する | その他の URL でブックマークを作成する | カテゴリが OTHER に判定される | |
| 有効な userId が存在する | name を空文字でブックマークを作成する | EmptyBookmarkNameError が返る | |
| 有効な userId が存在する | url を空文字でブックマークを作成する | EmptyBookmarkUrlError が返る | |
| 有効な userId が存在する | 同じ URL で複数のブックマークを作成する | それぞれ別のブックマークとして正常に作成される | |
