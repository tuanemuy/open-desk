# ブックマーク削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ブックマークが存在し、操作者が所有者である | ブックマークを削除する | ブックマークが削除され、削除した bookmarkId が返る | |
| ブックマークが存在しない | ブックマークを削除する | BookmarkNotFoundError が返る | |
| ブックマークが存在するが、操作者が所有者でない | ブックマークを削除する | BookmarkNotOwnedError が返る | |
| APP カテゴリのブックマークが存在し、操作者が所有者 | ブックマークを削除する | 正常に削除される | |
| SEARCH カテゴリのブックマークが存在し、操作者が所有者 | ブックマークを削除する | 正常に削除される | |
| OTHER カテゴリのブックマークが存在し、操作者が所有者 | ブックマークを削除する | 正常に削除される | |
