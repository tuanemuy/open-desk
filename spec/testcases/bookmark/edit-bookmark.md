# ブックマーク編集 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ブックマークが存在し、操作者が所有者である | name のみ変更して編集する | name が更新され、url とカテゴリはそのまま、更新後の DTO が返る | |
| ブックマークが存在し、操作者が所有者である | url のみ変更して編集する | url が更新され、カテゴリが再判定され、更新後の DTO が返る | |
| ブックマークが存在し、操作者が所有者である | name と url の両方を変更して編集する | name と url が更新され、カテゴリが再判定され、更新後の DTO が返る | |
| ブックマークが存在し、操作者が所有者である | url をアプリの URL に変更する | カテゴリが APP に再判定され、appId が設定される | |
| ブックマークが存在し、操作者が所有者である | url をアプリ以外の URL に変更する | カテゴリが再判定され、appId が null になる | |
| ブックマークが存在しない | ブックマークを編集する | BookmarkNotFoundError が返る | |
| ブックマークが存在するが、操作者が所有者でない | ブックマークを編集する | BookmarkNotOwnedError が返る | |
| ブックマークが存在し、操作者が所有者である | name を空文字に変更して編集する | EmptyBookmarkNameError が返る | |
| ブックマークが存在し、操作者が所有者である | url を空文字に変更して編集する | EmptyBookmarkUrlError が返る | |
| ブックマークが存在し、操作者が所有者である | name も url も指定せずに編集する | 何も変更されず、現在のブックマークの DTO が返る | |
