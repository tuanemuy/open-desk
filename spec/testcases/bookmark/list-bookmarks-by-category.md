# ブックマーク一覧取得（カテゴリ別） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが各カテゴリ（APP, SEARCH, OTHER）にブックマークを持っている | カテゴリ別にブックマーク一覧を取得する | 3カテゴリに分類されたブックマーク一覧が返る | |
| ユーザーのブックマークが0件 | ブックマーク一覧を取得する | app, search, other がすべて空配列で返る | |
| ユーザーが APP カテゴリのみにブックマークを持つ | ブックマーク一覧を取得する | app にブックマークが含まれ、search と other は空配列で返る | |
| ユーザーが SEARCH カテゴリのみにブックマークを持つ | ブックマーク一覧を取得する | search にブックマークが含まれ、app と other は空配列で返る | |
| ユーザーが OTHER カテゴリのみにブックマークを持つ | ブックマーク一覧を取得する | other にブックマークが含まれ、app と search は空配列で返る | |
| ユーザーが同じアプリに複数のブックマークを持つ | ブックマーク一覧を取得する | APP カテゴリ内で同じ appId のブックマークがグルーピングされる | |
| ユーザーが各カテゴリに複数件のブックマークを持つ | ブックマーク一覧を取得する | 各カテゴリ内で作成日時の昇順（追加順）に返る | |
| 他ユーザーのブックマークが存在する | 自分の userId で取得する | 自分のブックマークのみが返り、他ユーザーのブックマークは含まれない | |
