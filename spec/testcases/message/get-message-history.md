# メッセージ履歴取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メッセージ機能が有効で、操作者がスレッドの参加者で、メッセージが複数件存在する | offset: 0, limit: 10 でメッセージ履歴を取得する | 新しい順に最大10件のメッセージと totalCount が返る | |
| メッセージ機能が有効で、操作者がスレッドの参加者で、メッセージが0件 | メッセージ履歴を取得する | 空配列と totalCount: 0 が返る | |
| メッセージ機能が有効で、操作者がスレッドの参加者で、メッセージが50件存在する | offset: 10, limit: 10 で取得する | 11件目から20件目までのメッセージが新しい順で返る | |
| メッセージ機能が無効 | メッセージ履歴を取得する | MessageFeatureDisabledError が返る | |
| メッセージ機能が有効で、スレッドが存在しない | メッセージ履歴を取得する | ThreadNotFoundError が返る | |
| メッセージ機能が有効で、操作者がスレッドの参加者でない | メッセージ履歴を取得する | NotParticipantError が返る | |
| メッセージ機能が有効 | offset: -1 でメッセージ履歴を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | limit: 0 でメッセージ履歴を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | limit: 101 でメッセージ履歴を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | offset: 0, limit: 1 で取得する（limit 最小値） | 最新の1件が返る | |
| メッセージ機能が有効 | offset: 0, limit: 100 で取得する（limit 最大値） | 最大100件が返る | |
| メッセージ機能が有効で、メッセージが5件存在する | offset: 5, limit: 10 で取得する（offset が件数と同じ） | 空配列と totalCount: 5 が返る | |
