# メッセージスレッド一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メッセージ機能が有効で、参加中のスレッドが複数件存在する | offset: 0, limit: 10 でスレッド一覧を取得する | 最終メッセージ日時の新しい順に最大10件のスレッドと totalCount が返る | |
| メッセージ機能が有効で、参加中のスレッドが0件 | スレッド一覧を取得する | 空配列と totalCount: 0 が返る | |
| メッセージ機能が有効で、参加中のスレッドが50件存在する | offset: 10, limit: 10 で取得する | 11件目から20件目までのスレッドが最終メッセージ日時の新しい順で返る | |
| メッセージ機能が無効 | スレッド一覧を取得する | MessageFeatureDisabledError が返る | |
| メッセージ機能が有効 | offset: -1 でスレッド一覧を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | limit: 0 でスレッド一覧を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | limit: 101 でスレッド一覧を取得する | バリデーションエラーが返る | |
| メッセージ機能が有効 | offset: 0, limit: 1 で取得する（limit 最小値） | 最新の1件が返る | |
| メッセージ機能が有効 | offset: 0, limit: 100 で取得する（limit 最大値） | 最大100件が返る | |
| メッセージ機能が有効で、スレッドが5件存在する | offset: 5, limit: 10 で取得する（offset が件数と同じ） | 空配列と totalCount: 5 が返る | |
| メッセージ機能が有効で、lastMessageAt が null のスレッドがある | スレッド一覧を取得する | lastMessageAt が null のスレッドも含まれて返る | |
