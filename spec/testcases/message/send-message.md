# メッセージ送信 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メッセージ機能が有効で、送信者がスレッドの参加者である | 有効な content と空の添付ファイルでメッセージを送信する | メッセージが作成され、スレッドの lastMessageAt が更新され、相手に通知が送信され、DTO が返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | 添付ファイル付きでメッセージを送信する | メッセージが作成され、attachmentFileKeys に指定したファイルキーが含まれる | |
| メッセージ機能が無効 | メッセージを送信する | MessageFeatureDisabledError が返る | |
| メッセージ機能が有効で、スレッドが存在しない | メッセージを送信する | ThreadNotFoundError が返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者でない | メッセージを送信する | NotParticipantError が返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | content を空文字でメッセージを送信する | EmptyMessageContentError が返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | content にアプリ埋め込み要素（iframe タグ）を含めて送信する | バリデーションエラーが返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | content に opendesk-app タグを含めて送信する | バリデーションエラーが返る | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | サニタイズ済み HTML の content でメッセージを送信する | 正常にメッセージが作成される | |
| メッセージ機能が有効で、送信者がスレッドの参加者である | 連続してメッセージを送信する | 各メッセージが作成され、lastMessageAt が最新のメッセージの日時に更新される | |
