# メッセージスレッド取得/作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メッセージ機能が有効で、相手が通常ユーザーで、スレッドが存在しない | スレッドを取得/作成する | 新規スレッドが作成され、DTO が返る | |
| メッセージ機能が有効で、相手が通常ユーザーで、スレッドが既に存在する | スレッドを取得/作成する | 既存のスレッドが返る | |
| メッセージ機能が無効 | スレッドを取得/作成する | MessageFeatureDisabledError が返る | |
| メッセージ機能が有効で、相手がゲストユーザー | スレッドを取得/作成する | GuestUserMessageError が返る | |
| メッセージ機能が有効 | operatorId と counterpartId が同一でスレッドを取得/作成する | SameParticipantError が返る | |
| メッセージ機能が有効で、相手が通常ユーザー | 既存スレッドがある状態で再度同じペアで取得/作成する | 同じスレッドが返る（冪等） | |
