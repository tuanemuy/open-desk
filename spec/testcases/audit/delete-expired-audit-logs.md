# 期限切れ監査ログ削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 保持期間（6週間）を超過した監査ログが存在する | retentionWeeks: 6 で期限切れログを削除する | 超過したログが一括削除され、削除件数が返る | |
| 保持期間を超過した監査ログが存在しない | retentionWeeks: 6 で期限切れログを削除する | 削除件数 0 が返る | |
| 保持期間ちょうど境界の監査ログが存在する | retentionWeeks: 6 で期限切れログを削除する | 境界値の挙動が仕様どおりに処理される（超過したもののみ削除） | |
| 保持期間超過と期間内のログが混在する | retentionWeeks: 6 で期限切れログを削除する | 超過したログのみ削除され、期間内のログは保持される | |
| 保持期間を超過した監査ログが大量に存在する | retentionWeeks: 6 で期限切れログを削除する | 全件が一括削除され、正確な削除件数が返る | |
| 有効な監査ログが存在する | retentionWeeks: 1（最小値）で期限切れログを削除する | 1週間を超過したログが削除される | |
| 有効な監査ログが存在する | retentionWeeks: 0 で期限切れログを削除する | InvalidRetentionPeriodError が返る | |
| 有効な監査ログが存在する | retentionWeeks: -1（負の値）で期限切れログを削除する | InvalidRetentionPeriodError が返る | |
