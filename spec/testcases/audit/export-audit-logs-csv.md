# 監査ログ CSV ダウンロード テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 保持期間内の監査ログが複数件存在する | フィルタ条件なしで CSV ダウンロードする | 全件の監査ログと totalCount が返る | |
| 保持期間内の監査ログが0件 | フィルタ条件なしで CSV ダウンロードする | logs が空配列、totalCount が 0 で返る | |
| 保持期間内の監査ログが10万件ちょうど存在する | フィルタ条件なしで CSV ダウンロードする | 10万件の監査ログが正常に返る（境界値） | |
| 保持期間内の監査ログが10万件を超えて存在する | フィルタ条件なしで CSV ダウンロードする | ExportLimitExceededError が返る | |
| 10万件超のログが存在するが、フィルタ適用後は10万件以下 | フィルタ条件を指定して CSV ダウンロードする | フィルタ後の件数が10万件以下なので正常に返る | |
| CRITICAL と INFO のログが混在する | level: "CRITICAL" でフィルタして CSV ダウンロードする | CRITICAL のログのみが返る | |
| 複数ユーザーのログが存在する | 特定の userId でフィルタして CSV ダウンロードする | 該当ユーザーのログのみが返る | |
| 複数サービスのログが存在する | service: "GAROON" でフィルタして CSV ダウンロードする | GAROON のログのみが返る | |
| 複数モジュールのログが存在する | module でフィルタして CSV ダウンロードする（部分一致） | 該当モジュール名を含むログのみが返る | |
| 複数アクションのログが存在する | action でフィルタして CSV ダウンロードする（部分一致） | 該当アクション名を含むログのみが返る | |
| SUCCESS と FAILURE のログが混在する | result: "SUCCESS" でフィルタして CSV ダウンロードする | SUCCESS のログのみが返る | |
| 異なる日時のログが存在する | dateFrom と dateTo を指定してフィルタする | 指定範囲内のログのみが返る | |
| dateFrom が dateTo より後の日時 | dateFrom > dateTo でフィルタして CSV ダウンロードする | InvalidAuditFilterError が返る | |
| dateFrom が保持期間（6週間前）より古い | 6週間より前の dateFrom を指定して CSV ダウンロードする | InvalidAuditFilterError が返る | |
| dateFrom が保持期間（6週間前）のちょうど境界値 | 保持期間ちょうどの dateFrom を指定して CSV ダウンロードする | 正常に取得できる（境界値は許容） | |
| dateFrom が未指定 | dateFrom を省略して CSV ダウンロードする | dateFrom が保持期間（6週間前）に自動設定され、正常に取得できる | |
| 複数のフィルタ条件を組み合わせる | level, service, dateFrom, dateTo を指定して CSV ダウンロードする | 全条件に一致するログのみが返る | |
| 監査ログが1件のみ存在する | フィルタ条件なしで CSV ダウンロードする | 1件の監査ログが正常に返る | |
