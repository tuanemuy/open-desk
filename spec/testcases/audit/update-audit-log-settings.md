# 監査ログ設定更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 監査ログ設定が保存されている | 有効な AuditLogSetting で設定を更新する | 設定が上書き保存され、更新後の AuditLogSetting が返る | |
| 監査ログ設定が未作成（初回） | 有効な AuditLogSetting で設定を更新する | 新規に設定が保存され、AuditLogSetting が返る | |
| 監査ログ設定が保存されている | 現在と同じ値の AuditLogSetting で設定を更新する | 変更なしで同一の AuditLogSetting が返る（冪等性） | |
| 監査ログ設定が保存されている | 設定の一部フィールドのみ変更して更新する | 変更したフィールドのみ更新され、他はそのまま保持される | |
| 監査ログ設定が保存されている | 不正な AuditLogSetting で設定を更新する | ドメインモデルからバリデーションエラーが発生する | |
