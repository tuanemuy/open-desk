# フォロー テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| フォロー関係が存在しない | 他ユーザーをフォローする | フォロー関係が作成され、作成後の DTO が返る | |
| followerId と followeeId が同一 | 自分自身をフォローする | SelfFollowError が返る | |
| 既にフォロー関係が存在する | 同じユーザーを再度フォローする | DuplicateFollowError が返る | |
| ユーザーAがユーザーBをフォロー済み | ユーザーBがユーザーAをフォローする（相互フォロー） | 正常にフォロー関係が作成される | |
