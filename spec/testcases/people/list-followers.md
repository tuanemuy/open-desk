# フォロワー一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーのフォロワーが複数件存在する | offset: 0, limit: 10 でフォロワー一覧を取得する | 新しい順に最大10件のフォロワーと totalCount が返る | |
| 対象ユーザーのフォロワーが0件 | フォロワー一覧を取得する | 空配列と totalCount: 0 が返る | |
| 対象ユーザーのフォロワーが50件存在する | offset: 10, limit: 10 で取得する | 11件目から20件目までのフォロワーが新しい順で返る | |
| 任意の状態 | offset: -1 でフォロワー一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 0 でフォロワー一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 101 でフォロワー一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | offset: 0, limit: 1 で取得する（limit 最小値） | 最新の1件が返る | |
| 任意の状態 | offset: 0, limit: 100 で取得する（limit 最大値） | 最大100件が返る | |
| 対象ユーザーのフォロワーが5件存在する | offset: 5, limit: 10 で取得する（offset が件数と同じ） | 空配列と totalCount: 5 が返る | |
