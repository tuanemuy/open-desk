# カバー画像設定 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロフィールが存在し、カバー画像が未設定 | 5MB 以下の有効な fileKey でカバー画像を設定する | カバー画像が設定され、更新後の DTO が返る | |
| プロフィールが存在し、既にカバー画像が設定されている | 新しい fileKey でカバー画像を設定する | カバー画像が新しいものに置き換えられ、更新後の DTO が返る | |
| プロフィールが存在しない | カバー画像を設定する | ProfileNotFoundError が返る | |
| プロフィールが存在する | 5MB を超えるファイルの fileKey でカバー画像を設定する | CoverImageTooLargeError が返る | |
| プロフィールが存在する | File ドメインに存在しない fileKey でカバー画像を設定する | FileNotFoundError が返る | |
| プロフィールが存在する | ちょうど 5MB（5,242,880 バイト）のファイルで設定する | 正常にカバー画像が設定される | |
| プロフィールが存在する | 5MB + 1 バイト（5,242,881 バイト）のファイルで設定する | CoverImageTooLargeError が返る | |
| プロフィールが存在する | 1 バイトのファイル（最小の有効サイズ）で設定する | 正常にカバー画像が設定される | |
