# カバー画像削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロフィールが存在し、カバー画像が設定されている | カバー画像を削除する | カバー画像が削除され、coverImageFileKey が null の DTO が返る | |
| プロフィールが存在し、カバー画像が未設定 | カバー画像を削除する | 何も変更されず、coverImageFileKey が null の DTO が返る（冪等） | |
| プロフィールが存在しない | カバー画像を削除する | ProfileNotFoundError が返る | |
