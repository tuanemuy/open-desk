# プロフィール取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーが Identity ドメインに存在し、プロフィール拡張情報も存在する | targetUserId を指定してプロフィールを取得する | Identity 基本情報と People 拡張情報が統合された DTO が返る | |
| 対象ユーザーが Identity ドメインに存在し、プロフィール拡張情報が存在しない | targetUserId を指定してプロフィールを取得する | デフォルト値（カバー画像なし、コメント空文字）で新規作成され、統合された DTO が返る | |
| 対象ユーザーが Identity ドメインに存在しない | targetUserId を指定してプロフィールを取得する | UserNotFoundError が返る | |
| 対象ユーザーのプロフィールにカバー画像が設定されている | プロフィールを取得する | coverImageFileKey に有効な FileKey が含まれる | |
| 対象ユーザーのプロフィールにカバー画像が未設定 | プロフィールを取得する | coverImageFileKey が null で返る | |
| 対象ユーザーのプロフィールにコメントが設定されている | プロフィールを取得する | comment に設定済みの文字列が含まれる | |
