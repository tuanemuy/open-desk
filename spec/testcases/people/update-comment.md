# コメント更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロフィールが存在し、コメントが設定されている | 新しいコメント文字列で更新する | コメントが更新され、更新後の DTO が返る | |
| プロフィールが存在し、コメントが設定されている | 空文字でコメントを更新する | コメントがクリアされ、comment が空文字の DTO が返る | |
| プロフィールが存在し、コメントが空文字 | 新しいコメント文字列で更新する | コメントが設定され、更新後の DTO が返る | |
| プロフィールが存在しない | コメントを更新する | ProfileNotFoundError が返る | |
| プロフィールが存在する | 同じコメント内容で更新する | 正常に更新され、updatedAt が更新される | |
