# 投稿一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーの投稿が複数件存在する | offset: 0, limit: 10 で投稿一覧を取得する | 新しい順に最大10件の投稿と totalCount が返る | |
| 対象ユーザーの投稿が0件 | 投稿一覧を取得する | 空配列と totalCount: 0 が返る | |
| 対象ユーザーの投稿が50件存在する | offset: 10, limit: 10 で取得する | 11件目から20件目までの投稿が新しい順で返る | |
| 対象ユーザーの投稿が5件存在する | offset: 0, limit: 100 で取得する | 5件の投稿と totalCount: 5 が返る | |
| 任意の状態 | offset: -1 で投稿一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 0 で投稿一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 101 で投稿一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | offset: 0, limit: 1 で取得する（limit 最小値） | 最新の1件が返る | |
| 任意の状態 | offset: 0, limit: 100 で取得する（limit 最大値） | 最大100件が返る | |
| 対象ユーザーの投稿が5件存在する | offset: 5, limit: 10 で取得する（offset が件数と同じ） | 空配列と totalCount: 5 が返る | |
| 対象ユーザーの投稿が5件存在する | offset: 100, limit: 10 で取得する（offset が件数を超過） | 空配列と totalCount: 5 が返る | |
