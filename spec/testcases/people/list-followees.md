# フォロー中一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーがフォロー中のユーザーが複数件存在する | offset: 0, limit: 10 でフォロー中一覧を取得する | 新しい順に最大10件のフォロー中ユーザーと totalCount が返る | |
| 対象ユーザーがフォロー中のユーザーが0件 | フォロー中一覧を取得する | 空配列と totalCount: 0 が返る | |
| 対象ユーザーがフォロー中のユーザーが50件存在する | offset: 10, limit: 10 で取得する | 11件目から20件目までのフォロー中ユーザーが新しい順で返る | |
| 任意の状態 | offset: -1 でフォロー中一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 0 でフォロー中一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | limit: 101 でフォロー中一覧を取得する | バリデーションエラーが返る | |
| 任意の状態 | offset: 0, limit: 1 で取得する（limit 最小値） | 最新の1件が返る | |
| 任意の状態 | offset: 0, limit: 100 で取得する（limit 最大値） | 最大100件が返る | |
| 対象ユーザーがフォロー中のユーザーが5件存在する | offset: 5, limit: 10 で取得する（offset が件数と同じ） | 空配列と totalCount: 5 が返る | |
