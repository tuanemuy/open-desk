# スレッド削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者で、対象がデフォルトスレッドでない | スレッドを削除する | スレッドと関連コメント・フォロー・いいねが削除される | |
| コメント・フォロー等の関連データが存在するスレッドで操作者がスペース管理者 | スレッドを削除する | 関連コメント、フォローが削除された後にスレッドが削除される | |
| 関連データが存在しないスレッドで操作者がスペース管理者 | スレッドを削除する | スレッドが正常に削除される | |
| 存在しないスレッドIDを指定する | スレッド削除を試みる | ThreadNotFoundError が返る | |
| デフォルトスレッド（isDefault=true）を指定する | スレッド削除を試みる | DefaultThreadDeletionError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | スレッド削除を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスレッド作成者だがスペース管理者でない | スレッド削除を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | スレッド削除を試みる | SpaceAdminRequiredError が返る | |
