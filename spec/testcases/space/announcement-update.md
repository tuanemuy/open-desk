# お知らせ更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| マルチスレッドスペースで操作者がスペース管理者 | お知らせ本文を更新する | お知らせが更新され、spaceId, body, updatedBy, updatedAt が返る | |
| マルチスレッドスペースで操作者がスペース管理者、お知らせ未作成 | お知らせ本文を設定する | 新しいお知らせが生成され、本文が設定される | |
| マルチスレッドスペースで操作者がスペース管理者、既存のお知らせあり | お知らせ本文を更新する | 既存のお知らせ本文が上書き更新される | |
| 存在しないスペースIDを指定する | お知らせ更新を試みる | SpaceNotFoundError が返る | |
| シングルスレッドスペース（useMultiThread=false） | お知らせ更新を試みる | MultiThreadRequiredError が返る | |
| マルチスレッドスペースで操作者がスペース管理者でない | お知らせ更新を試みる | SpaceAdminRequiredError が返る | |
| マルチスレッドスペースで操作者がスペースメンバーでない | お知らせ更新を試みる | SpaceAdminRequiredError が返る | |
| マルチスレッドスペースで操作者がスペース管理者 | body を65,535文字で更新する | お知らせが正常に更新される（境界値） | |
| マルチスレッドスペースで操作者がスペース管理者 | body を65,536文字で更新する | バリデーションエラーが返る | |
| マルチスレッドスペースで操作者がスペース管理者 | body を空文字で更新する | お知らせが空文字で更新される | |
