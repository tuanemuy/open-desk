# スペース削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者である | スペースを削除する | スペースと関連データ（スレッド・コメント・メンバー・お知らせ・関連リンク・フォロー・いいね）がすべて削除される | |
| スレッド・コメント・フォロー等の関連データが存在するスペースで操作者がスペース管理者 | スペースを削除する | スレッド関連コメント、フォロー、スレッド、お知らせ、関連リンク、メンバーが順に削除される | |
| 関連データが存在しないスペースで操作者がスペース管理者 | スペースを削除する | スペースが正常に削除される | |
| 存在しないスペースIDを指定する | スペース削除を試みる | SpaceNotFoundError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | スペース削除を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | スペース削除を試みる | SpaceAdminRequiredError が返る | |
| 複数スレッドを持つスペースで操作者がスペース管理者 | スペースを削除する | 全スレッドとその関連コメント・フォローが削除される | |
