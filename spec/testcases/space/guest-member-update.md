# ゲストメンバー更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ゲストスペースで操作者がスペース管理者 | 管理者1名を含む有効なメンバーリストで更新する | ゲストメンバーが指定リストに置き換わる | |
| ゲストスペースで操作者がスペース管理者 | 新しいゲストユーザーを追加する | 新メンバーが追加される | |
| ゲストスペースで操作者がスペース管理者 | 既存ゲストメンバーを削除する | 指定されたメンバーが削除される | |
| 存在しないスペースIDを指定する | ゲストメンバー更新を試みる | SpaceNotFoundError が返る | |
| 通常スペース（ゲストスペースでない）を指定する | ゲストメンバー更新を試みる | NotGuestSpaceError が返る | |
| ゲストスペースで操作者がスペース管理者でない（一般メンバー） | ゲストメンバー更新を試みる | SpaceAdminRequiredError が返る | |
| ゲストスペースで操作者がスペースメンバーでない | ゲストメンバー更新を試みる | SpaceAdminRequiredError が返る | |
| ゲストスペースで操作者がスペース管理者 | 管理者を含まないメンバーリストで更新する | NoAdminMemberError が返る | |
| ゲストスペースで操作者がスペース管理者 | 空のメンバーリストで更新する | NoAdminMemberError が返る | |
| ゲストスペースで操作者がスペース管理者 | 使用停止中のユーザーを含むリストで更新する | InvalidMemberError が返る | |
| ゲストスペースで操作者がスペース管理者 | 削除済みのユーザーを含むリストで更新する | InvalidMemberError が返る | |
