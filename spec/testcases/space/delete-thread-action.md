# スレッドアクション削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理権限を持つ、スレッドアクションが存在する | スレッドアクションを削除する | スレッドアクションが削除される | |
| 操作者が cybozu.com 共通管理者である（systemAdmin 権限なし）、スレッドアクションが存在する | スレッドアクションを削除する | cybozu.com 共通管理者でも削除可能で、正常に削除される | |
| 操作者がシステム管理権限を持つ、フィールドマッピングを持つスレッドアクションが存在する | スレッドアクションを削除する | フィールドマッピングを含めて正常に削除される | |
| 操作者がシステム管理権限を持たない一般ユーザー | スレッドアクションを削除する | SystemPermissionDeniedError が返る | |
| 操作者がシステム管理権限を持つ | 存在しない threadActionId を指定して削除する | ThreadActionNotFoundError が返る | |
