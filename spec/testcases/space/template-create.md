# テンプレート作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者 | 有効な名前でテンプレートを作成する | テンプレートが作成され、スペースの設定・スレッド名・アプリID・関連リンク・お知らせ本文が含まれる | |
| スレッドが複数存在するスペースで操作者がスペース管理者 | テンプレートを作成する | 全スレッド名がテンプレートに含まれる | |
| 関連リンクが存在するスペースで操作者がスペース管理者 | テンプレートを作成する | 関連リンクがテンプレートに含まれる | |
| お知らせが存在するスペースで操作者がスペース管理者 | テンプレートを作成する | お知らせ本文がテンプレートに含まれる | |
| アプリが存在するスペースで操作者がスペース管理者 | テンプレートを作成する | アプリIDがテンプレートに含まれる | |
| 存在しないスペースIDを指定する | テンプレート作成を試みる | SpaceNotFoundError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | テンプレート作成を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | テンプレート作成を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペース管理者 | name を空文字で作成する | バリデーションエラーが返る | |
| 関連データが最小限のスペースで操作者がスペース管理者 | テンプレートを作成する | 最小限の内容でテンプレートが作成される | |
