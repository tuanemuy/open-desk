# スレッドフォロー解除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーで、fixedMember=false、フォロー中 | スレッドのフォローを解除する | フォロー関係が削除される | |
| 存在しないスレッドIDを指定する | スレッドフォロー解除を試みる | ThreadNotFoundError が返る | |
| 操作者がスペースメンバーでない | スレッドフォロー解除を試みる | NotMemberError が返る | |
| fixedMember=true のスペースで操作者がメンバー | スレッドフォロー解除を試みる | FixedMemberError が返る | |
| スペースメンバーで、フォローしていない | スレッドフォロー解除を試みる | NotFollowingError が返る | |
| fixedMember=false のスペースで操作者がスペース管理者、フォロー中 | スレッドのフォローを解除する | フォロー関係が正常に削除される | |
