# コメント投稿 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーでスレッドが存在する | テキスト付きコメントを投稿する | コメントが作成され、commentId, threadId, spaceId, text, creatorId, createdAt が返る | |
| スペースメンバーでスレッドが存在する | ファイル添付のみのコメントを投稿する | コメントが作成される（text=null, files あり） | |
| スペースメンバーでスレッドが存在する | テキストとファイル添付の両方を含むコメントを投稿する | コメントが作成される | |
| スペースメンバーでスレッドが存在する | @メンション付きコメントを投稿する | コメントが作成され、メンション通知が生成される | |
| スペースメンバーでスレッドが存在する | ファイルを5件添付してコメントを投稿する | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドが存在する | メンションを10件指定してコメントを投稿する | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドが存在する | フォロワーが存在するスレッドにコメントを投稿する | コメントが作成され、フォロワーにスペース通知が生成される | |
| 存在しないスレッドIDを指定する | コメント投稿を試みる | ThreadNotFoundError が返る | |
| 操作者がスペースメンバーでない | コメント投稿を試みる | NotMemberError が返る | |
| スペースメンバーでスレッドが存在する | text と files の両方を空にしてコメントを投稿する | EmptyCommentError が返る | |
| スペースメンバーでスレッドが存在する | text=null, files=[] でコメントを投稿する | EmptyCommentError が返る | |
| スペースメンバーでスレッドが存在する | メンションを11件指定してコメントを投稿する | TooManyMentionsError が返る | |
| スペースメンバーでスレッドが存在する | ファイルを6件添付してコメントを投稿する | TooManyFilesError が返る | |
| スペースメンバーでスレッドが存在する | text を65,535文字で投稿する | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドが存在する | text を65,536文字で投稿する | バリデーションエラーが返る | |
| スペースメンバーでスレッドが存在する | ファイルの width を100px で指定する | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドが存在する | ファイルの width を750px で指定する | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドが存在する | ファイルの width を99px で指定する | バリデーションエラーが返る | |
| スペースメンバーでスレッドが存在する | ファイルの width を751px で指定する | バリデーションエラーが返る | |
