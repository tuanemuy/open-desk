# メンバー一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開スペースが存在し、操作者が認証済みユーザー | メンバー一覧を取得する | メンバー一覧（entity, isAdmin, includeSubs）が返る | |
| 公開スペースが存在し、操作者がメンバーでない認証済みユーザー | メンバー一覧を取得する | メンバー一覧が正常に返る | |
| 非公開スペースが存在し、操作者がスペースメンバー | メンバー一覧を取得する | メンバー一覧が返る | |
| 非公開スペースが存在し、操作者がスペース管理者 | メンバー一覧を取得する | メンバー一覧が返る | |
| 存在しないスペースIDを指定する | メンバー一覧取得を試みる | SpaceNotFoundError が返る | |
| 非公開スペースが存在し、操作者がメンバーでない | メンバー一覧取得を試みる | SpaceAccessDeniedError が返る | |
| メンバーが1名のスペースで操作者がそのメンバー | メンバー一覧を取得する | 1名のメンバー情報が返る | |
| 複数メンバー（管理者・一般メンバー混在）のスペース | メンバー一覧を取得する | 全メンバーの情報が isAdmin フラグと共に返る | |
