# スペース作成（テンプレート） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース作成権限を持ち、有効なテンプレートが存在する | テンプレートからスペースを作成する | テンプレートの設定に基づきスペース・スレッド・お知らせ・関連リンクが生成される | |
| 操作者がスペース作成権限を持つ | テンプレートの設定（useMultiThread, coverImage等）が反映されたスペースを作成する | テンプレートの設定値が正しくスペースに反映される | |
| 操作者がスペース作成権限を持つ | isPrivate=true, fixedMember=true で作成する | 指定した設定が正しく適用される | |
| 操作者がスペース作成権限を持つ | 管理者1名を含むメンバーを指定する | 全メンバーが登録され、管理者が正しく設定される | |
| 操作者にスペース作成権限がない | テンプレートからスペース作成を試みる | SpacePermissionDeniedError が返る | |
| 存在しない templateId を指定する | テンプレートからスペース作成を試みる | SpaceTemplateNotFoundError が返る | |
| 操作者がスペース作成権限を持つ | name を空文字で作成する | EmptySpaceNameError が返る | |
| 操作者がスペース作成権限を持つ | name を129文字で作成する | SpaceNameTooLongError が返る | |
| 操作者がスペース作成権限を持つ | name を128文字で作成する | スペースが正常に作成される（境界値） | |
| 操作者がスペース作成権限を持つ | name を1文字で作成する | スペースが正常に作成される（境界値） | |
| 通常スペースが既に500件存在する | テンプレートからスペース作成を試みる | SpaceLimitExceededError が返る | |
| 通常スペースが499件存在する | テンプレートからスペース作成を試みる | スペースが正常に作成される（境界値） | |
| 操作者がスペース作成権限を持つ | members に管理者を含めずに作成する | NoAdminMemberError が返る | |
| 操作者がスペース作成権限を持つ | members を空配列で作成する | NoAdminMemberError が返る | |
| テンプレートにスレッド定義が複数ある | テンプレートからスペースを作成する | テンプレート内の全スレッドが生成され、threads 配列に含まれる | |
