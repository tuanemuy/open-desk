# スレッド更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者 | スレッドのタイトルを変更する | タイトルが更新される | |
| 操作者がスレッド作成者 | スレッドのタイトルを変更する | タイトルが更新される | |
| 操作者がスペース管理者 | スレッドの本文を変更する | 本文が更新される | |
| 操作者がスレッド作成者 | スレッドの本文を変更する | 本文が更新される | |
| 操作者がスペース管理者 | タイトルと本文を同時に変更する | 両方が更新される | |
| 操作者がスペース管理者 | body を null に変更する | 本文が null に更新される | |
| 存在しないスレッドIDを指定する | スレッド更新を試みる | ThreadNotFoundError が返る | |
| 操作者がスペース管理者でもスレッド作成者でもない（一般メンバー） | スレッド更新を試みる | ThreadUpdatePermissionDeniedError が返る | |
| 操作者がスペース管理者 | title を空文字に変更する | EmptyThreadTitleError が返る | |
| 操作者がスペース管理者 | title を129文字に変更する | ThreadTitleTooLongError が返る | |
| 操作者がスペース管理者 | title を128文字に変更する | タイトルが正常に更新される（境界値） | |
| 操作者がスペース管理者 | title を1文字に変更する | タイトルが正常に更新される（境界値） | |
| 操作者がスペース管理者 | body を65,535文字に変更する | 本文が正常に更新される（境界値） | |
| 操作者がスペース管理者 | body を65,536文字に変更する | ThreadBodyTooLongError が返る | |
