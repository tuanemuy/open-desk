# ゲストユーザー追加 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理者権限を持つ | 有効な名前・メールアドレスでゲストユーザーを追加する | ゲストユーザーが作成され、userId, name, email, company が返る | |
| 操作者がシステム管理者権限を持つ | company を指定してゲストユーザーを追加する | 会社名付きのゲストユーザーが作成される | |
| 操作者がシステム管理者権限を持つ | company を省略してゲストユーザーを追加する | company=null のゲストユーザーが作成される | |
| 操作者がシステム管理者権限を持つ | spaceIds に有効なゲストスペースを指定して追加する | ゲストユーザーが作成され、指定スペースのメンバーに追加される | |
| 操作者がシステム管理者権限を持つ | spaceIds に複数のゲストスペースを指定して追加する | 全指定スペースのメンバーに追加される | |
| 操作者がシステム管理者権限を持つ | spaceIds を省略して追加する | ゲストユーザーが作成される（スペースへの追加なし） | |
| 操作者が cybozu 管理者 | ゲストユーザーを追加する | ゲストユーザーが正常に作成される | |
| 操作者にシステム管理権限がない | ゲストユーザー追加を試みる | SystemPermissionDeniedError が返る | |
| 操作者がシステム管理者権限を持つ | 不正なメールアドレス形式で追加する | バリデーションエラーが返る | |
| 操作者がシステム管理者権限を持つ | name を空文字で追加する | バリデーションエラーが返る | |
| 操作者がシステム管理者権限を持つ | email を空文字で追加する | バリデーションエラーが返る | |
| 操作者がシステム管理者権限を持つ | spaceIds に通常スペース（ゲストスペースでない）を指定する | NotGuestSpaceError が返る | |
| 操作者がシステム管理者権限を持つ | spaceIds に存在しないスペースIDを指定する | SpaceNotFoundError が返る | |
