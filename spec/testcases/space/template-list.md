# テンプレート一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース作成権限を持ち、テンプレートが複数存在する | テンプレート一覧を取得する | テンプレート一覧（templateId, name, sourceSpaceId, useMultiThread, createdAt）と totalCount が返る | |
| 操作者がスペース作成権限を持つ | offset=0, limit=10 で取得する | 先頭10件のテンプレート情報が返る | |
| 操作者がスペース作成権限を持つ | offset=10, limit=10 で取得する | 11件目から20件目のテンプレート情報が返る | |
| 操作者がスペース作成権限を持つ | limit を省略して取得する | デフォルト100件で取得される | |
| 操作者がスペース作成権限を持つ | offset を省略して取得する | デフォルト0から取得される | |
| 操作者にスペース作成権限がない | テンプレート一覧取得を試みる | SpacePermissionDeniedError が返る | |
| テンプレートが0件の状態 | テンプレート一覧を取得する | 空の配列と totalCount=0 が返る | |
| 操作者がスペース作成権限を持つ | offset に負の値を指定する | バリデーションエラーが返る | |
| 操作者がスペース作成権限を持つ | limit=1 で取得する | 1件が返る（境界値） | |
