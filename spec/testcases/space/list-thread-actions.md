# スレッドアクション一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理権限を持つ、スレッドアクションが複数件存在する | デフォルトの offset・limit でスレッドアクション一覧を取得する | スレッドアクション一覧と totalCount が返る | |
| 操作者が cybozu.com 共通管理者である（systemAdmin 権限なし） | スレッドアクション一覧を取得する | cybozu.com 共通管理者でもアクセス可能で、スレッドアクション一覧が返る | |
| 操作者がシステム管理権限を持つ、スレッドアクションが0件 | スレッドアクション一覧を取得する | 空配列と totalCount: 0 が返る | |
| 操作者がシステム管理権限を持つ、スレッドアクションが150件存在する | offset: 0, limit: 100 で取得する | 先頭100件が返り、totalCount: 150 が返る | |
| 操作者がシステム管理権限を持つ、スレッドアクションが150件存在する | offset: 100, limit: 100 で取得する | 残り50件が返り、totalCount: 150 が返る | |
| 操作者がシステム管理権限を持つ、スレッドアクションが150件存在する | offset: 150, limit: 100 で取得する | 空配列と totalCount: 150 が返る | |
| 操作者がシステム管理権限を持たない一般ユーザー | スレッドアクション一覧を取得する | SystemPermissionDeniedError が返る | |
