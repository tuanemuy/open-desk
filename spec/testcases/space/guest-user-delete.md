# ゲストユーザー削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理者権限を持ち、対象がゲストユーザー | ゲストユーザーを削除する | ゲストユーザーが全スペースから退会し、Identity ドメインから削除される | |
| 複数のゲストスペースに参加しているゲストユーザーで操作者がシステム管理者 | ゲストユーザーを削除する | 全スペースのメンバーシップが削除された後、ユーザーが削除される | |
| ゲストスペースに未参加のゲストユーザーで操作者がシステム管理者 | ゲストユーザーを削除する | ユーザーが正常に削除される | |
| 操作者が cybozu 管理者 | ゲストユーザーを削除する | ゲストユーザーが正常に削除される | |
| 操作者にシステム管理権限がない | ゲストユーザー削除を試みる | SystemPermissionDeniedError が返る | |
| 対象ユーザーがゲストユーザーでない（通常ユーザー） | ゲストユーザー削除を試みる | NotGuestUserError が返る | |
| 存在しない targetUserId を指定する | ゲストユーザー削除を試みる | UserNotFoundError が返る | |
