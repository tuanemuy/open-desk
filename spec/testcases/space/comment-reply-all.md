# 全員に返信 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーで、スレッドに複数の参加者がいる | テキスト付きで全員に返信する | コメントが作成され、スレッド参加者全員への @メンションが自動挿入される（操作者は除外） | |
| スペースメンバーで、スレッドに複数の参加者がいる | ファイル添付のみで全員に返信する | コメントが作成される（text=null, files あり、全員メンション） | |
| スペースメンバーで、スレッドに複数の参加者がいる | additionalMentions を追加して全員に返信する | スレッド参加者メンションと追加メンションが統合・重複排除される | |
| スペースメンバーで、スレッドに自分だけが参加している | 全員に返信する | 自分自身は除外されるため、メンションは空になる | |
| 存在しないスレッドIDを指定する | 全員に返信を試みる | ThreadNotFoundError が返る | |
| 操作者がスペースメンバーでない | 全員に返信を試みる | NotMemberError が返る | |
| スペースメンバーでスレッドに参加者がいる | text と files の両方を空にして全員に返信する | EmptyCommentError が返る | |
| スペースメンバーでスレッドに参加者が多数 | 全員メンション + additionalMentions が10件を超える | TooManyMentionsError が返る | |
| スペースメンバーでスレッドに参加者がいる | 全員メンション + additionalMentions の合計が10件 | コメントが正常に作成される（境界値） | |
| スペースメンバーでスレッドに参加者がいる | ファイルを6件添付して全員に返信する | TooManyFilesError が返る | |
| スペースメンバーでスレッドに参加者がいる | ファイルを5件添付して全員に返信する | コメントが正常に作成される（境界値） | |
| スペースメンバーで、additionalMentions にスレッド参加者と同じユーザーを指定 | 全員に返信する | 重複排除されてメンションの重複がなくなる | |
