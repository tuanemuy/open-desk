# スペース使用状況一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理者権限を持つ | スペース使用状況一覧を取得する | 全スペースの統計情報（spaceId, name, isGuest, memberCount, adminCount, createdAt）と totalCount が返る | |
| 操作者が cybozu 管理者である | スペース使用状況一覧を取得する | 全スペースの統計情報が正常に返る | |
| 操作者がシステム管理者権限を持つ | offset=0, limit=10 で取得する | 先頭10件のスペース情報が返る | |
| 操作者がシステム管理者権限を持つ | offset=10, limit=10 で取得する | 11件目から20件目のスペース情報が返る | |
| 操作者がシステム管理者権限を持つ | limit を省略して取得する | デフォルト100件で取得される | |
| 操作者がシステム管理者権限を持つ | offset を省略して取得する | デフォルト0から取得される | |
| 操作者がシステム管理者権限を持つ | limit=100 で取得する | 最大100件が返る（境界値） | |
| 操作者がシステム管理者権限を持つ | limit=101 で取得する | バリデーションエラーが返る（境界値） | |
| 操作者がシステム管理者権限を持つ | limit=1 で取得する | 1件が返る（境界値） | |
| 操作者がシステム管理者権限を持つ | offset に負の値を指定する | バリデーションエラーが返る | |
| 操作者にシステム管理権限がない | スペース使用状況一覧取得を試みる | SystemPermissionDeniedError が返る | |
| スペースが0件の状態で操作者がシステム管理者 | スペース使用状況一覧を取得する | 空の配列と totalCount=0 が返る | |
