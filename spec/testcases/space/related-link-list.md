# 関連リンク一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開スペースで関連リンクが複数存在し、操作者が認証済みユーザー | 関連リンク一覧を取得する | 関連リンク一覧（linkId, title, url）が返る | |
| 公開スペースで操作者がメンバーでない認証済みユーザー | 関連リンク一覧を取得する | 関連リンク一覧が正常に返る | |
| 非公開スペースで操作者がスペースメンバー | 関連リンク一覧を取得する | 関連リンク一覧が返る | |
| 非公開スペースで操作者がスペース管理者 | 関連リンク一覧を取得する | 関連リンク一覧が返る | |
| 存在しないスペースIDを指定する | 関連リンク一覧取得を試みる | SpaceNotFoundError が返る | |
| 非公開スペースで操作者がメンバーでない | 関連リンク一覧取得を試みる | SpaceAccessDeniedError が返る | |
| 関連リンクが0件のスペース | 関連リンク一覧を取得する | 空の配列が返る | |
