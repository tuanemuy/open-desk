# スペース作成（白紙） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース作成権限を持つ | 有効な入力で白紙スペースを作成する | スペースが作成され、デフォルトスレッドと初期メンバーが生成される。spaceId, defaultThreadId, createdAt が返る | |
| 操作者がスペース作成権限を持つ | isPrivate=true で作成する | 非公開スペースが作成される | |
| 操作者がスペース作成権限を持つ | isPrivate=false で作成する | 公開スペースが作成される | |
| 操作者がスペース作成権限を持つ | useMultiThread=true で作成する | マルチスレッドが有効なスペースが作成される | |
| 操作者がスペース作成権限を持つ | fixedMember=true で作成する | 固定メンバー設定のスペースが作成される | |
| 操作者がスペース作成権限を持つ | appCreationPermission="EVERYONE" で作成する | 全員がアプリ作成可能なスペースが作成される | |
| 操作者がスペース作成権限を持つ | appCreationPermission="ADMIN" で作成する | 管理者のみアプリ作成可能なスペースが作成される | |
| 操作者がスペース作成権限を持つ | coverImage に PRESET タイプを指定する | プリセットカバー画像のスペースが作成される | |
| 操作者がスペース作成権限を持つ | coverImage に BLOB タイプを指定する | BLOB カバー画像のスペースが作成される | |
| 操作者がスペース作成権限を持つ | 管理者1名を含む複数メンバーを指定する | 全メンバーが登録され、管理者が正しく設定される | |
| 操作者にスペース作成権限がない | スペース作成を試みる | SpacePermissionDeniedError が返る | |
| 操作者がスペース作成権限を持つ | name を空文字で作成する | EmptySpaceNameError が返る | |
| 操作者がスペース作成権限を持つ | name を129文字で作成する | SpaceNameTooLongError が返る | |
| 操作者がスペース作成権限を持つ | name を128文字で作成する | スペースが正常に作成される（境界値） | |
| 操作者がスペース作成権限を持つ | name を1文字で作成する | スペースが正常に作成される（境界値） | |
| 通常スペースが既に500件存在する | スペース作成を試みる | SpaceLimitExceededError が返る | |
| 通常スペースが499件存在する | スペース作成を試みる | スペースが正常に作成される（境界値） | |
| 操作者がスペース作成権限を持つ | members に管理者を含めずに作成する | NoAdminMemberError が返る | |
| 操作者がスペース作成権限を持つ | members を空配列で作成する | NoAdminMemberError が返る | |
| 操作者がスペース作成権限を持つ | PRESET の coverImage に無効なプリセットキーを指定する | バリデーションエラーが返る | |
| 操作者がスペース作成権限を持つ | BLOB の coverImage にファイルキーなしで指定する | バリデーションエラーが返る | |
