# ゲストスペース作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がゲストスペース作成権限を持ち、ゲストスペース機能が有効 | 有効な入力でゲストスペースを作成する | ゲストスペースが作成される。isGuest=true, isPrivate=true が設定される | |
| 操作者がゲストスペース作成権限を持つ | isPrivate を指定せずにゲストスペースを作成する | isPrivate=true が強制的に設定される | |
| 操作者がゲストスペース作成権限を持つ | useMultiThread=true で作成する | マルチスレッドが有効なゲストスペースが作成される | |
| 操作者がゲストスペース作成権限を持つ | fixedMember=true で作成する | 固定メンバー設定のゲストスペースが作成される | |
| 操作者がゲストスペース作成権限を持つ | appCreationPermission="EVERYONE" で作成する | 全員がアプリ作成可能なゲストスペースが作成される | |
| 操作者がゲストスペース作成権限を持つ | 管理者1名を含む複数メンバーを指定する | 全メンバーが登録され、管理者が正しく設定される | |
| 操作者にゲストスペース作成権限がない | ゲストスペース作成を試みる | SpacePermissionDeniedError が返る | |
| ゲストスペース機能が無効 | ゲストスペース作成を試みる | GuestSpaceFeatureDisabledError が返る | |
| 操作者がゲストスペース作成権限を持つ | name を空文字で作成する | EmptySpaceNameError が返る | |
| 操作者がゲストスペース作成権限を持つ | name を129文字で作成する | SpaceNameTooLongError が返る | |
| 操作者がゲストスペース作成権限を持つ | name を128文字で作成する | ゲストスペースが正常に作成される（境界値） | |
| 操作者がゲストスペース作成権限を持つ | name を1文字で作成する | ゲストスペースが正常に作成される（境界値） | |
| ゲストスペースが既に500件存在する | ゲストスペース作成を試みる | SpaceLimitExceededError が返る | |
| ゲストスペースが499件存在する | ゲストスペース作成を試みる | ゲストスペースが正常に作成される（境界値） | |
| 操作者がゲストスペース作成権限を持つ | members に管理者を含めずに作成する | NoAdminMemberError が返る | |
| 操作者がゲストスペース作成権限を持つ | members を空配列で作成する | NoAdminMemberError が返る | |
