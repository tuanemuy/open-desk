# スレッドフォロー テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーで、fixedMember=false、未フォロー状態 | スレッドをフォローする | フォロー関係が保存される | |
| 存在しないスレッドIDを指定する | スレッドフォローを試みる | ThreadNotFoundError が返る | |
| 操作者がスペースメンバーでない | スレッドフォローを試みる | NotMemberError が返る | |
| fixedMember=true のスペースで操作者がメンバー | スレッドフォローを試みる | FixedMemberError が返る | |
| スペースメンバーで、既にフォロー中 | スレッドフォローを試みる | AlreadyFollowingError が返る | |
| fixedMember=false のスペースで操作者がスペース管理者 | スレッドをフォローする | フォロー関係が正常に保存される | |
