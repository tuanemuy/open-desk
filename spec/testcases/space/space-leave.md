# スペース退会 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペースの一般メンバーで、fixedMember=false | スペースを退会する | 操作者がスペースメンバーから削除される | |
| 操作者がスペース管理者で、他に管理者が1名以上存在し、fixedMember=false | スペースを退会する | 操作者がスペースメンバーから削除される | |
| 存在しないスペースIDを指定する | スペース退会を試みる | SpaceNotFoundError が返る | |
| 操作者がスペースメンバーでない | スペース退会を試みる | NotMemberError が返る | |
| fixedMember=true のスペースで操作者がメンバー | スペース退会を試みる | FixedMemberError が返る | |
| 操作者がスペースの唯一の管理者 | スペース退会を試みる | LastAdminError が返る | |
| 操作者がスペースの唯一の管理者で、他に一般メンバーが存在する | スペース退会を試みる | LastAdminError が返る | |
| 操作者がスペース管理者で、他に管理者が1名存在する | スペースを退会する | 正常に退会できる（最後の管理者でない） | |
