# コメント削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がコメント投稿者 | コメントを削除する | コメントと関連いいねが削除される | |
| 操作者がスペース管理者（コメント投稿者でない） | コメントを削除する | コメントと関連いいねが削除される | |
| 操作者がコメント投稿者かつスペース管理者 | コメントを削除する | コメントが正常に削除される | |
| いいねが付いたコメントで操作者がコメント投稿者 | コメントを削除する | 関連いいねが先に削除された後、コメントが削除される | |
| 存在しないコメントIDを指定する | コメント削除を試みる | CommentNotFoundError が返る | |
| 操作者がコメント投稿者でもスペース管理者でもない（一般メンバー） | コメント削除を試みる | CommentDeletePermissionDeniedError が返る | |
| 操作者がスペースメンバーでない | コメント削除を試みる | CommentDeletePermissionDeniedError が返る | |
