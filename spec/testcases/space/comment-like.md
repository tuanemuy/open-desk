# コメントにいいね テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーで、コメントが存在し、未いいね状態 | コメントにいいねする | いいねが保存され、liked=true が返る | |
| スペースメンバーで、コメントが存在し、いいね済み状態 | コメントにいいねする（トグル） | いいねが取り消され、liked=false が返る | |
| スペースメンバーで、自分が投稿したコメントが存在し、未いいね状態 | 自分のコメントにいいねする | いいねが保存され、liked=true が返る | |
| 存在しないコメントIDを指定する | いいねを試みる | CommentNotFoundError が返る | |
| 操作者がスペースメンバーでない | いいねを試みる | NotMemberError が返る | |
| スペースメンバーで、いいねを付けた直後 | 再度いいね操作を行う | いいねが取り消され、liked=false が返る（トグル確認） | |
