# 関連リンク追加 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者 | 有効なタイトルとURLで関連リンクを追加する | 関連リンクが作成され、linkId, spaceId, title, url が返る | |
| 操作者がスペース管理者 | HTTPS の URL で関連リンクを追加する | 関連リンクが正常に作成される | |
| 操作者がスペース管理者 | HTTP の URL で関連リンクを追加する | 関連リンクが正常に作成される | |
| 存在しないスペースIDを指定する | 関連リンク追加を試みる | SpaceNotFoundError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | 関連リンク追加を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | 関連リンク追加を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペース管理者 | title を空文字で追加する | バリデーションエラーが返る | |
| 操作者がスペース管理者 | url を空文字で追加する | バリデーションエラーが返る | |
| 操作者がスペース管理者 | 不正な URL 形式で追加する | バリデーションエラーが返る | |
