# メンバー一括更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者である | 管理者1名を含む有効なメンバーリストで置き換える | メンバー構成が指定リストに置き換わる | |
| 操作者がスペース管理者である | 新しいメンバーを追加したリストで置き換える | 新メンバーが追加され、除外されたメンバーは削除される | |
| 操作者がスペース管理者である | 既存メンバーの isAdmin を変更したリストで置き換える | 管理者権限が更新される | |
| 操作者がスペース管理者である | includeSubs を変更したリストで置き換える | サブ組織含む設定が更新される | |
| 存在しないスペースIDを指定する | メンバー一括更新を試みる | SpaceNotFoundError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | メンバー一括更新を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | メンバー一括更新を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペース管理者である | 管理者を含まないメンバーリストで置き換える | NoAdminMemberError が返る | |
| 操作者がスペース管理者である | 空のメンバーリストで置き換える | NoAdminMemberError が返る | |
| 操作者がスペース管理者である | 使用停止中のユーザーを含むメンバーリストで置き換える | InvalidMemberError が返る | |
| 操作者がスペース管理者である | 削除済みのユーザーを含むメンバーリストで置き換える | InvalidMemberError が返る | |
| 操作者がスペース管理者である | 管理者を複数名含むメンバーリストで置き換える | 複数管理者が正しく設定される | |
