# 返信（@メンション自動挿入） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スペースメンバーで、返信先コメントが存在する | テキスト付きで返信する | コメントが作成され、返信先投稿者への @メンションが自動挿入される | |
| スペースメンバーで、返信先コメントが存在する | ファイル添付のみで返信する | コメントが作成される（text=null, files あり、メンション自動挿入あり） | |
| スペースメンバーで、返信先コメントが存在する | additionalMentions を追加して返信する | 自動挿入メンションと追加メンションが統合される | |
| スペースメンバーで、返信先コメントが自分の投稿 | 自分のコメントに返信する | 自分自身へのメンションは重複排除される | |
| スペースメンバーで、返信先コメントが存在する | additionalMentions に返信先投稿者を含めて返信する | 重複排除されてメンションは1件になる | |
| 存在しないスレッドIDを指定する | 返信を試みる | ThreadNotFoundError が返る | |
| 操作者がスペースメンバーでない | 返信を試みる | NotMemberError が返る | |
| 存在しない replyToCommentId を指定する | 返信を試みる | CommentNotFoundError が返る | |
| スペースメンバーで返信先コメントが存在する | text と files の両方を空にして返信する | EmptyCommentError が返る | |
| スペースメンバーで返信先コメントが存在する | 自動挿入分と additionalMentions の合計が10件を超える | TooManyMentionsError が返る | |
| スペースメンバーで返信先コメントが存在する | 自動挿入分と additionalMentions の合計が10件 | コメントが正常に作成される（境界値） | |
| スペースメンバーで返信先コメントが存在する | ファイルを6件添付して返信する | TooManyFilesError が返る | |
| スペースメンバーで返信先コメントが存在する | ファイルを5件添付して返信する | コメントが正常に作成される（境界値） | |
