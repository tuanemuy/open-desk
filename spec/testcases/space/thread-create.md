# スレッド作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| マルチスレッドスペースで操作者がスペースメンバー | 有効なタイトルでスレッドを作成する | スレッドが作成され、作成者が自動フォローされる。threadId, spaceId, title, creatorId, createdAt が返る | |
| マルチスレッドスペースで操作者がスペースメンバー | タイトルと本文を指定してスレッドを作成する | スレッドが作成され body が設定される | |
| マルチスレッドスペースで操作者がスペースメンバー | notifyOnCreate=true でスレッドを作成する | スレッドが作成され、スペースメンバーに通知が送信される | |
| マルチスレッドスペースで操作者がスペースメンバー | notifyOnCreate=false でスレッドを作成する | スレッドが作成され、通知は送信されない | |
| マルチスレッドスペースで操作者がスペースメンバー | notifyOnCreate を省略してスレッドを作成する | スレッドが作成され、通知は送信されない（デフォルト: false） | |
| 存在しないスペースIDを指定する | スレッド作成を試みる | SpaceNotFoundError が返る | |
| シングルスレッドスペース（useMultiThread=false） | スレッド作成を試みる | MultiThreadRequiredError が返る | |
| マルチスレッドスペースで操作者がスペースメンバーでない | スレッド作成を試みる | NotMemberError が返る | |
| マルチスレッドスペースで操作者がスペースメンバー | title を空文字で作成する | EmptyThreadTitleError が返る | |
| マルチスレッドスペースで操作者がスペースメンバー | title を129文字で作成する | ThreadTitleTooLongError が返る | |
| マルチスレッドスペースで操作者がスペースメンバー | title を128文字で作成する | スレッドが正常に作成される（境界値） | |
| マルチスレッドスペースで操作者がスペースメンバー | title を1文字で作成する | スレッドが正常に作成される（境界値） | |
| マルチスレッドスペースで操作者がスペースメンバー | body を65,535文字で作成する | スレッドが正常に作成される（境界値） | |
| マルチスレッドスペースで操作者がスペースメンバー | body を65,536文字で作成する | ThreadBodyTooLongError が返る | |
| マルチスレッドスペースで操作者がスペースメンバー | body を省略して作成する | body=null のスレッドが正常に作成される | |
