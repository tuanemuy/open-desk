# テンプレート削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理者権限を持ち、テンプレートが存在する | テンプレートを削除する | テンプレートが削除される | |
| 操作者が cybozu 管理者で、テンプレートが存在する | テンプレートを削除する | テンプレートが正常に削除される | |
| 操作者にシステム管理権限がない | テンプレート削除を試みる | SystemPermissionDeniedError が返る | |
| 存在しない templateId を指定する | テンプレート削除を試みる | SpaceTemplateNotFoundError が返る | |
