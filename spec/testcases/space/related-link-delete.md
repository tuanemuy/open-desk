# 関連リンク削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がスペース管理者で、関連リンクが存在する | 関連リンクを削除する | 関連リンクが削除される | |
| 存在しない linkId を指定する | 関連リンク削除を試みる | RelatedLinkNotFoundError が返る | |
| 操作者がスペース管理者でない（一般メンバー） | 関連リンク削除を試みる | SpaceAdminRequiredError が返る | |
| 操作者がスペースメンバーでない | 関連リンク削除を試みる | SpaceAdminRequiredError が返る | |
