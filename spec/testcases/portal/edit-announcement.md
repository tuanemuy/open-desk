# お知らせ掲示板編集 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がシステム管理者である | 有効なタイトル・本文・添付ファイルキーでお知らせ掲示板を編集する | お知らせ掲示板が更新され、更新後の DTO が返る | |
| 操作者が cybozu.com 共通管理者である | 有効なタイトル・本文・添付ファイルキーでお知らせ掲示板を編集する | お知らせ掲示板が更新され、更新後の DTO が返る | |
| 既存のお知らせ掲示板が存在しない | システム管理者がお知らせ掲示板を編集する | デフォルト値（タイトル:「お知らせ」）で新規作成された後に更新される | |
| 操作者がシステム管理者である | 本文を空文字、添付ファイルを空配列で編集する | 本文が空文字、添付ファイルが空配列で正常に更新される | |
| 操作者がシステム管理者でも cybozu.com 共通管理者でもない | お知らせ掲示板を編集する | AnnouncementPermissionError が返る | |
| 操作者がシステム管理者である | タイトルを空文字で編集する | EmptyTitleError が返る | |
| 操作者がシステム管理者である | 1GB を超える添付ファイルを含めて編集する | AttachmentTooLargeError が返る | |
| 操作者がシステム管理者である | 添付ファイルがちょうど 1GB（1,073,741,824 バイト）である | 正常に更新される | |
| 操作者がシステム管理者である | 添付ファイルが 1GB + 1 バイト（1,073,741,825 バイト）である | AttachmentTooLargeError が返る | |
| 操作者がシステム管理者である | タイトルが1文字（最小の有効値）で編集する | 正常に更新される | |
| 操作者がシステム管理者である | 複数の添付ファイルを含めて編集する（すべて1GB以下） | 正常に更新される | |
| 操作者がシステム管理者である | 複数の添付ファイルのうち1つだけ1GBを超える | AttachmentTooLargeError が返る | |
| 既存のお知らせ掲示板に添付ファイルがある状態 | 添付ファイルを空配列に変更して編集する | 添付ファイルがクリアされ正常に更新される | |
