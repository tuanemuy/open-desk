# ポータル表示取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 認証済みユーザーであり、お知らせ掲示板が存在する | デフォルトパラメータでポータル表示を取得する | お知らせ掲示板・通知・スペース・アプリの各ウィジェットデータが返る | |
| 認証済みユーザーであり、お知らせ掲示板が存在しない | ポータル表示を取得する | announcement が null で、他のウィジェットデータが返る | |
| 認証済みユーザーである | spaceWidgetDisplayMode を "joined" で取得する | 参加中のスペースのみがスペースウィジェットに返る | |
| 認証済みユーザーである | appWidgetDisplayMode を "all" で取得する | すべてのアプリがアプリウィジェットに返る | |
| 認証済みユーザーである | notificationFilterMode を "all" で取得する | すべての通知が通知ウィジェットに返る | |
| 認証済みユーザーである | spaceWidgetDisplayMode を未指定で取得する | デフォルト値 "joined" が適用される | |
| 認証済みユーザーである | appWidgetDisplayMode を未指定で取得する | デフォルト値 "all" が適用される | |
| 認証済みユーザーである | notificationFilterMode を未指定で取得する | デフォルト値 "all" が適用される | |
| Notification ドメインが障害中 | ポータル表示を取得する | 通知ウィジェットは空で返却され、他のウィジェットは正常に取得できる | |
| Space ドメインが障害中 | ポータル表示を取得する | スペースウィジェットは空で返却され、他のウィジェットは正常に取得できる | |
| App ドメインが障害中 | ポータル表示を取得する | アプリウィジェットは空で返却され、他のウィジェットは正常に取得できる | |
| 全外部ドメイン（Notification, Space, App）が障害中 | ポータル表示を取得する | すべてのウィジェットが空で返却され、お知らせ掲示板のみ表示される | |
| 認証済みユーザーであり、通知・スペース・アプリが0件 | ポータル表示を取得する | 各ウィジェットが空配列・totalCount: 0 で正常に返る | |
