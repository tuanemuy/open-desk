# 組織間アクセス権評価 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーが存在し、ユーザーの所属組織からターゲット組織への FULL ルールが有効 | ユーザーのターゲット組織へのアクセスを評価する | accessLevel: FULL が返る | |
| 対象ユーザーが存在し、ユーザーの所属組織からターゲット組織への READ_ONLY ルールが有効 | ユーザーのターゲット組織へのアクセスを評価する | accessLevel: READ_ONLY が返る | |
| 対象ユーザーが存在し、ユーザーの所属組織からターゲット組織への NONE ルールが有効 | ユーザーのターゲット組織へのアクセスを評価する | accessLevel: NONE が返る | |
| 対象ユーザーが cybozu.com 共通管理者である | ユーザーのターゲット組織へのアクセスを評価する | ルールに関係なく accessLevel: FULL が即座に返る | |
| 対象ユーザーが存在し、ユーザーの所属組織からターゲット組織へのルールが存在しない | ユーザーのターゲット組織へのアクセスを評価する | デフォルトの accessLevel が返る | |
| 対象ユーザーが存在し、ユーザーの所属組織からターゲット組織へのルールが存在するが無効（isEnabled: false） | ユーザーのターゲット組織へのアクセスを評価する | 無効なルールは適用されず、デフォルトの accessLevel が返る | |
| 対象ユーザーが複数の組織に所属し、各組織からターゲット組織へ異なるルールが設定されている | ユーザーのターゲット組織へのアクセスを評価する | OrgAccessEvaluationService によって適切に評価された accessLevel が返る | |
| 対象ユーザーが存在し、ユーザーがどの組織にも所属していない | ユーザーのターゲット組織へのアクセスを評価する | デフォルトの accessLevel が返る | |
| 対象ユーザーが存在しない | ユーザーのターゲット組織へのアクセスを評価する | UserNotFoundError が返る | |
