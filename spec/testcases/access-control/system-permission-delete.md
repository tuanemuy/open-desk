# システム権限の削除 テストケース

UC-AC10: システム権限設定を削除する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者にシステム管理権限があり、対象のシステム権限が存在する | システム権限削除を実行する | システム権限が削除される | |
| 操作者が cybozu.com 共通管理者で、対象のシステム権限が存在する | システム権限削除を実行する | 正常にシステム権限が削除される | |
| 操作者にシステム管理権限がなく、cybozu.com 共通管理者でもない | システム権限削除を実行する | SystemPermissionDeniedError が返される | |
| 対象のシステム権限が存在しない | システム権限削除を実行する | SystemPermissionNotFoundError が返される | |
| 対象のシステム権限を削除した後 | 同じ systemPermissionId で再度削除を試みる | SystemPermissionNotFoundError が返される | |
| systemAdmin=true のシステム権限が対象 | 削除を実行する | 正常に削除される | |
