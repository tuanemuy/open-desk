# アプリアクセス権の取得 テストケース

UC-AC01: アプリIDを指定してアプリアクセス権設定を取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリが存在し、操作者にアプリ管理権限（appEditable）がある | アプリアクセス権取得を実行する | appId, rights, revision を含むアプリアクセス権が返される | |
| アプリが存在し、複数のアクセス権エントリが設定されている | アプリアクセス権取得を実行する | 全てのアクセス権エントリが返される | |
| アプリが存在するが、操作者にアプリ管理権限がない | アプリアクセス権取得を実行する | AppPermissionDeniedError が返される | |
| アプリが存在しない | アプリアクセス権取得を実行する | AppNotFoundError が返される | |
| アプリが存在し、操作者がアプリ作成者である | アプリアクセス権取得を実行する | アプリ作成者として権限が評価され、結果が返される | |
| アプリが存在し、操作者が組織経由でアプリ管理権限を持つ | アプリアクセス権取得を実行する | 組織経由の権限が評価され、正常に取得できる | |
