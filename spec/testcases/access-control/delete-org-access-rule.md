# 組織間アクセス権削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者が cybozu.com 共通管理者である、組織間アクセス権が存在する | 組織間アクセス権を削除する | 組織間アクセス権が削除される | |
| 操作者が cybozu.com 共通管理者である、有効な組織間アクセス権が存在する | 有効なルールを削除する | 正常に削除される | |
| 操作者が cybozu.com 共通管理者である、無効な組織間アクセス権が存在する | 無効なルールを削除する | 正常に削除される | |
| 操作者が cybozu.com 共通管理者でない | 組織間アクセス権を削除する | CybozuAdminRequiredError が返る | |
| 操作者が cybozu.com 共通管理者である | 存在しない orgAccessRuleId を指定して削除する | OrgAccessRuleNotFoundError が返る | |
