# システム権限一覧の取得 テストケース

UC-AC07: 全システム権限設定を取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者にシステム管理権限（SYSTEM_ADMIN）がある | システム権限一覧取得を実行する | 全てのシステム権限設定（permissions）が返される | |
| 操作者が cybozu.com 共通管理者（isCybozuAdmin=true） | システム権限一覧取得を実行する | 全てのシステム権限設定が返される | |
| 操作者にシステム管理権限がなく、cybozu.com 共通管理者でもない | システム権限一覧取得を実行する | SystemPermissionDeniedError が返される | |
| システム権限が1件も設定されていない | 管理者がシステム権限一覧取得を実行する | 空の permissions 配列が返される | |
| 複数のシステム権限が設定されている（ユーザー、組織、グループ） | 管理者がシステム権限一覧取得を実行する | 全エンティティタイプの権限設定が返される | |
| 操作者が組織経由でシステム管理権限を持つ | システム権限一覧取得を実行する | 正常に全システム権限設定が返される | |
