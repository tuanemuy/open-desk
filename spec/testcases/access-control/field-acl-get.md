# フィールドアクセス権の取得 テストケース

UC-AC05: アプリIDを指定してフィールドアクセス権設定を取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリが存在し、操作者にアプリ管理権限がある | フィールドアクセス権取得を実行する | appId, rights, revision を含むフィールドアクセス権が返される | |
| アプリが存在し、複数のフィールドアクセス権ルールが設定されている | フィールドアクセス権取得を実行する | 全ルールが返される | |
| アプリが存在するが、操作者にアプリ管理権限がない | フィールドアクセス権取得を実行する | AppPermissionDeniedError が返される | |
| アプリが存在しない | フィールドアクセス権取得を実行する | AppNotFoundError が返される | |
| アプリが存在し、フィールドアクセス権が設定されていない | フィールドアクセス権取得を実行する | 空の rights が返される | |
| アプリが存在し、操作者が組織経由でアプリ管理権限を持つ | フィールドアクセス権取得を実行する | 正常に取得できる | |
