# システム権限の更新 テストケース

UC-AC09: 既存のシステム権限設定を更新する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者にシステム管理権限があり、対象のシステム権限が存在する | 有効な権限フラグを指定して更新する | システム権限が更新され、更新後の設定が返される | |
| 操作者が cybozu.com 共通管理者で、対象のシステム権限が存在する | 更新を実行する | 正常にシステム権限が更新される | |
| 操作者にシステム管理権限がなく、cybozu.com 共通管理者でもない | 更新を実行する | SystemPermissionDeniedError が返される | |
| 対象のシステム権限が存在しない | 更新を実行する | SystemPermissionNotFoundError が返される | |
| 対象のシステム権限が存在する | systemAdmin を false から true に変更する | systemAdmin が true に更新される | |
| 対象のシステム権限が存在する | systemAdmin を true から false に変更する | systemAdmin が false に更新される | |
| 対象のシステム権限が存在する | 全権限フラグを true に更新する | 全項目が true に更新される | |
| 対象のシステム権限が存在する | 全権限フラグを false に更新する | 全項目が false に更新される | |
| 対象のシステム権限が存在する | appCreate のみ true、他は全て false に更新する | appCreate のみ true、他は false で更新される | |
| 対象のシステム権限が存在する | 更新前と同じ値で更新を実行する | 正常に完了し、値は変更なし | |
