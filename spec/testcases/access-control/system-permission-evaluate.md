# ユーザーのシステム権限評価 テストケース

UC-AC11: 指定ユーザーに適用されるシステム権限を結合評価する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 対象ユーザーが存在し、ユーザー直接のシステム権限が設定されている | 権限評価を実行する | ユーザーの権限が返される | |
| 対象ユーザーが存在し、組織経由のシステム権限が設定されている | 権限評価を実行する | 組織経由の権限が OR 結合されて返される | |
| 対象ユーザーが存在し、グループ経由のシステム権限が設定されている | 権限評価を実行する | グループ経由の権限が OR 結合されて返される | |
| 対象ユーザーが複数の権限設定を持つ（ユーザー、組織、グループ） | 権限評価を実行する | 全ての権限が OR 結合されて返される（いずれかで true なら true） | |
| 対象ユーザーが cybozu.com 共通管理者（isCybozuAdmin=true） | 権限評価を実行する | 全権限項目が true で返される | |
| 対象ユーザーのいずれかの SystemPermission で SYSTEM_ADMIN が true | 権限評価を実行する | 全権限項目が true で返される | |
| 対象ユーザーにシステム権限が一切設定されていない | 権限評価を実行する | 全権限項目が false で返される | |
| 対象ユーザーが存在しない | 権限評価を実行する | UserNotFoundError が返される | |
| 対象ユーザーに appCreate=true の権限のみがある | 権限評価を実行する | appCreate=true、他の項目は false で返される | |
| 対象ユーザーに組織A（appCreate=true）と組織B（spaceCreate=true）の権限がある | 権限評価を実行する | appCreate=true, spaceCreate=true、他は false で返される（OR 結合） | |
| 対象ユーザーに全権限が false の SystemPermission のみがある | 権限評価を実行する | 全権限項目が false で返される | |
