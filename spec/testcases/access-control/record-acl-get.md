# レコードアクセス権の取得 テストケース

UC-AC03: アプリIDを指定してレコードアクセス権設定を取得する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリが存在し、操作者にアプリ管理権限がある | レコードアクセス権取得を実行する | appId, rights, revision を含むレコードアクセス権が返される | |
| アプリが存在し、操作者にアプリ管理権限がある | lang="ja" を指定してレコードアクセス権取得を実行する | フィールド名が日本語でローカライズされて返される | |
| アプリが存在し、操作者にアプリ管理権限がある | lang="en" を指定してレコードアクセス権取得を実行する | フィールド名が英語でローカライズされて返される | |
| アプリが存在し、操作者にアプリ管理権限がある | lang を省略してレコードアクセス権取得を実行する | フィールド名のローカライズなしで返される | |
| アプリが存在するが、操作者にアプリ管理権限がない | レコードアクセス権取得を実行する | AppPermissionDeniedError が返される | |
| アプリが存在しない | レコードアクセス権取得を実行する | AppNotFoundError が返される | |
| アプリが存在し、レコードアクセス権が複数ルール設定されている | レコードアクセス権取得を実行する | 全ルールが返される | |
| アプリが存在し、filterCond が設定されたルールがある | レコードアクセス権取得を実行する | filterCond を含むルールが正しく返される | |
