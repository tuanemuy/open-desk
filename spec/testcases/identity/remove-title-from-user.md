# ユーザーからの役職解除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーに役職が割り当てられている | ユーザーから役職を解除する | 役職の割り当てが解除され、正常終了する | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | titleId を空文字で送信する | バリデーションエラーが返される | |
| - | titleId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーから役職を解除する | UserNotFoundError が返される | |
| 指定した titleId の役職が存在しない | ユーザーから役職を解除する | TitleNotFoundError が返される | |
| ユーザーにその役職が割り当てられていない | ユーザーから役職を解除する | TitleNotAssignedError が返される | |
| ユーザーが役職A・Bの2つを持っている | 役職Aのみ解除する | 役職Aのみ解除され、役職Bの割り当ては維持される | |
