# OAuthトークンリフレッシュ テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効なリフレッシュトークンが存在する | リフレッシュトークンでトークンを更新する | 新しい accessToken・refreshToken・expiresAt・scopes が返却される | |
| - | refreshToken を空文字で送信する | バリデーションエラーが返される | |
| リフレッシュトークンが無効（期限切れ等） | 無効なリフレッシュトークンで更新する | InvalidTokenError が返される | |
| リフレッシュトークンが存在しない | 存在しないリフレッシュトークンで更新する | InvalidTokenError が返される | |
| 有効なリフレッシュトークンが存在する | トークンリフレッシュ後、旧リフレッシュトークンで再度更新する | InvalidTokenError が返される（ローテーション） | |
