# グループからのユーザー削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーがグループに所属している | ユーザーをグループから削除する | ユーザーのグループ所属が解除され、正常終了する | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | groupId を空文字で送信する | バリデーションエラーが返される | |
| - | groupId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーをグループから削除する | UserNotFoundError が返される | |
| 指定した groupId のグループが存在しない | ユーザーをグループから削除する | GroupNotFoundError が返される | |
| ユーザーがそのグループに所属していない | グループからユーザーを削除する | NotMemberError が返される | |
