# SCIM ユーザーの削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーが存在する | SCIM ユーザーを削除する | ユーザーが削除され、正常終了する | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーがセッションを持つ | SCIM ユーザーを削除する | ユーザーの全セッションが強制終了される | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーが組織に所属している | SCIM ユーザーを削除する | ユーザーの全組織所属関係が解除される | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーがグループに所属している | SCIM ユーザーを削除する | ユーザーの全グループ所属関係が解除される | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーに役職が割り当てられている | SCIM ユーザーを削除する | ユーザーの全役職割り当てが解除される | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーが存在する | SCIM ユーザーを削除する | 外部マッピング（externalId, resourceType="User"）が削除される | |
| プロビジョニングが有効でトークンが正しく、SCIM ユーザーが組織・グループ・役職すべてに関連している | SCIM ユーザーを削除する | セッション終了・組織解除・グループ解除・役職解除・ユーザー削除・マッピング削除がすべて実行される | |
| - | bearerToken を空文字で送信する | バリデーションエラーが返される | |
| - | externalId を空文字で送信する | バリデーションエラーが返される | |
| プロビジョニングが無効 | SCIM ユーザーを削除する | ProvisioningDisabledError が返される | |
| プロビジョニングが有効だがトークンが不正 | SCIM ユーザーを削除する | InvalidBearerTokenError が返される | |
| 指定した externalId に対応するマッピングが存在しない | SCIM ユーザーを削除する | ScimResourceNotFoundError が返される | |
| externalId のマッピングは存在するが、マッピング先のユーザーが存在しない | SCIM ユーザーを削除する | ScimResourceNotFoundError が返される | |
