# APIトークン発行 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリ管理者ユーザーが存在する | 有効なスコープ1つを指定して API トークンを発行する | トークン文字列とスコープが返却される | |
| アプリ管理者ユーザーが存在する | 複数の有効なスコープを指定して API トークンを発行する | トークン文字列と全スコープが返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | scopes を空配列で送信する | バリデーションエラーが返される | |
| - | scopes に無効なスコープ値を含めて送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | API トークンを発行する | UserNotFoundError が返される | |
| アプリ管理者ユーザーが存在する | 全種類の有効なスコープを指定して発行する | トークンが正常に発行される | |
