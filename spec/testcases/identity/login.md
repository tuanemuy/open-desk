# ログイン（パスワード認証） テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効なユーザーが存在する | 正しいログイン名とパスワードでログインする | セッションが作成され、sessionId・userId・displayName・language・timezone・expiresAtが返却される | |
| 有効なユーザーが存在する | 正しい認証情報と country（JP）を指定してログインする | セッションが作成され、country が記録される | |
| 有効なユーザーが存在する | 正しい認証情報で country を省略してログインする | セッションが作成される（country は null） | |
| - | loginName を空文字で送信する | バリデーションエラーが返される | |
| - | loginName にメールアドレス形式でない文字列を送信する | バリデーションエラーが返される | |
| - | password を空文字で送信する | バリデーションエラーが返される | |
| - | ipAddress を空文字で送信する | バリデーションエラーが返される | |
| - | ipAddress に不正な形式（例: "abc"）を送信する | バリデーションエラーが返される | |
| - | userAgent を空文字で送信する | バリデーションエラーが返される | |
| - | country に ISO 3166-1 alpha-2 でない文字列（例: "JPN"）を指定する | バリデーションエラーが返される | |
| 指定したログイン名のユーザーが存在しない | 存在しないログイン名でログインする | InvalidCredentialsError が返される | |
| 有効なユーザーが存在する | 正しいログイン名と誤ったパスワードでログインする | InvalidCredentialsError が返される | |
| ユーザーが無効化されている（isActive = false） | そのユーザーの認証情報でログインする | UserInactiveError が返される | |
| アカウントがロックアウトされている | そのユーザーの認証情報でログインする | AccountLockedError が返される | |
| 有効なユーザーが存在する | IPv4 アドレス（例: "192.168.1.1"）でログインする | セッションが作成され、ipAddress が記録される | |
| 有効なユーザーが存在する | IPv6 アドレス（例: "::1"）でログインする | セッションが作成され、ipAddress が記録される | |
