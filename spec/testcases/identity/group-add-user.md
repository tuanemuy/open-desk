# グループへのユーザー追加 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーとグループが存在し、ユーザーがそのグループに未所属 | ユーザーをグループに追加する | ユーザーがグループメンバーとして追加され、userId・groupId が返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | groupId を空文字で送信する | バリデーションエラーが返される | |
| - | groupId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーをグループに追加する | UserNotFoundError が返される | |
| 指定した groupId のグループが存在しない | ユーザーをグループに追加する | GroupNotFoundError が返される | |
| ユーザーが既にそのグループに所属している | 同じユーザーを同じグループに再度追加する | AlreadyMemberError が返される | |
| ユーザーがグループAに所属している | 同じユーザーを別のグループBに追加する | ユーザーがグループBにも追加される（複数グループ所属可） | |
