# ログイン履歴取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが過去2週間以内にログインした履歴がある | ログイン履歴を取得する | loginHistories に過去2週間分の履歴が createdAt 降順で返却される | |
| ユーザーが過去2週間以内にログインした履歴がない | ログイン履歴を取得する | loginHistories が空配列で返却される | |
| ユーザーが15日前にログインした履歴のみがある | ログイン履歴を取得する | loginHistories が空配列で返却される（2週間超過のため除外） | |
| ユーザーが14日前にログインした履歴がある | ログイン履歴を取得する | その履歴が含まれる（境界値：ちょうど14日前） | |
| 同一 userAgent で15件のログイン履歴がある | ログイン履歴を取得する | 同一 userAgent グループで最新10件のみ返却される | |
| 異なる3つの userAgent でそれぞれ5件のログイン履歴がある | ログイン履歴を取得する | 各 userAgent グループ5件ずつ、計15件が createdAt 降順でマージされて返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ログイン履歴を取得する | UserNotFoundError が返される | |
| ユーザーが期限切れセッションと有効セッションの両方を持っている | ログイン履歴を取得する | 期限切れ・有効の両方が含まれる（過去2週間以内であれば） | |
