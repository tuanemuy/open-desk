# グループの削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 所属メンバーなしのグループが存在する | グループを削除する | グループが削除され、正常終了する | |
| - | groupId を空文字で送信する | バリデーションエラーが返される | |
| - | groupId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した groupId のグループが存在しない | グループを削除する | GroupNotFoundError が返される | |
| グループに所属ユーザーが1人存在する | グループを削除する | GroupHasMembersError が返される | |
| グループに所属ユーザーが複数存在する | グループを削除する | GroupHasMembersError が返される | |
