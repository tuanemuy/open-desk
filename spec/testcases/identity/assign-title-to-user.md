# ユーザーへの役職割り当て テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーと役職が存在し、ユーザーにその役職が未割り当て | ユーザーに役職を割り当てる | 役職が割り当てられ、userId・titleId が返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | titleId を空文字で送信する | バリデーションエラーが返される | |
| - | titleId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーに役職を割り当てる | UserNotFoundError が返される | |
| 指定した titleId の役職が存在しない | ユーザーに役職を割り当てる | TitleNotFoundError が返される | |
| ユーザーに既にその役職が割り当て済み | 同じユーザーに同じ役職を再度割り当てる | TitleAlreadyAssignedError が返される | |
| ユーザーが役職Aを持っている | 同じユーザーに別の役職Bを割り当てる | ユーザーに役職Bも追加される（複数役職保持可） | |
