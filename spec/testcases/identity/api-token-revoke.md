# APIトークン無効化 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリ管理者ユーザーに紐づく有効な API トークンが存在する | 有効なトークンを無効化する | トークンが無効化され、正常終了する | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | token を空文字で送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | トークンを無効化する | UserNotFoundError が返される | |
| ユーザーは存在するがトークンが存在しない | 存在しないトークン文字列で無効化する | InvalidTokenError が返される | |
| ユーザーは存在するがトークンが既に無効化済み | 無効化済みのトークンで再度無効化する | InvalidTokenError が返される | |
| ユーザーAのトークンが存在する | ユーザーBの userId でユーザーAのトークンを無効化する | InvalidTokenError が返される | |
