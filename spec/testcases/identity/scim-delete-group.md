# SCIM グループの削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| プロビジョニングが有効でトークンが正しく、SCIM グループが存在する（メンバーなし） | SCIM グループを削除する | グループが削除され、正常終了する | |
| プロビジョニングが有効でトークンが正しく、SCIM グループにメンバーが所属している | SCIM グループを削除する | 全メンバーのグループ所属関係が解除された後、グループが削除される | |
| プロビジョニングが有効でトークンが正しく、SCIM グループにメンバーが複数所属している | SCIM グループを削除する | 全メンバーのグループ所属関係が解除され、グループが削除される | |
| プロビジョニングが有効でトークンが正しく、SCIM グループが存在する | SCIM グループを削除する | 外部マッピング（externalId, resourceType="Group"）が削除される | |
| - | bearerToken を空文字で送信する | バリデーションエラーが返される | |
| - | externalId を空文字で送信する | バリデーションエラーが返される | |
| プロビジョニングが無効 | SCIM グループを削除する | ProvisioningDisabledError が返される | |
| プロビジョニングが有効だがトークンが不正 | SCIM グループを削除する | InvalidBearerTokenError が返される | |
| 指定した externalId に対応するマッピングが存在しない | SCIM グループを削除する | ScimResourceNotFoundError が返される | |
| externalId のマッピングは存在するが、マッピング先のグループが存在しない | SCIM グループを削除する | ScimResourceNotFoundError が返される | |
