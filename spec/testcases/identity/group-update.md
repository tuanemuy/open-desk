# グループの更新 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| グループが存在する | name を新しい値に変更する | グループ名が変更され、groupId・name・code が返却される | |
| - | groupId を空文字で送信する | バリデーションエラーが返される | |
| - | groupId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | name を空文字で指定する | EmptyGroupNameError が返される | |
| 指定した groupId のグループが存在しない | グループを更新する | GroupNotFoundError が返される | |
| グループが存在する | 同じ name に更新する（変更なし） | 更新が正常に完了する | |
