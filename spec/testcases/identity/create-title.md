# 役職の作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| システム管理者が認証済み | name を指定して役職を作成する | 役職が作成され、titleId・name・orderIndex・createdAt が返却される | |
| システム管理者が認証済み | orderIndex を省略して役職を作成する | orderIndex が 0 で作成される | |
| システム管理者が認証済み | orderIndex を 5 に指定して役職を作成する | orderIndex が 5 で作成される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | orderIndex に負数（-1）を指定する | バリデーションエラーが返される | |
| - | orderIndex に小数（1.5）を指定する | バリデーションエラーが返される | |
| 同一の name を持つ役職が既に存在する | 同じ name で役職を作成する | DuplicateTitleNameError が返される | |
| 既存の役職名と大文字小文字が異なる名前の役職がある | 同じ名前で大文字小文字を変えて作成する | 一意性チェックの仕様に従い、重複判定される | |
| - | orderIndex を 0 に指定して作成する | orderIndex が 0 で作成される（境界値） | |
| - | 一意な name で複数の役職を作成する | 各役職が正常に作成される | |
