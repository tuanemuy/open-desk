# 役職一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 役職が5件存在する | 役職一覧を取得する | 5件の役職情報が返却され、totalCount=5 となる | |
| 役職が存在しない | 役職一覧を取得する | titles が空配列で返却され、totalCount=0 となる | |
| 役職が15件存在する | offset=0, limit=10 で取得する | 先頭10件が返却され、totalCount=15 となる | |
| 役職が15件存在する | offset=10, limit=10 で取得する | 残り5件が返却され、totalCount=15 となる | |
| 役職が15件存在する | offset=15, limit=10 で取得する | titles が空配列で返却され、totalCount=15 となる | |
| "マネージャー" と "シニアマネージャー" の役職が存在する | keyword="マネージャー" で取得する | 部分一致で2件が返却される | |
| 役職が存在する | keyword に一致する役職がない文字列を指定する | titles が空配列で返却され、totalCount=0 となる | |
| - | offset に負数（-1）を指定する | バリデーションエラーが返される | |
| - | limit に 0 を指定する | バリデーションエラーが返される | |
| - | limit に 101 を指定する | バリデーションエラーが返される | |
| - | offset・limit を省略して取得する | offset=0, limit=100 のデフォルト値で取得される | |
| - | limit に 1 を指定する | 先頭1件のみ返却される（境界値） | |
| - | limit に 100 を指定する | 最大100件が返却される（境界値） | |
