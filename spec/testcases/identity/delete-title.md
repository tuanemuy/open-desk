# 役職の削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 割り当て済みユーザーなしの役職が存在する | 役職を削除する | 役職が削除され、正常終了する | |
| - | titleId を空文字で送信する | バリデーションエラーが返される | |
| - | titleId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した titleId の役職が存在しない | 役職を削除する | TitleNotFoundError が返される | |
| 役職に割り当て済みユーザーが1人存在する | 役職を削除する | TitleHasAssigneesError が返される | |
| 役職に割り当て済みユーザーが複数存在する | 役職を削除する | TitleHasAssigneesError が返される | |
