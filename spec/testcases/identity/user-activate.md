# ユーザー有効化 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 無効状態（isActive = false）のユーザーが存在する | ユーザーを有効化する | isActive が true に変更され、userId・isActive・updatedAt が返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザー有効化を実行する | UserNotFoundError が返される | |
| ユーザーが既に有効状態（isActive = true） | 再度有効化を実行する | AlreadyActiveError が返される | |
| 無効化されたユーザーを有効化した後 | そのユーザーの認証情報でログインする | ログインが成功する | |
