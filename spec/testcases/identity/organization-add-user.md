# 組織へのユーザー追加 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーと組織が存在し、ユーザーがその組織に未所属 | ユーザーを組織に追加する | ユーザーが組織メンバーとして追加され、userId・organizationId が返却される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | organizationId を空文字で送信する | バリデーションエラーが返される | |
| - | organizationId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーを組織に追加する | UserNotFoundError が返される | |
| 指定した organizationId の組織が存在しない | ユーザーを組織に追加する | OrganizationNotFoundError が返される | |
| ユーザーが既にその組織に所属している | 同じユーザーを同じ組織に再度追加する | AlreadyMemberError が返される | |
| ユーザーが組織Aに所属している | 同じユーザーを別の組織Bに追加する | ユーザーが組織Bにも追加される（複数組織所属可） | |
