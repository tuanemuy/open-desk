# パスワード変更 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 認証済みユーザーが存在する | 正しい現在のパスワードとポリシーを満たす新しいパスワードで変更する | パスワードが変更され、正常終了する | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | currentPassword を空文字で送信する | バリデーションエラーが返される | |
| - | newPassword を空文字で送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | パスワード変更を実行する | UserNotFoundError が返される | |
| 認証済みユーザーが存在する | 誤った currentPassword でパスワード変更する | InvalidCredentialsError が返される | |
| パスワードポリシーの最小文字数が8文字 | newPassword に7文字のパスワードを指定する | バリデーションエラーが返される | |
| パスワードポリシーの最小文字数が8文字 | newPassword にちょうど8文字のパスワードを指定する | パスワードが変更され、正常終了する | |
| パスワードポリシーで複雑さ要件あり（大文字・小文字・数字・記号） | 数字のみの newPassword を指定する | バリデーションエラーが返される | |
| パスワードポリシーで複雑さ要件あり | 要件を満たす newPassword を指定する | パスワードが変更され、正常終了する | |
| パスワードポリシーでログイン名と同一が禁止 | loginName と同一の newPassword を指定する | バリデーションエラーが返される | |
| パスワードポリシーで過去3世代のパスワード再利用禁止 | 1つ前のパスワードと同じ newPassword を指定する | バリデーションエラーが返される | |
| パスワードポリシーで過去3世代のパスワード再利用禁止 | 3つ前のパスワードと同じ newPassword を指定する | バリデーションエラーが返される | |
| パスワードポリシーで過去3世代のパスワード再利用禁止 | 4つ前のパスワードと同じ newPassword を指定する | パスワードが変更され、正常終了する | |
