# グループの作成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| システム管理者が認証済み | name・code を指定してグループを作成する | グループが作成され、groupId・name・code が返却される | |
| - | name を空文字で送信する | バリデーションエラーが返される | |
| - | code を空文字で送信する | バリデーションエラーが返される | |
| 同一の code を持つグループが既に存在する | 同じ code でグループを作成する | DuplicateGroupCodeError が返される | |
| - | 一意な code で複数グループを作成する | 各グループが正常に作成される | |
