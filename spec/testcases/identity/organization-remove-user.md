# 組織からのユーザー削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが組織に所属している（主所属組織でない） | ユーザーを組織から削除する | ユーザーの組織所属が解除され、正常終了する | |
| ユーザーの主所属組織として設定されている組織がある | その組織からユーザーを削除する | 組織所属が解除され、主所属組織（primaryOrganizationId）がクリアされる | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | organizationId を空文字で送信する | バリデーションエラーが返される | |
| - | organizationId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザーを組織から削除する | UserNotFoundError が返される | |
| 指定した organizationId の組織が存在しない | ユーザーを組織から削除する | OrganizationNotFoundError が返される | |
| ユーザーがその組織に所属していない | 組織からユーザーを削除する | NotMemberError が返される | |
