# セッション強制終了 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが複数のセッションを持っている | 自分の別端末のセッションを強制終了する | 指定したセッションが終了され、正常終了する | |
| ユーザーが現在のセッションを持っている | 現在のセッション自身を強制終了する | 現在のセッションが終了され、正常終了する | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | sessionId を空文字で送信する | バリデーションエラーが返される | |
| - | sessionId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した sessionId のセッションが存在しない | セッションを強制終了する | SessionNotFoundError が返される | |
| 他のユーザーのセッションが存在する | 他ユーザーの sessionId を指定して終了する | SessionNotFoundError が返される（他人のセッション存在を隠蔽） | |
