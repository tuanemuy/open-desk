# ユーザー削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが存在し、セッション・組織・グループに所属していない | ユーザーを削除する | ユーザーが削除され、正常終了する | |
| ユーザーが複数のセッションを持っている | ユーザーを削除する | 全セッションが終了された後、ユーザーが削除される | |
| ユーザーが複数の組織に所属している | ユーザーを削除する | すべての組織所属が解除された後、ユーザーが削除される | |
| ユーザーが複数のグループに所属している | ユーザーを削除する | すべてのグループ所属が解除された後、ユーザーが削除される | |
| ユーザーがセッション・組織・グループすべてに所属している | ユーザーを削除する | セッション終了、組織所属解除、グループ所属解除がすべて行われた後、ユーザーが削除される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザー削除を実行する | UserNotFoundError が返される | |
