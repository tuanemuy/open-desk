# 組織の削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 子組織なし・所属ユーザーなしの組織が存在する | 組織を削除する | 組織が削除され、正常終了する | |
| - | organizationId を空文字で送信する | バリデーションエラーが返される | |
| - | organizationId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した organizationId の組織が存在しない | 組織を削除する | OrganizationNotFoundError が返される | |
| 組織に子組織が存在する | 組織を削除する | OrganizationHasChildrenError が返される | |
| 組織に所属ユーザーが存在する | 組織を削除する | OrganizationHasMembersError が返される | |
| 組織に子組織と所属ユーザーの両方が存在する | 組織を削除する | エラーが返される（子組織または所属ユーザーの存在による） | |
