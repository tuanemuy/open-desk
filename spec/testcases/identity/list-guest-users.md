# ゲストユーザー一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ゲストユーザーが5件存在する | ゲストユーザー一覧を取得する | 5件のゲストユーザー情報が返却され、totalCount=5 となる | |
| ゲストユーザーが存在しない | ゲストユーザー一覧を取得する | guestUsers が空配列で返却され、totalCount=0、trialCount=0、paidCount=0、licensedCount=0 となる | |
| ゲストユーザーが15件存在する | offset=0, limit=10 で取得する | 先頭10件が返却され、totalCount=15 となる | |
| ゲストユーザーが15件存在する | offset=10, limit=10 で取得する | 残り5件が返却され、totalCount=15 となる | |
| ゲストユーザーが15件存在する | offset=15, limit=10 で取得する | guestUsers が空配列で返却され、totalCount=15 となる | |
| - | offset に負数（-1）を指定する | バリデーションエラーが返される | |
| - | limit に 0 を指定する | バリデーションエラーが返される | |
| - | limit に 101 を指定する | バリデーションエラーが返される | |
| - | offset・limit を省略して取得する | offset=0, limit=100 のデフォルト値で取得される | |
| 試用中のゲストユーザーが2件、有料のゲストユーザーが3件存在する | ゲストユーザー一覧を取得する | trialCount=2、paidCount=3 が正しく集計されて返却される | |
| ゲストユーザーが複数のゲストスペースに所属している | ゲストユーザー一覧を取得する | guestSpaceNames に所属する全ゲストスペース名が含まれる | |
| ゲストユーザーが無効化されている（isActive=false） | ゲストユーザー一覧を取得する | isActive=false のゲストユーザーも一覧に含まれる | |
| ゲストユーザーが一度もログインしていない | ゲストユーザー一覧を取得する | lastLoginAt が null で返却される | |
| 試用期限が設定されたゲストユーザーが存在する | ゲストユーザー一覧を取得する | trialExpiresAt に期限日時が返却される | |
| - | limit に 1 を指定する | 先頭1件のみ返却される（境界値） | |
| - | limit に 100 を指定する | 最大100件が返却される（境界値） | |
