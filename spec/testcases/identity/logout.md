# ログアウト テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 認証済みユーザーの有効なセッションが存在する | 有効な sessionId でログアウトする | セッションが無効化され、正常終了する | |
| - | sessionId を空文字で送信する | バリデーションエラーが返される | |
| - | sessionId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した sessionId のセッションが存在しない | 存在しない sessionId でログアウトする | SessionNotFoundError が返される | |
| セッションが既に無効化されている | 無効化済みの sessionId でログアウトする | SessionNotFoundError が返される | |
| 認証済みユーザーの有効なセッションが存在する | ログアウト後に同じ sessionId で再度ログアウトする | SessionNotFoundError が返される | |
