# ユーザー無効化 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効状態（isActive = true）のユーザーが存在する | ユーザーを無効化する | isActive が false に変更され、全セッションが強制終了される | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID v4 形式でない文字列を送信する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | ユーザー無効化を実行する | UserNotFoundError が返される | |
| ユーザーが既に無効状態（isActive = false） | 再度無効化を実行する | AlreadyInactiveError が返される | |
| 有効状態のユーザーが複数セッションを持っている | ユーザーを無効化する | ユーザーの全セッションが終了される | |
| 有効状態のユーザーがセッションを持っていない | ユーザーを無効化する | isActive が false に変更され、正常終了する | |
