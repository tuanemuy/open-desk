# セッション一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ユーザーが有効なセッションを3つ持っている | セッション一覧を取得する | 3件のセッション情報が createdAt 降順で返却され、totalCount=3 となる | |
| ユーザーが有効なセッションを持っていない | セッション一覧を取得する | sessions が空配列で返却され、totalCount=0 となる | |
| ユーザーが有効なセッション7つと期限切れセッション3つを持っている | セッション一覧を取得する | 有効な7件のみが返却され、totalCount=7 となる | |
| ユーザーが有効なセッションを7つ持っている | offset=0, limit=5 で取得する | 先頭5件が返却され、totalCount=7 となる | |
| ユーザーが有効なセッションを7つ持っている | offset=5, limit=5 で取得する | 残り2件が返却され、totalCount=7 となる | |
| - | userId を空文字で送信する | バリデーションエラーが返される | |
| - | userId に UUID 形式でない文字列を送信する | バリデーションエラーが返される | |
| - | offset に負数（-1）を指定する | バリデーションエラーが返される | |
| - | limit に 0 を指定する | バリデーションエラーが返される | |
| - | limit に 6 を指定する | バリデーションエラーが返される | |
| 指定した userId のユーザーが存在しない | セッション一覧を取得する | UserNotFoundError が返される | |
| ユーザーが有効なセッションを持っている | offset=0, limit=1 で取得する | 最新の1件のみ返却される（境界値） | |
| ユーザーが有効なセッションを持っている | offset・limit を省略して取得する | offset=0, limit=5 のデフォルト値で取得される | |
| 現在のセッションを含む複数セッションがある | セッション一覧を取得する | 現在のセッションの isCurrent が true、他は false で返却される | |
