# メンション通知生成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メンション対象ユーザーが複数存在する | メンション通知を生成する | 各対象ユーザーに通知が生成され、notifications 配列が返る | |
| メンション対象に送信者自身が含まれる | メンション通知を生成する | 送信者自身への通知は除外される | |
| sourceType=COMMENT でメンション通知を生成 | メンション通知を生成する | type と sourceType が正しく設定された通知が生成される | |
| sourceType=THREAD でメンション通知を生成 | メンション通知を生成する | type と sourceType が正しく設定された通知が生成される | |
| 受信者のメール通知設定が有効 | メンション通知を生成する | 通知生成後にメール通知が送信される | |
| 受信者のデスクトップ通知設定が有効 | メンション通知を生成する | 通知生成後にデスクトップ通知が送信される | |
| 受信者のメール通知設定が無効 | メンション通知を生成する | メール通知は送信されないが、通知自体は生成される | |
| メール通知の送信に失敗する | メンション通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| デスクトップ通知の送信に失敗する | メンション通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| mentionedUserIds が1件 | メンション通知を生成する | 1件の通知が生成される（境界値） | |
| title が256文字 | メンション通知を生成する | 通知が正常に生成される（境界値） | |
| title が257文字 | メンション通知を生成する | バリデーションエラーが返る | |
| content が1024文字 | メンション通知を生成する | 通知が正常に生成される（境界値） | |
| content が1025文字 | メンション通知を生成する | バリデーションエラーが返る | |
| title が空文字 | メンション通知を生成する | バリデーションエラーが返る | |
| sourceId が空文字 | メンション通知を生成する | バリデーションエラーが返る | |
