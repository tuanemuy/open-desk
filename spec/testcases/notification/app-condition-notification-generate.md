# アプリ条件通知生成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アプリ条件通知の対象ユーザーが複数存在する | アプリ条件通知を生成する | 各対象ユーザーに通知が生成され、notifications 配列が返る | |
| 対象に送信者自身が含まれる | アプリ条件通知を生成する | 送信者自身への通知は除外される | |
| mentionedUserIds が指定されている | アプリ条件通知を生成する | メンション対象ユーザーは通知対象から除外される（重複排除） | |
| mentionedUserIds が省略されている | アプリ条件通知を生成する | recipientIds 全員に通知が生成される（送信者除外のみ） | |
| sourceType=RECORD でアプリ条件通知を生成 | アプリ条件通知を生成する | sourceType=RECORD の通知が生成される | |
| sourceType=COMMENT でアプリ条件通知を生成 | アプリ条件通知を生成する | sourceType=COMMENT の通知が生成される | |
| 受信者のメール通知設定が有効 | アプリ条件通知を生成する | メール通知が送信される | |
| 受信者のデスクトップ通知設定が有効 | アプリ条件通知を生成する | デスクトップ通知が送信される | |
| メール通知の送信に失敗する | アプリ条件通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| デスクトップ通知の送信に失敗する | アプリ条件通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| recipientIds 全員が mentionedUserIds に含まれる | アプリ条件通知を生成する | 全員除外され、通知は0件生成される | |
| title が256文字 | アプリ条件通知を生成する | 通知が正常に生成される（境界値） | |
| title が257文字 | アプリ条件通知を生成する | バリデーションエラーが返る | |
| content が1024文字 | アプリ条件通知を生成する | 通知が正常に生成される（境界値） | |
| content が1025文字 | アプリ条件通知を生成する | バリデーションエラーが返る | |
| title が空文字 | アプリ条件通知を生成する | バリデーションエラーが返る | |
| sourceId が空文字 | アプリ条件通知を生成する | バリデーションエラーが返る | |
