# 未読通知件数取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者宛の未読通知が複数存在する | 未読通知件数を取得する | 正確な unreadCount が返る | |
| 操作者宛の未読通知が0件 | 未読通知件数を取得する | unreadCount=0 が返る | |
| 操作者宛の通知がすべて既読 | 未読通知件数を取得する | unreadCount=0 が返る | |
| 操作者宛の未読通知が1件 | 未読通知件数を取得する | unreadCount=1 が返る（境界値） | |
| 操作者宛の未読通知が大量に存在する | 未読通知件数を取得する | 正確な件数が返る | |
