# カスタムフィルタ削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者が所有するカスタムフィルタが存在する | カスタムフィルタを削除する | フィルタが削除される | |
| 存在しない filterId を指定する | カスタムフィルタ削除を試みる | FilterNotFoundError が返る | |
| 他ユーザーが所有するフィルタIDを指定する | カスタムフィルタ削除を試みる | FilterAccessDeniedError が返る | |
| ビルトインフィルタのIDを指定する | カスタムフィルタ削除を試みる | CannotDeleteBuiltInFilterError が返る | |
