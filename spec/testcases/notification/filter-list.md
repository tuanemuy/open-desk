# フィルタ一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者がカスタムフィルタを複数所有している | フィルタ一覧を取得する | ビルトインフィルタ（「自分宛」「あとで読む」「すべて」）とカスタムフィルタの一覧が返る | |
| 操作者がカスタムフィルタを所有していない | フィルタ一覧を取得する | ビルトインフィルタのみが返る（カスタムフィルタは空配列） | |
| 操作者が認証済みユーザー | フィルタ一覧を取得する | ビルトインフィルタが必ず3件（「自分宛」「あとで読む」「すべて」）含まれる | |
| 他ユーザーがカスタムフィルタを所有している | フィルタ一覧を取得する | 他ユーザーのフィルタは含まれず、操作者のフィルタのみが返る | |
