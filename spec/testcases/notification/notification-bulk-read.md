# 通知一括既読化 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者宛の未読通知が複数存在する | notificationIds を指定して一括既読にする | 指定された通知が既読になり、readCount が返る | |
| 操作者宛の未読通知が複数存在する | notificationIds を省略して一括既読にする | 全未読通知が既読になり、readCount が返る | |
| 操作者宛の未読通知と既読通知が混在 | notificationIds に既読通知を含めて一括既読にする | 未読のもののみカウントされ、readCount が返る | |
| 操作者宛の未読通知が0件 | notificationIds を省略して一括既読にする | readCount=0 が返る | |
| notificationIds に存在しない通知IDを含む | 一括既読にする | 存在しない通知IDは無視され、有効な通知のみ既読になる | |
| notificationIds に他ユーザー宛の通知IDを含む | 一括既読にする | 操作者が受信者である通知のみ既読になり、他ユーザー宛は無視される | |
| 操作者宛の未読通知が大量に存在する | notificationIds を省略して一括既読にする | 全未読通知が既読になる | |
| notificationIds に空配列を指定する | 一括既読にする | readCount=0 が返る | |
