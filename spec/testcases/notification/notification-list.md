# 通知一覧取得 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作者宛の通知が複数存在する | フィルタ未指定で通知一覧を取得する | ビルトインフィルタ「自分宛」で通知一覧と totalCount が返る | |
| 操作者宛の通知が複数存在する | isRead=true で取得する | 既読通知のみが返る | |
| 操作者宛の通知が複数存在する | isRead=false で取得する | 未読通知のみが返る | |
| 操作者宛の通知が複数存在する | isRead を省略して取得する | 既読・未読を問わず全通知が返る | |
| 操作者宛の通知が複数存在する | offset=0, limit=10 で取得する | 先頭10件の通知が返る | |
| 操作者宛の通知が複数存在する | offset=10, limit=10 で取得する | 11件目から20件目の通知が返る | |
| 操作者宛の通知が複数存在する | limit を省略して取得する | デフォルト50件で取得される | |
| 操作者宛の通知が複数存在する | offset を省略して取得する | デフォルト0から取得される | |
| 有効なカスタムフィルタIDを指定する | カスタムフィルタで通知一覧を取得する | フィルタ条件に一致する通知のみが返る | |
| 有効なビルトインフィルタIDを指定する | ビルトインフィルタで通知一覧を取得する | フィルタ条件に一致する通知が返る | |
| 存在しない filterId を指定する | 通知一覧取得を試みる | FilterNotFoundError が返る | |
| 他ユーザーが所有するフィルタIDを指定する | 通知一覧取得を試みる | FilterAccessDeniedError が返る | |
| 操作者宛の通知が0件の状態 | 通知一覧を取得する | 空の配列と totalCount=0 が返る | |
| 操作者宛の通知が存在する | offset に負の値を指定する | バリデーションエラーが返る | |
| 操作者宛の通知が存在する | limit=1 で取得する | 1件が返る（境界値） | |
| 操作者宛の通知が存在する | limit=0 で取得する | バリデーションエラーが返る（境界値） | |
