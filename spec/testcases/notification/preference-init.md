# 通知設定初期化 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 新しいユーザーアカウントが作成された | 通知設定を初期化する | デフォルト値で通知設定が生成される（emailEnabled=true, emailScope=MENTION_ONLY, emailFormat=HTML, desktopEnabled=false） | |
| 新しいユーザーアカウントが作成された | 通知設定を初期化する | ビルトインフィルタ（「自分宛」「あとで読む」「すべて」）が同時に生成される | |
| 既に通知設定が存在するユーザー | 通知設定初期化を再度実行する | 既存の設定がそのまま返る（冪等性の保証） | |
| 既に通知設定が存在するユーザー | 通知設定初期化を再度実行する | 既存設定が上書きされない | |
| 既にビルトインフィルタが存在するユーザー | 通知設定初期化を再度実行する | 既存フィルタが重複生成されない | |
