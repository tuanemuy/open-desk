# 期限切れ通知の一括削除 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 保持期限を超過した通知が複数存在する | retentionDays を指定して一括削除する | 期限切れ通知が削除され、deletedCount が返る | |
| 保持期限を超過した通知が0件 | retentionDays を指定して一括削除する | deletedCount=0 が返る | |
| 保持期限内の通知のみ存在する | retentionDays を指定して一括削除する | deletedCount=0 が返る（期限内の通知は削除されない） | |
| 保持期限を超過した通知と期限内の通知が混在する | retentionDays を指定して一括削除する | 期限超過の通知のみ削除され、期限内の通知は残る | |
| retentionDays=1 を指定（最小値） | 1日以上前の通知が存在する状態で一括削除する | 1日以上前の通知が削除される（境界値） | |
| retentionDays=0 を指定 | 一括削除を試みる | バリデーションエラーが返る | |
| retentionDays に負の値を指定する | 一括削除を試みる | バリデーションエラーが返る | |
| データベースエラーが発生する | 一括削除を試みる | 外部サービスエラーが返る | |
| 大量の期限切れ通知が存在する | retentionDays を指定して一括削除する | 全期限切れ通知が削除され、正確な deletedCount が返る | |
