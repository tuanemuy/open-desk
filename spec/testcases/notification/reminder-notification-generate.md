# リマインダー通知生成 テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| リマインダー対象ユーザーが複数存在する | リマインダー通知を生成する | 各対象ユーザーに通知が生成される。senderId は null（システム自動生成） | |
| リマインダー対象ユーザーが1名 | リマインダー通知を生成する | 1件の通知が生成される（境界値） | |
| sourceType=RECORD で通知を生成 | リマインダー通知を生成する | sourceType=RECORD の通知が生成される | |
| 受信者のメール通知設定が有効 | リマインダー通知を生成する | メール通知が送信される | |
| 受信者のデスクトップ通知設定が有効 | リマインダー通知を生成する | デスクトップ通知が送信される | |
| メール通知の送信に失敗する | リマインダー通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| デスクトップ通知の送信に失敗する | リマインダー通知を生成する | 通知生成自体は成功する（外部サービスエラーは通知には影響しない） | |
| title が256文字 | リマインダー通知を生成する | 通知が正常に生成される（境界値） | |
| title が257文字 | リマインダー通知を生成する | バリデーションエラーが返る | |
| content が1024文字 | リマインダー通知を生成する | 通知が正常に生成される（境界値） | |
| content が1025文字 | リマインダー通知を生成する | バリデーションエラーが返る | |
| title が空文字 | リマインダー通知を生成する | バリデーションエラーが返る | |
| sourceId が空文字 | リマインダー通知を生成する | バリデーションエラーが返る | |
